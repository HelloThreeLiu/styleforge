## 二、本页面如何应用

- **导航**：暖奶油吸顶 + backdrop-blur + `rgba(38,37,30,.1)` 底线；链接 14px/500 hover 变暖绯红；右侧药丸"控制台"（`#e6e5e0` 底）+ 暖表面"获取 API 密钥"按钮（8px 圆角）。
- **英雄区**：居中构图 + 104px 顶部大留白；药丸标签（mono `● live` 绿 + 版本号）；H1 `clamp(36→72px)`/400/-0.028em 压缩双行；副文用衬线 17.28px/1.35（jjannon 层级照搬）；主 CTA 暖表面按钮 + ghost 变体（6% 暖棕底）。
- **代码编辑器预览**：深暖控制台 `#17150f` + 大模糊氛围阴影 + 暖环；文件名栏（mono 11px/-0.275px）+ 三圆点；curl 请求与 JSON 响应的语法高亮**全部取自时间线四色**（注释桃、函数蓝、字符串鼠尾草绿、标点淡紫），金色留给数字——把源风格"编辑器截图即英雄"翻译为 API 语境。
- **请求时间线**：AI Timeline 的 API 化四步（parse/fetch/merge/respond），每步语义色圆点 + mono 步骤码 + 衬线说明，横向连接线 `rgba(38,37,30,.1)`。
- **定价区**：置于 `#f7f7f4` 浅一度分区（表面交替手法）；计费切换用双层药丸分段（激活项浅表面底，"省 20%" 用 mono 绿），JS 联动改价。三卡：沙盒/专业（**精选**：金调边框 + 10px 圆角 + 氛围阴影 + mono `most popular` 旗标 + 深墨按钮 hover 变暖绯红）/企业。**权益清单全部衬线**（文档明示 pricing feature lists 用 jjannon），数字与配额用 mono 强调。
- **数据带**：`rgba(38,37,30,.55)` 强边做顶线的四联数字（26px/-0.0125em）。
- **页脚**：mono 小写栏题（uppercase 转换）+ 衬线品牌句；底栏 mono 11px 版本号。
- **响应式**：900 起时间线 2 列、定价单列（精选置顶）、数据 2 列；768 起导航折叠、区块距收缩；480：英雄 36px、按钮全宽 ≥44px、时间线单列、页脚单列；375px 下展示 36px（≥30px 底线）。

## 三、有意偏离点及理由

1. **字体替换**：CursorGothic（私有哥特体）以 Archivo 替代（同为工程感 grotesk，400/500/600 对应其字重纪律）；jjannon 衬线以 Lora 替代（暖编辑衬线，`"cswh"` 花饰特性无法复现，属可接受损失）；berkeleyMono 按回退链以 IBM Plex Mono 替代。
2. **中文负字距折衷**：源文档字距针对拉丁字形，中文统一收至 -0.028em（72px）/-0.02em（36px）/-0.0125em（26px），压缩气质保留、避免并笔。
3. **英雄最小字号**：源文档响应式收至 26px，低于平台 375px ≥30px 底线，故移动端下限设为 36px——平台底线优先，在此声明。
4. **oklab 边框**：以 `rgba(38,37,30, α)` 作为 CSS 等价回退（文档 §9 迭代指南明示此法）。
5. 无其他偏离：暖表面阶、hover 变暖绯红、药丸/8px 双圆角制、三声部字役、时间线四色、氛围大模糊阴影均逐项取自 DESIGN.md。
