# 设计笔记：Meridian 支付基础设施落地页

## 一、从 DESIGN.md 学到的核心决策

学习对象：`awesome-design-md/design-md/stripe/DESIGN.md`（study 模式，纯复刻）。吸收的核心 tokens：

| Token | 取值 | 角色 |
|---|---|---|
| 标题字重/字距 | 56px / weight 300 / -1.4px；32px / 300 / -0.64px | "轻字重即奢侈"——反常规的细字重大标题是 Stripe 最强的排版签名 |
| 标题色 | `#061b31`（深海军蓝，非黑） | 温暖、金融级严肃感 |
| 主品牌紫 | `#533afd`（CTA/链接），hover `#4434d4` | 唯一交互色 |
| 正文字色 | `#64748d` | 次级文本灰 |
| 签名阴影 | `rgba(50,50,93,0.25) 0 30px 45px -30px` + `rgba(0,0,0,0.1) 0 18px 36px -18px` | 蓝调双层阴影——海拔感也是品牌色 |
| 渐变装饰 | `#ea2261` → `#f96bee`（ruby→magenta） | 仅用于英雄区强调词与装饰线，克制使用 |
| 圆角体系 | 4px（按钮）/ 6-8px（卡片） | 保守圆角，无药丸形 |
| 边框 | `#e5edf5` | 冷调极浅边框 |
| 深色区 | `#1c1e54`（brand dark） | 品牌暗部章节 |
| 数字 | `"tnum"` 表格数字 + SourceCodePro 代码字体 | 金融数据的等宽对齐 |
| OpenType | 全局 `"ss01"` | 字形风格集（字体不可得时以 Inter 近似） |

## 二、本页面如何应用

- **导航**：白底 sticky + backdrop blur、14px/400 链接、右侧紫色主按钮 + 描边次按钮，6px 容器圆角——完全按 Navigation 规范。
- **英雄区**：56px/300/-1.4px 主标题，"支付基础设施"五字用 ruby→magenta 渐变裁切；背景用品牌紫与 magenta 的低透明度径向渐变做"暮色天空"氛围；底部一条渐变装饰线（Stripe 式的克制装饰）。
- **特性网格**：`#e5edf5` 边框 + 8px 圆角白卡，hover 时叠加签名蓝调双层阴影；图标统一线稿风格、紫色描边、淡紫底 `rgba(83,58,253,0.06)`。
- **代码演示**：深海军蓝 `#061b31` 代码卡承载 SourceCodePro 12px/行高2 的代码块，语法高亮用品牌 magenta 与成功绿；配 tnum 指标行（99.999% / 135+ / 46 / <80ms）。
- **定价**：三卡布局，中卡用 `#061b31` 深边框 + 签名阴影做 featured 层级；"推荐"角标用品牌渐变；价格数字启用 tnum。
- **深色 CTA**：`#1c1e54` 底 + 白字 + 半透明白次级描边按钮。
- **响应式**：768px 两列→480px 单列；导航折叠为汉堡；56px 标题在移动端降至 32px 并按比例放宽字距。

## 三、有意偏离点及理由

1. **字体**：DESIGN.md 指定 sohne-var（私有字体），按"CDN 字体 + 系统回退"底线规则以 Inter 300/400 近似（同为几何无衬线，字重体系一致），并在字体栈首位保留 `sohne-var` 以便未来替换。`"ss01"` 特性在 Inter 上无效，已声明但不生效——这是客观限制，非遗忘。
2. **展示品牌**：页面为虚构品牌"Meridian"，所有文案、数据均为原创，未复用 Stripe 商标、Logo 或真实文案（版权红线 R2）。
3. 无其他偏离：色板、阴影、圆角、字重体系、按钮规格、深色区用法均逐项取自 DESIGN.md。
