## 二、本页面如何应用

- **导航**：白底 sticky + `blur(12px)` + 5% 底线；链接 15px/500 hover 变绿；右端深色药丸 CTA。
- **Hero**：顶部 1100px 宽**绿白云雾径向渐变 wash**（浅绿 90% → 40% → 透明，溢出隐藏）→ 浅绿底徽章（社区/工具/非营利三数据）→ 64px/600/-1.28px「全社区的电钻，不该一共只有三台。」→ 18px 灰副文 → 深色药丸主 CTA + 白 ghost 药丸。
- **Trust bar**：`Loved by these neighborhoods` 13px/uppercase/0.65px 区标 + 六格 `#fafafa` 16px 圆角社区徽标（5% 边框、灰字灰度处理）。
- **数字条**：三格 48px/600/-1px 数字（4,200+ 件工具 / 38,000 次借出 / ¥0 会员费）。
- **Feature 卡 ×3**：16px 圆角白卡（5% 边 + 耳语阴影，hover 边框加深至 8%）——浅绿圆角图标块 + 20px/600 标题 + 14px 灰正文 + **Geist Mono 大写技术注脚**（`avg pickup: 4 min`）。
- **三步流程**：24px 特写卡 + 药丸步骤号（浅绿底深绿字 mono）+ 4px 圆角行内代码标签（`join: open-day · sat 10:00`）。
- **深色 CTA 区**：`#0d0d0d` 24px 圆角大盒——品牌绿 mono 标签、白 40px/-0.8px 标题、**药丸邮箱输入**（`#141414` 底 + 8% 白边，focus 绿边）+ 绿色药丸按钮 + 「✓ 已登记」反馈。
- **页脚**：白底多栏（13px/uppercase 区标），链接 hover 绿；mono 状态行 `shed: 27 · tools: 4200`。
- **响应式**：1280 收容器；1024 卡片两列、trust 三列；768 导航折叠、统计/卡片单列、CTA 盒收边距；480 邮箱输入全宽；375 显式处理（hero 30px≥底线、字距收至 -0.5px、数字 38px）。

## 三、有意偏离点及理由

1. **主题自行改选**：建议主题「婚礼邀请与回函」与白露页撞车，改选「社区工具共享网络」；marketing/consumer 采纳建议。
2. **字体**：Inter 与 Geist Mono 均可直接从 Google Fonts 加载，与文档完全一致，无字体偏离；中文回退链（PingFang SC/微软雅黑）按平台底线追加。
3. **中文负字距**：-1.28px/-0.8px 文档值应用于中英混排标题；480px 以下收至 -0.8px、375px 收至 -0.5px 防粘连。
4. **Hero 渐变的形状**：文档描述"soft green-to-white cloud-like gradient wash"未给精确公式；以径向椭圆（浅绿 `#d4fa8` 系 → 白 → 透明）居中渲染，色值严格取自文档浅绿面，仅形状参数为自由度，在此声明。
5. 无其他偏离：全药丸按钮、5% 边框体系、三字重、Geist Mono 大写标签、16/24px 圆角、耳语阴影、白上白无灰区、深色 CTA 盒均逐项取自 DESIGN.md。
