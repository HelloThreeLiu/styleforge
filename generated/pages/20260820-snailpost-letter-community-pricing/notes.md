## 二、本页面如何应用

- **导航**：2px 墨线吸顶；衬线斜体字标"慢递."（橙点）；链接 hover 橙色下划线。
- **英雄区**：点阵纸面上 84px 衬线"把邮件 / 熬成一封信"（"一封信"斜体橙）；右侧**微斜信件装置**：LIVE 橙点脉冲（在途中）、收件地址、`#fffdf6` 信封（墨线折痕 + 斜贴邮票 + 手写体开头）、**纯 CSS 火漆印章**（不规则圆 + 径向橙渐变 + 衬线"慢"字 + 硬投影）——橙色集中在"热"的物件上。
- **跑马灯**：焦墨条滚动社区数据（在途/最远/最长/火漆数），`<b>` 关键词染橙。
- **会员三档**：2px 墨边 + 硬投影卡；**精选「火漆」档**：3px 橙边 + 橙色硬投影 + 双贴纸（左上迷你火漆章 + 右上"最受欢迎"）+ 橙底 CTA；权益清单 `—` 前缀衬线体；免费档含一条淡化项。
- **三道工序**：深纸分区 + 左墨线分栏，"落笔/封蜡/等待"各嵌一个斜体橙字。
- **信件摘录**：微斜 `#fffdf6` 信纸卡 + 衬线斜体引文 + 编号式署名。
- **终章**："第一封信，写给六天后的谁？"（"六天后"斜体橙）+ 橙 CTA。
- **页脚**：焦墨反转，"隐私（我们不读信）"是社区性格的落点。
- **响应式**：768 起导航折叠、英雄单栏、会员单列（精选置顶）、工序纵排、页脚两栏；480：装置与信纸**旋转归零**、按钮全宽 ≥44px、页脚单列；375px 下展示 48px（≥30px 底线）。

## 三、有意偏离点及理由

1. **风格自选说明**：本轮 round 计划只输出 1 个抽取风格（spotify），按 §11"不得追问、计划外可自选池中风格"的原则补足第 2 页；选择 ink-ember-v1 的原因——★4.5 高分血统、首次被回学（验证沉淀文档的可复现性）、且与 spotify 页的类型/行业/主题互不雷同。
2. **字体**：与 EMBER 原页一致（Fraunces + Inter，CDN 直载 + 宋体/雅黑回退）。
3. **定价页的非商品化处理**：按 §11 题材纪律，把 pricing 做成"社区会员支持"叙事（免费笔友档/火漆年付赠章/城市分局共建），弱化商品感。
4. 无其他偏离：三色材料、2px 墨线、硬偏移投影、贴纸/微斜/按压三顽皮、橙的"热"纪律、跑马灯与焦墨页脚均逐项取自 ink-ember-v1/DESIGN.md。
