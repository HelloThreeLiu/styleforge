## 二、本页面如何应用

- **导航**：奶油吸顶 + 沙色底线；logo 为橙色八角星记号 + 「夜观 starlog.」（衬线斜体英文——GT Alpina 层的落点）；橙色 4px CTA「订阅更新」。
- **英雄区**：Degular 式展示标题 `clamp(40→56px)`/500/宽字重（Archivo 125% 宽轴复刻 wide-set 几何展示），行高按 CJK 折衷 1.06；「星图」一词用 Newsreader 细斜体（GT Alpina 编辑层的词级点缀）；双 CTA：深色大按钮（20/24 宽绰内距）+ 浅沙幽灵。
- **精选星图卡**：8px 圆角沙边卡；星图为暖近黑面板 + **纯 CSS 星点**（十二枚 radial-gradient 星点，含一颗橙色变星）+ SVG 橙色星座连线（天琴座 Vega）+ 大写星等角标——「奶油纸上的暖黑天文台」。
- **分类 Tab**：文档签名的 inset 下划线——激活橙、hover 沙；JS 真实过滤六篇日志（全部/行星/深空/流星/器材）。
- **日志网格**：5px 圆角沙边卡 ×6；大写分类标签 + Inter 20/600 标题 + 正文 16px + 暖灰元信息（日期 · 观测地）；hover 边框加深（唯一的卡片态变化）。
- **数据计数**：48px/500 大数字三联，上下沙色通栏线。
- **订阅**：左标题（展示 + 衬线斜体短语）右表单；输入框 focus 变橙边（文档焦点规则）。
- **页脚**：暖黑反转四栏，沙色链接 hover 奶白，底栏"晴朗 · 微风 · Bortle 3"彩蛋。
- **响应式**：1024 起日志两列；768 起导航折叠、英雄单列、日志/数据/订阅单列、页脚两栏；480：英雄 40px、CTA 全宽、页脚单列；375px 下展示 40px（≥30px 底线），Tab 触控 ≥44px。

## 三、有意偏离点及理由

1. **字体替换**：Degular Display 为商业展示字体，以 Archivo 可变宽轴（wdth 125）+ 500/600 复刻其"宽置几何展示"气质；GT Alpina 以 Newsreader 细斜体（300 italic）替代；Inter 按文档直载。
2. **CJK 行高折衷**：0.90 展示行高对中文会裁切，放宽至 1.06；压缩块气质靠宽字重与负字距保留。
3. **星图连线用内联 SVG**：平台禁外部图片；星点为 CSS radial-gradient、星座连线为内联 SVG（非外部资源），符合"单文件自包含"底线。
4. **Tab 过滤为真实交互**：文档未给 Tab 行为规格；按"inset 下划线 + 真实内容过滤"实现，与源工具气质一致。
5. 无其他偏离：奶油/暖黑/橙色纪律、沙边优先零阴影、inset Tab 下划线、按钮圆角阶梯、深色页脚反转均逐项取自 DESIGN.md。
