## 二、本页面如何应用

- **导航**：实心 `#201d1d` 吸顶（无模糊无透明）；品牌 `hertz~` 700 字重 + 绿色波浪号；「设置」项用 2px `#9a9898` 底线激活（tab 指示语法）；右侧"文档 · 夜航西飞"弱化用户区。
- **页头**：`$ hertz settings --studio` 命令行式眉题（绿色 flag 提示）——把源风格"终端英雄区"翻译为设置页语境；H1 38px/700 与 16px 副题。
- **Tab 组**：16px/500/行高 1.0 的紧排标签 + 2px 底线指示，JS 真实切换五个面板（账号/播放器/分发/通知/API）。
- **表单**：全部浅底 `#f8f7f7` + 20px 内距 + 6px 圆角输入框，focus 边框变蓝；readonly 字段改暗面 `#302c2c` + 中灰字区分态。标签 16px/700，提示 14px/行高 2.0。
- **开关**：全站方角平面开关——48×26 轨道 + 2px 方形滑块，ON 态绿色描边 + 12% 绿底 + 绿滑块（语义绿的"激活"用法）；无一处阴影。
- **播放器预览**：`#302c2c` 抬升暗面 + `#646262` 描边的 4px 圆角嵌入卡：方形播放键、绿色进度已播段——把设置项的后果即时可见。
- **分发面板**：平台状态用语义四色标注（绿已收录 / 橙待审核 / 弱灰未提交 + 蓝描边"提交收录"按钮）；RSS 复制按钮点击后 1.4s 绿色"✓ 已复制"瞬时反馈（终端式，无 toast 弹层）。
- **API 面板**：等宽密钥掩码 + 显隐切换 + 蓝色描边"重新生成"；用量行 `12,483 / 50,000`；**危险区**红描边容器（40% 红）+ 红底删除按钮，两段确认（首次变"再点一次确认删除"，3 秒超时复位）——语义红的三段式（默认/hover `#d70015`）逐项落实。
- **页脚**：暖透明顶边 + 四栏链接（`#9a9898`，hover 蓝）+ MIT License 底栏。
- **响应式**：768 起导航折叠抽屉（激活项转绿色）、H1 28px、内联字段纵排；480/375：H1 24px、按钮强制 ≥44px 触控、密钥行换行可滚动、页脚单列；窄容器全站无横向滚动。

## 三、有意偏离点及理由

1. **字体替换**：Berkeley Mono 为商业授权字体，按文档回退栈首位以 IBM Plex Mono（Google Fonts，400/500/700）替代；中文回退至系统等宽/默认字体（文档回退栈本身即如此声明），CJK 与拉丁混排的字宽差异属平台渲染行为。
2. **开关组件为词表外推导**：DESIGN.md 无开关规格；按"方角 4px + 描边深度 + 语义绿激活"三原则推导，未引入阴影与渐变。
3. **命令行眉题**：词表无设置页页头范式；借 §4"Terminal Hero"组件以单行命令形式移植，保持终端身份而不占用内容空间。
4. **危险区红描边容器**：词表仅给红色按钮规格；容器用 40% 透明红描边强化分区，属语义色的合理延展（危险信号），未引入新色。
5. 无其他偏离：暖黑/暖白双色板、零阴影纯边框深度、4/6px 双圆角体系、8px 栅格、150ms 内瞬时动效、单字体单声部均逐项取自 DESIGN.md。
