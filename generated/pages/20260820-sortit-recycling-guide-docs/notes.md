## 二、本页面如何应用

- **顶栏**：白底吸顶 + `#e0e2e6` 底线；十字回收记号 logo（蓝）；**搜索框置于导航中央**——并做成真实功能（按物品关键词过滤疑难清单）；蓝 CTA"下载打印版"。
- **文档骨架**：232px 粘性侧栏（分区大写小标 + 蓝色药丸激活态）+ 正文单栏——文档站的标准骨架以 Airtable 交互件语法搭建。
- **正文排版**：面包屑（蓝链接）→ 40px/400 大标题 → 元信息行 → 18px 导语；H2 24/700、正文 16/1.65/0.18px 正字距；内联链接蓝 + hover 下划线。
- **口诀提示卡**：浅表面 16px 圆角 + 柔环境影 + 蓝色圆角图标位——文档站 callout 语法。
- **四分类速记卡**：`1px` 边框 16px 圆角四联，图标底色分别取蓝调 10%、成功绿 10%、警示红 10%、中性 8%——语义色的克制使用。
- **数据表 ×2**：可回收清单（材质/举例/投放要求 ✓ 绿/误区 ✗ 红）与投放时间表——**Airtable 数据表基因的正面出场**：大写表头 + 浅表面表头底 + 行 hover 3% 蓝染。
- **疑难问答**：16px 圆角边框卡 ×8，hover 蓝调多层阴影；高频/便民标签为 8% 蓝底药丸；搜索无结果时显示空态提示。
- **志愿者横幅**：24px 圆角 + 6% 蓝渐变底 + 20% 蓝边——蓝色唯一的"大面积"形态（同源纪律）。
- **页脚**：极简单行 + 链接 hover 蓝。
- **响应式**：1024 起四分类两列；768 起导航折叠、搜索隐藏、**文档转单栏**（侧栏转为顶部锚点导航）、四分类单列；480：标题 30px、横幅按钮全宽；375px 下标题 30px（恰守底线），问答卡触控充分。
