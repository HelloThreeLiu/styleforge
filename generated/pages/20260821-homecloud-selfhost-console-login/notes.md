## 二、本页面如何应用

- **导航**：`#0f0f0f` blur + `.06` 白雾底线；青框 logo（1px 青边 + 50% 青芯）；链接白 hover 青；白主按钮（hover 加硬偏移阴影）。
- **Hero（钴蓝→黑渐变 + 青辉光双层）**：mono 大写 overline（v2.4 染青）→ 64px/400/**0.87 行高**三行压缩标题「你家电表后面，藏着一台云。」→ 60% 白副文 → mono 大数字事实行（14 应用 / 2.1 TB / **0 字节出网**）。
- **登录卡（签名组合）**：`#000000` 卡 + `.12` 白边 4px + **4px 4px 硬偏移阴影** + 卡后青 8% 径向 halo；mono 小写标签 + 透明输入（`.10` 边 → focus 信号蓝）；白「LAN 直连登录」+ 青 12% 底海洋蓝边「远程中继」双按钮；底部 **SSH 指纹行**（mono 2px 圆角代码条，指纹段染青）。
- **服务状态区**：六张黑卡（`.10` 边）——mono 服务名小标 + 青色辉光状态点（warn 用海洋蓝）+ 20px/500 标题 + 60% 白描述 + mono 元数据行（uptime/磁盘/实体数）。
- **终端预览卡**：JetBrains Mono 14px/-0.28px，`$` 提示符染青、注释 35% 白、warn 行注释灰——`homecloud status --all` 的真实感输出。
- **大字品牌区**：`HOMECLOUD` 超大 0.87 行高词标（品牌宣言式分区）。
- **页脚**：`.06` 顶线四栏，mono 栏题，链接 hover 青。
- **交互**：登录按钮「connecting… → ✓ 已接入 home.lan」模拟反馈。
- **响应式**：1024 hero 单列、登录卡限宽、服务两列；768 导航折叠、服务单列；480 按钮全宽；375 显式处理（标题 30px、硬阴影减为 3px）。

## 三、有意偏离点及理由

1. **主题改选**：建议主题撞密邮页，改为「自托管家庭服务器控制台」；login/dev-tool 采纳。
2. **字体替换**：abcDiatype（商业）→ Google Fonts **Space Grotesk**（几何精确的 sans，400/500 档）；JetBrains Mono 直载；中文回退链按平台底线。
3. **中文 0.87 行高**：64px 中文在 0.87 行高下靠手动换行控制（三行独立），笔画不粘连；375px 放宽至 1.0。
4. **钴蓝只进渐变**：严格遵循"钴蓝不做文字色"——hero 背景径向（35% 透明度）为其唯一出场。
5. 无其他偏离：白雾五档边框、硬偏移签名阴影、青 12% 上限背景态、mono 大写纪律、近方角 2/4px、三层退隐白文本均逐项取自 DESIGN.md。
