# 设计笔记：EMBER 夜间白噪音电台

## 一、自创设计语言声明（Ink & Ember 墨与烬 v1）

本页面为 original 模式，不继承任何种子/派生风格，以下 tokens 为本次原创的完整设计语言：

**核心理念**：一张被炉火照亮的旧报纸。编辑排版的骨架（衬线巨字、分栏、边框）注入篝火的温度（烬火橙）与手工的顽皮（贴纸、斜角、硬投影）。整体气质：安静但不冷淡，复古但不怀旧。

| 类别 | Token | 取值 | 角色 |
|---|---|---|---|
| 底色 | `--paper` | `#f6efe2` | 奶油纸底，全站画布 |
| 底色 | `--paper-deep` | `#efe5d1` | 深一度的纸，特性行分区 |
| 墨色 | `--ink` | `#221b12` | 焦墨：标题、正文、边框 |
| 墨色 | `--ink-60` | `#6f6250` | 淡墨次级文本 |
| 墨色 | `--ink-25` | `#c9bda8` | 极淡墨分隔线 |
| 强调 | `--ember` | `#f4481e` | 烬火橙——全站唯一彩色，只给"热"的东西（火焰、行动、直播灯） |
| 强调 | `--ember-deep` | `#c93512` | 烬火按压态 |
| 边框 | `--rule` | `2px solid var(--ink)` | 粗墨线是结构语言，全站统一 2px |
| 阴影 | `--shadow-hard` | `5px 5px 0 var(--ink)` | 硬偏移投影，无模糊——印刷品的错觉 |
| 字体 | `--serif` | Fraunces（Georgia/宋体回退） | 展示字体：标题、数字、节目名，斜体为强调 |
| 字体 | `--sans` | Inter（系统回退） | 正文与 UI |
| 组件 | sticker | 2px 墨边 + 硬投影 + rotate(-2.5°) | 贴纸式徽章——手工顽皮感的来源 |
| 动效 | waveform | 高度 18%↔92% 呼吸动画 | 声音的可视化，每三根染一根烬火橙 |
| 动效 | marquee | 26s 无限横向滚动 | 播音节目条——"电台"隐喻的仪式感 |
| 纹理 | 点阵纸面 | `radial-gradient` 22px 网格 | 英雄区的旧纸颗粒 |
| 排版 | 巨衬线 | clamp(48px, 6.5vw, 84px) / 行高 1.02 | 报头式标题，斜体 + 烬火橙做词级强调 |

**Do's**：2px 墨线贯穿一切结构；彩色只允许烬火橙；标题永远衬线、正文永远无衬线；徽章永远微斜。
**Don'ts**：不用模糊阴影（破坏印刷感）；不用第二强调色（火焰只有一种温度）；圆角不超过 2px（火柴盒没有圆角）。

## 二、本页面如何应用

- **英雄区**：点阵纸面背景上，84px 衬线"把夜熬成声音"（"声音"斜体烬火橙），直播机卡片整体 rotate(1.2°) + 硬投影，像一个随手放在版面上的收音机。
- **直播机**：LIVE 红点脉冲 + 24 根呼吸波形条（每 3 根 1 根橙色）+ 频道时刻表，把"电台"的产品隐喻做成视觉主体。
- **跑马灯**：焦墨底反白节目条，`<b>` 标签的关键词染烬火橙，无限横向滚动制造"正在播出"的临场感。
- **场景章节**：章节序号用 88px 描边空心衬线数字（`-webkit-text-stroke`），三张场景卡各用纯 CSS 绘制封面画（雨纹渐变+灯箱 / 径向台灯光晕 / 三角火焰+drop-shadow 辉光）。
- **特性行**：`--paper-deep` 分区 + 左墨线分栏，标题延续"衬线+橙色斜体词"的强调公式。
- **页脚**：焦墨反转（墨底纸字），链接 hover 变烬火橙——火焰在黑暗里更亮。

## 三、有意偏离点及理由

original 模式无源风格可偏离。两处自主说明：

1. **字体选择**：Fraunces（Google Fonts 可变衬线，自带 opsz 光学尺寸）+ Inter 均为 CDN 字体且含系统回退，符合平台技术底线；选 Fraunces 是因为它的高对比度字形与"旧报纸"理念一致，且免费可复现。
2. **动画克制**：全站动画仅三种（脉冲、波形、跑马灯），均为"声音的隐喻"服务；未加滚动渐入等装饰性动效，避免偏离"纸面"的静态印刷气质。
