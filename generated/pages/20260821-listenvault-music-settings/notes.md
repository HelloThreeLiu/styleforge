## 二、本页面如何应用

- **导航**：森林黑 blur sticky；绿色叶片 logo（`border-radius: 50% 0 50% 50%` 旋转 45°）+ mono 宽字距小注；链接白 hover 蓝；**功能绿药丸 CTA**「导入音乐」（hover scale 1.1 / active scale 0.85）。
- **暗色页头（hero 模式）**：mono 宽字距绿标签 `SETTINGS · V4.2 · LOCAL-FIRST` → **衬线 64px/400/1.2**「你的音乐库，是一座只属于你的档案馆。」（"只属于你"染绿——本区的霓虹绿一次）→ 20px 白青副文 → 深青状态药丸（绿点 + 库存读数）。
- **白色内容区（双模式转换）**：230px 粘性侧栏（激活项左 3px 功能绿条 + 6% 绿底 + scrollspy）+ 五个设置分区；每分区 = mono 绿编号标签 → 36px/500 区题 → 300 轻字重描述 → **16px 圆角白卡**（`#b8c4c2` 银边 + **森林染色双层阴影**）。
- **设置行套件**：标签（16px/500 + 14px/300 灰说明）左、控件右；行内代码 `composer` 用蓝底 mono；toggle（20px 圆角轨道，开 = 功能绿）；分段选择器（激活功能绿底白字）；mono 路径输入（focus 绿边）。
- **重建索引**：`#3d4f58` 描边卡 + 深青药丸按钮（hover 亮青 translateX 5px）+ 两步确认（3 秒复位）。
- **保存条**：绿药丸 + 「✓ 已保存到本地」淡出反馈。
- **暗色统计区（feature 模式）**：mono 绿标签 + **绿下划线签名标题**（2px 底边）+ 三张 24px 圆角深青大卡（衬线 56px 数字 + 300 灰说明）。
- **页脚**：森林黑 + `#3d4f58` 顶线；mono 2.5px 宽字距栏题；链接 hover 蓝。
- **响应式**：1024 侧栏转顶部横滚药丸 chip；768 导航折叠、设置行堆叠、统计单列；425 按钮全宽、页脚单列；375 显式处理（hero 34px、统计数字 44px）。

## 三、有意偏离点及理由

1. **字体替换**：MongoDB Value Serif（专有）→ Google Fonts **Fraunces**（编辑衬线、有机字形，最接近 Value Serif 的机构感）；Euclid Circular A（专有）→ **DM Sans**（几何圆无衬线，300–700 档齐全，含 300 轻字重默认）；Source Code Pro 直载。中文回退链按平台底线追加（衬线位回退 Songti SC）。
2. **霓虹绿密度**：全页绿共四处——页头标签、hero 染色词、统计区标签、下划线（各属不同 section，每区一次）；toggle 用功能绿而非霓虹绿（霓虹绿不做大面积轨道），在此声明取舍。
3. **危险区无红**：DESIGN.md 语义色仅蓝/绿；"重建索引"以 teal 灰描边卡 + 深青按钮替代红色警示，遵循"严格冷色（teal/green/blue）"的 Don't 条款。
4. **中文衬线渲染**：标题为中文时 Fraunces 不生效（回退 Songti/宋体系），衬线感由中文宋体承担，字形气质与 Value Serif 的编辑感方向一致；在此声明。
5. 无其他偏离：森林黑双模式、功能绿药丸物理缩放、深青按钮亮青横移、mono 宽字距字段标签、森林染色阴影、300 轻字重正文、16/24px 圆角阶梯均逐项取自 DESIGN.md。
