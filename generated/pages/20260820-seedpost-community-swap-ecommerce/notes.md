## 二、本页面如何应用

- **导航**：白底 + 粉紫蓝 conic 圆点 logo；「种子架」药丸激活；右侧"我的豆子 · 12"+ 深色 8px CTA"寄出种子"。
- **英雄区**：Outfit `clamp(38→80px)`/500/lh1.10"把阳台的收成 / 寄给下一户人家"；蓝徽章"秋播交换窗口"；**筛选药丸分段**（全部/茄果/豆类/叶菜/花草）真实过滤种子架。
- **种子架**：六张白卡 20px 圆角；**种子袋为纯 CSS 内容图**（纸袋 + 科属色带 + radial 种粒点阵——色彩由"产品"供给）；精选「外婆的酸浆番茄」完整三件套（渐变 + 紫辉光 + 深色徽章 + 白 CTA），桌面置顶；价格全部以 **豆子计价**（`1–3 豆/包`，豆粒为 CSS 圆点）——e-commerce 的去商品化处理。
- **以豆换豆**：三步卡（Poppins 步名 + 蓝色数字圆）；**豆子账本**用 Roboto tabular-nums（寄入/换出/流通豆，盈余染功能蓝）——数据语境交给 Roboto 的纪律落点。
- **种植者说**：三张 16px 卡 + 渐变头像圆；文案强调社区叙事（"有种子的地方，就没有真正的告别"）。
- **终章 CTA**：渐变大卡 24px 圆角 + 紫辉光（精选卡待遇），白底按钮。
- **页脚**：`#181e25` 四栏 + "豆子是唯一的货币，收成是最好的利息"。
- **响应式**：1024 起货架/步骤/证言单列（精选置顶）；768 起导航折叠、账本容器内横滚、页脚两栏；480：英雄 38px、筛选换行居中、CTA 全宽 ≥44px、页脚单列；375px 展示 38px（≥30px 底线），无横向滚动。

## 三、有意偏离点及理由

1. **风格自选说明**：round 计划连续第二轮只抽 1 个风格；按零追问原则自选补足。选 pastel-gallery-v1 的原因——★4 血统、首次回学（继 ink-ember-v1 之后第二份沉淀文档的可复现性实测）、与 spacex 页类型/行业/主题互不雷同（e-commerce 为近 8 页唯一空余类型）。
2. **e-commerce 的非商品化处理**：按 §11 题材纪律，"商店"被处理为以豆换豆的社区交换（无货币价格、账本为流通记录），规避商品展示套路。
3. **种子袋色带**：科属色（茄红/豆绿/叶青/花粉）属产品内容色（"色彩只来自产品卡"的许可范围），界面色板保持白/深/蓝纪律。
4. 无其他偏离：精选三件套、双轨按钮、四字体分工、药丸筛选联动、≤0.16 阴影、深页脚均逐项取自 pastel-gallery-v1/DESIGN.md。
