## 二、本页面如何应用

- **导航**：奶油 sticky + blur + 沙色底线；橙色方块叠奶油横条 logo（榫卯的"咬合"隐喻）；链接 16px/500 hover 加下划线（Zapier 的反向下划线模式：默认无、hover 有）；右侧橙按钮。
- **登录区（双栏 hero）**：左叙事——大写 kicker → 56px/500/**行高 0.90** Degular 风格标题「把重复的事，交给榫卯。」（"榫卯"染橙）→ **GT Alpina 位**（细衬线 40px/300/-1.6px「两块木头咬合，不用一根钉子。」）→ 20px 副文 → 三个 48px/500 统计数字。右登录卡（`#fffdf9` + 沙边 5px）：邮箱/密码输入（focus 橙边）、记住设备 + 忘记密码行、**橙主按钮**（8px 16px/4px）、"或"分隔线（沙色细线）、**深色大 SSO 按钮**（20px 24px/8px）。
- **连接区**：区标「01 / Connect」→ **签名 Tab**（透明底 + inset 下划线：橙=激活、沙=hover，水平横滚）→ 面板切换（热门连接 6 张 / 本周新上架 3 张）——集成对卡（色块 app 图标 + 箭头 + 名称 + 触发说明 + 运行次数大写微标）。
- **编辑体块**：GT Alpina 位 48px/300/-1.92px 细衬线大字（斜体强调染橙）+ 右侧三段正文——"自托管一等公民"的社区叙事。
- **页脚**：`#201515` 满宽反白四栏；链接 `#c5c0b1` hover 白；**14px 圆角社交圆钮**（沙边圆块 hover 沙底黑字）。
- **交互**：tab 双面板切换；密码显隐按钮；登录按钮「正在连接… → ✓ 欢迎回来」模拟反馈（1.8s 复位）。
- **响应式**：1280 收容器；991 登录区/编辑区单列、集成卡 2 列；768 导航折叠（CTA 隐藏）；600 统计数字缩至 36px；450 集成卡单列、按钮全宽、卡片减 padding；375 显式处理（标题 34px、编辑体字距收至 -0.8px）。

## 三、有意偏离点及理由

1. **主题自行改选**：建议主题「加密邮箱客户端」与密邮页（同类型同行业同主题）撞车，改为「开源自动化工作流引擎」；login/dev-tool 采纳建议。
2. **字体替换**：Degular Display（Klim 商业字体）→ Google Fonts **Bricolage Grotesque**（宽体几何、500/600 字重，最接近其宽扁气质）；GT Alpina（Klim 商业字体）→ **Cormorant**（300 细衬线 + 负字距，保留编辑体的纤细优雅）；Inter 直载。三字体角色分工严格照文档执行。
3. **中文行高 0.90**：Degular 的 0.90 压缩行高用于中文标题会导致笔画重叠，标题为中文时以 0.90 配 56px 大字号 + 手动换行控制（每行独立），实测可保持压缩块观感；编辑体中文 -1.92px 收窄至 -0.8px~-1.6px 分档应用。
4. **app 图标**：集成卡的应用图标以品牌色圆角方块 + 首字/单字绘制（CSS 实现，无外部图片）；色值取自各应用的通用品牌色，属内容数据而非 UI token。
5. 无其他偏离：奶油画布、暖近黑文本、沙色边框结构、零卡阴影、inset 下划线 tab、橙唯一强调、按钮 padding 体系、深色页脚反转均逐项取自 DESIGN.md。
