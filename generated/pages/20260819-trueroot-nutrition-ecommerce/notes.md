## 二、本页面如何应用

- **公告条 + 导航**：蓝底公告条（下划线链接）；吸顶白导航 + `#e0e2e6` 底线；logo 用 900 字重 + 蓝点；导航项 hover 浅表面药丸（12px 圆角延伸到交互件）；右侧浅底搜索框、幽灵"登录"与蓝底"购物车 · 2"。
- **英雄区**：48px 双声部标题——首行 400 常规、次行 **900 重音**（Airtable 的 Display Bold 层级）；18px/0.18px 副文；蓝白双 CTA（16px 24px/12px 圆角）；三枚 ✓ 前缀信任点（成功绿）。右侧静物：32px 圆角浅表面容器 + 三只纯 CSS 药罐（暗色瓶盖 + 白标签带）+ CSS 叶形 + 批次徽章，全部只允许柔环境影与蓝调阴影。
- **分类瓦片**：`#f8fafc` 底 24px 圆角四联，图标全为几何 CSS（双色胶囊/同心圆片/菌群双圆/旋转叶），hover 蓝调阴影上浮。
- **商品网格**：`1px #e0e2e6` 边框 24px 圆角产品卡；罐体艺术复用英雄区 jar 组件（换渐变即换 SKU）；卡题 20px/0.12px 正字距；hover 蓝调多层阴影 + 3px 上浮；"加入购物车"用小号蓝 CTA。
- **溯源横幅（对源风格的致敬）**：浅表面 24px 圆角分栏，右侧做了一张 **Airtable 式数据表卡**——表头 12px/0.28px 大写、行分隔 `#e0e2e6`、判定列成功绿 ✓——把"品牌即数据库"的气质翻译成电商语境的批次报告。
- **订阅制 / 证言 / 邮件**：边框卡 + 蓝色数字圆步骤；32px 400 字重证言（引用人 0.28px 字距）；浅底输入框 focus 变蓝 + 12px 圆角按钮。
- **响应式**：1024 起商品/分类 2 列；768 起导航折叠、搜索隐藏、英雄单列、横幅单栏、邮件表单纵向；480 起商品单列、CTA 全宽（≥44px 触控）、页脚单列；375px 下英雄标题 34px（≥30px 底线）。

## 三、有意偏离点及理由

1. **字体替换**：Haas / Haas Groot Disp 为私有字体，以 Inter（400/500/700/900 完整对应其字重体系）替代；正字距体系（0.07–0.28px）逐级照搬。
2. **成功绿的使用范围**：DESIGN.md 仅标注 `--theme_success-text`；本页将其用于检测判定与信任点 ✓——属语义化延伸（正向判定场景），未做装饰使用。
3. **导航搜索框**：词表未给搜索框规格，按"标准 Haas 输入 + 组件圆角 12px + 浅表面底"组合推导，与按钮体系统一。
4. 无其他偏离：色板、12px 圆角 CTA、16–24px 卡片、蓝调多层阴影、正字距、48px 双声部标题均逐项取自 DESIGN.md。
