## 二、本页面如何应用

- **导航**：白底 blur sticky；紫色主按钮「下载数据」+ ghost「API 文档」。
- **Hero**：徽章行（成功徽章「第 9 年公开 · 无保留审计意见」+ 中性徽章）→ 48px/300/-0.96px「每一笔善意，都经得起翻账。」→ 18px slate 副文 → 搜索框（focus 紫边 + 3% 紫光环）。
- **统计卡 ×4**：蓝调多层阴影 + tnum（¥2,847,116 年度收入 / 94.6% 拨付率 / 2.1% 管理费 / 137 项目）——Stripe 金融面板语言的公益转译。
- **两栏文档**：200px 粘性侧栏（激活紫左条 + 5% 紫底 + scrollspy）+ 内容三节：
  - **流向记录**：年度分段器（2026/2025/2024，**JS 重写整表并实时重算本页合计**）+ 表格（日期 tnum / 项目+凭证编号小字 / 类别 / 金额 / 状态徽章）+ 搜索过滤 + 空态；行 hover 3% 紫底。
  - **记账规则**：四条 R-01~R-04 编号规则行（mono 紫编号 + 500 标题 + 300 正文）。
  - **代码卡**：`curl` API 示例（Source Code Pro / 行高 2.0 / 键紫字符串绿）+ 顶栏绿色 200 OK。
- **深靛蓝开放数据区**：`#1c1e54` + 32px/300/-0.64px 白标题「信任不该依赖信任本身。」+ 三张 10% 白边卡（REST API / CSV 快照 / 审计报告，各带 mono 端点行）。
- **页脚**：白底四栏 + mono 版本行。
- **响应式**：992 侧栏转横滚 chip、统计两列、API 卡单列；768 导航折叠、表格容器内横滚；480 统计单列、按钮全宽；375 显式处理（标题 30px、字距 -0.6px、统计数字 24px）。
