## 二、本页面如何应用

- **导航**：`#121212` 底 + blur + `#232323` 底线；conic 唱纹小圆盘 logo + 大写字标 `BSIDES` + 灰色中文小注；链接灰 700 hover 白；绿底黑字药丸「订阅」。
- **Hero（左文右盘 1.2fr:1fr）**：绿徽章（2px 圆角 + 12% 绿底 + 35% 绿边）→ 64px/700/1.08/-0.02em 大标题，「B 面」染绿（唯一染绿词，呼应收听行动语义）→ 灰副文 → 绿底黑字「▶ 收听最新一期」+ 描边钮「浏览全部口述」；右侧 **24s 旋转唱片**（conic 唱纹 + 橙红紫三停中心 label + L3 重阴影 + inset 暗角）。
- **口述档案（专辑网格 4 列）**：每期=一家唱片店：封面三停撞色渐变（橙红紫/青绿金/粉紫/绿橙各一套）+ 底部 45% 黑压暗 + 白色 EP 角标；卡 hover `#282828` 并右下浮现 **44px 绿色圆形播放键**。
- **第 042 期 tracklist**：`#181818` 容器 + 表头灰底线；七章节（序号 hover 绿、标题 700 + 讲述人 12px 灰、关键词列、时长 tabular 右对齐、行 hover 3% 白）。
- **订阅绿黑渐变盒**：绿色唯一大面积形态，邮箱药丸（focus 绿边）+ 绿底黑字按钮 +「✓ 已订阅」反馈。
- **页脚**：4 栏 + `#232323` 细分隔线，链接灰 hover 白。
- **正在播放条（签名组件）**：fixed 76px 三段式——左 46px 封面缩略 + 曲目信息（省略号截断）；中 36px 白圆播放键（hover 绿）+ 4px 进度条（已播白 hover 绿，可点击跳转）+ 双向时间 tabular；右「HQ 口述档案」绿字 + 许可状态。JS 实现播放/暂停切换与每秒推进，专辑卡的浮现播放键会拉起并自动开始播放。
