## 二、本页面如何应用

- **顶栏**：白底 + 沙色底线；红色圆 logo「拾」；**居中搜索框**（16px 圆角 + 暖银边）做成真实功能——按词集名过滤瀑布流；右侧暖光圆形动作钮（通知数/头像）+ 红底黑字"创建词集"。
- **页头**：28px/700/-1.2px 标题"早上好，陆拾词。"（负字距签名）+ 12px 橄榄灰副题 + 右侧学习天数说明。
- **瀑布流仪表盘（签名布局的仪表盘化）**：`column-count: 3` + `break-inside: avoid`，九张高度不齐的卡片自然错落：
  - **今日复习**：44px 大数字 + 红色进度条 + **可点击翻转的 3D 闪卡**（正面沙灰底词面 / 背面梅紫黑底释义，rotateY 翻转）+ 红底黑字 CTA——红色唯一的大胆时刻。
  - **连续打卡**：24 天 + 七日圆点行（命中绿 700，今日红描边）。
  - **词集卡 ×4**：暖调渐变封面（沙/淡紫灰/米/灰绿——均为暖中性系）+ **conic-gradient 进度环**（红环 + 白边悬浮）+ 12px 统计行 + 沙灰按钮。
  - **记忆曲线**：七根绿 700 保持率柱（D1→D60 递增——间隔重复的叙事）。
  - **智能推荐**：推荐紫 8% 底标签（AI 推荐语义色）+ 三个条目带暖光圆形"+"钮（点击变 ✓）。
  - **本周成就**：圆形徽章（红/绿/暖光三枚）。
- **页脚**：`#33332e` 深色单行式，暖银链接 hover 白。
- **响应式**：1024 起瀑布流两列；768 起搜索隐藏、瀑布流单列（卡片全宽）；480：标题 24px/-0.8px、圆形钮收窄；375px 下所有按钮 ≥44px 触控，页面无横向滚动。

## 三、有意偏离点及理由

1. **字体**：Pin Sans 为私有字体，按文档回退栈直接使用系统字体（含 PingFang SC/Microsoft YaHei）——**零外部字体请求**；紧凑字阶（12/14/16/28/44px）与 400/600/700 字重纪律照搬。
2. **封面渐变代替摄影**：平台禁外部图片；词集封面用四组**暖中性渐变**（沙/紫灰/米/灰绿）承担"摄影即内容"的角色，未引入冷调新色。
3. **瀑布流以 CSS columns 实现**：词表未给仪表盘化规格；以 `column-count + break-inside` 还原 masonry 的错落密度，卡片高度天然不齐。
4. **进度环用 conic-gradient**：词表无环组件规格；红环 + 白边 + 12px 字的组合未超出圆角与配色纪律。
5. 无其他偏离：暖中性三表面、红底黑字 CTA、16px 圆角双件（按钮/输入）、近零阴影、深色页脚均逐项取自 DESIGN.md。
