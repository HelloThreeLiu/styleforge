## 二、本页面如何应用

- **布局**：桌面双栏——左侧品牌陈述（48px/700 标题"你的邮箱，只属于你。"，"你"染绿——绿色唯一装饰性让步且承担行动语义），右侧登录卡；移动端单栏隐藏封面行。
- **左侧**：绿色圆 logo「密」；**专辑式信封封面**（深绿渐变 + 绿描边信封折线 + 发光锁孔——封面艺术即色彩源）；**安全特性做成 tracklist**（`#` 序号 hover 变绿、标题 700 + 银色副题、右对齐"✓ 状态"数据列）——把产品卖点翻译为播放清单。
- **登录卡**：`#181818` 卡 + 重阴影；输入框用文档**签名的 inset 边框组合**（focus 内描边变白）；"显示密码"按钮 hover `#282828`；记住设备勾选用 `#1db954`；找回密钥链接银色 hover 白。
- **按钮**：主 CTA 绿底黑字全药丸大写字标"登 录"（hover 放大 + 提亮）；`#4d4d4d` 分隔线"或"；两条深色药丸（硬件密钥 / 本地密钥库）。
- **底部安全状态条**：Now Playing 的安全化——左段"会话密钥"（46px 封面缩略 + 溢出省略），中段**五根绿色均衡条**动画标注 AES-256-GCM，右段 TLS 1.3 + 绿色"● 连接已加密"；移动端隐藏中段（可精简不可删除）。
- **交互**：显示/隐藏密码真实切换；登录按钮两段反馈（"正在解密本地密钥库…" → "✓ 欢迎回来，{用户名}"）。
- **响应式**：768 起单栏、tracklist 隐藏状态列、状态条两段式；480：标题 32px、按钮 52px 高（触控≥44px）；375px 无横向滚动。

## 三、有意偏离点及理由

1. **同风格二次学习**：与 08-18 声游记（blog/travel）相比类型（login）、行业（dev-tool）、主题完全不同；DESIGN.md 全文于本会话通读。
2. **字体**：SpotifyMixUI 私有，以 Inter（400/600/700）替代，字重二进制纪律保留。
3. **图标字符**：硬件密钥按钮的 🔑/🗂 为系统 emoji 字符（文档回退栈含 Apple Color Emoji 类回退），非外部资源；保持按钮药丸语法。
4. **绿色在"均衡条/锁孔辉光"的使用**：属于加密状态的功能可视化（信号即绿），与播放/激活语义同构，非装饰填充。
5. 无其他偏离：三层炭黑、inset 输入框签名、大写字标绿 CTA、tracklist 语法、Now Playing 条均逐项取自 DESIGN.md。
