## 二、本页面如何应用

- **导航**：`#08090a` 透明 blur 底 + `.05` 白底线；渐变靛蓝方块 logo + 590 字重名 + 四级灰版本号；链接 13px/510 hover 提亮；右侧**按钮式输入**命令面板触发器（⌘K kbd 徽标）+ ghost 按钮。
- **页头**：面包屑 → 48px/510/-1.056px「设置」→ 18px/400 三级灰副文 → 9999px 运行状态 pill（emerald 状态点 + mono 显存数据）。
- **布局**：210px 粘性设置导航（激活项 `.02` 白底 + 左侧 3px 靛蓝条 + scrollspy）+ 右侧六个分区。
- **通用区**：原生 select 定制为 ghost 下拉；三段外观选择器（`.02` 底 + 激活 `.05` + 1px 黑环）；恢复会话 toggle（开=靛蓝轨道）。
- **模型区**：三张模型选择卡（`.02` 白底 + `.08` 描边 + 选中靛蓝描边与圆点）+ 上下文/温度滑块（`accent-color: #5e6ad2`，mono 数值实时刷新）。
- **性能区**：显存占用卡（6px 靛蓝进度条 + mono 标注 + 足迹说明）+ 量化/并加分段器。
- **隐私区**：遥测 toggle 默认关 + 保留期分段——"没有账号体系"的文案反差。
- **快捷键表**：行式表格 + `kbd` mono 徽标（`.05` 白底 + `.05` 描边 + 4px）。
- **危险区**：红 30% 描边 + 3% 红底卡，两步确认（3 秒复位）。
- **保存条**：右下角浮层——靛蓝主按钮 + emerald「✓ 已保存」1.6s 淡出。
- **命令面板（签名组件）**：`#191a1b` + `.08` 白描边 + 12px 圆角 + 五层级联阴影 + 85% 黑遮罩；⌘K/Ctrl+K 开启、Esc 关闭、实时过滤、↑↓ 循环高亮、↵ 跳转分区。
- **响应式**：1280 收容器；992 侧栏转顶部横向滚动 tab；768 导航链接隐藏、设置行标签/控件上下堆叠；480 toggle 放大至 44px 触控、保存条全宽右对齐；375 显式处理（标题 30px≥底线）。

## 三、有意偏离点及理由

1. **类型保留、行业/主题改选**：settings 采纳建议；主题「漫画阅读器书架」与墨匣页（同类型同行业同主题，恰滑出 8 页窗口）撞车、且与同轮云窗页（entertainment）行业冲突，改选 ai/本地模型运行器。
2. **字体**：Inter Variable 从 Google Fonts 加载 `wght@300..900`，510/590 非标准字重直接可用；`"cv01","ss03"` 为 Inter 原生支持的 OpenType 特性，如实声明于 CSS——与文档要求完全一致，无偏离。Berkeley Mono 无公开 CDN，直接采用文档自带回退链（ui-monospace/SF Mono/Menlo），中文场景回退至系统黑体。
3. **中文负字距**：-1.056px/-0.24px 等文档值应用于中英混排标题（中文在 48px/20px 下可安全承受）；375px 显式收紧至 -0.6px。
4. **logo 渐变**：文档规定靛蓝不做装饰用途；logo 方块使用 `#5e6ad2→#7170ff` 的同色系渐变视为品牌标记（brand mark）而非 UI 装饰，属边界判断，在此显式声明。
5. 无其他偏离：三级亮度堆叠、半透明白描边、按钮微透明底、510 签名字重、命令面板五层阴影、成功绿仅状态、圆角阶梯均逐项取自 DESIGN.md。
