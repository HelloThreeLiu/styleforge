## 二、本页面如何应用

- **导航**：紫黑透明 + 玻璃 blur + 紫底线；荧光绿菱形 logo（带辉光，导航区的绿）；内凹紫按钮「预约观星」。
- **Hero**：环境辉光径向渐变之上 **5 枚呼吸星点**（`twinkle` 动画：透明度+缩放+辉光，绿=夜色中的光，本区的"一次"）→ 紫色 kicker（不用绿，避免与星点叠加）→ 88px「带你看一次真正的黑。」→ 白实心 CTA + 内凹紫按钮 → **玻璃计数卡 ×3**（9 年 / 214 个观星夜 / 3,100+ 同行者）。
- **星野手记（作品墙）**：6 张 CSS 绘制星空场景卡（银河拱桥斜渐变带+山影 / 流星尾迹线 / repeating-conic 星轨弧 / 月升辉光圆 / 黄道光锥 / M31 椭圆光斑），每张附等宽摄影参数行（14mm f/1.8 · 15s · ISO3200）——把"器材数据"作为等宽字体的自然落点；卡题圆点紫/粉/珊瑚逐卡分配。
- **观测记录卡**：YAML 观星夜记录（站点/限星等/视宁度/目标清单/团组），语法高亮关键字=荧光绿（本区的"一次"）、字符串=代码黄、注释=半透明白；顶栏 `● log #212` 绿点状态行。
- **团期行式清单**：日期（展示字体 22px/700）+ 团名集合点 + 状态徽章（绿边「余 4 席/报名开放」、紫边「已成团」、灰边「候补中」）——行式而非卡网格。
- **终章**：「黑，是要留给孩子的一种自然资源。」+ 白实心 CTA + 暗夜保护基金叙事。
- **页脚**：`#150f23` 深区四栏，栏题紫、链接 hover 紫。
- **响应式**：992 作品两列、玻璃卡单列；768 导航折叠、团期行收窄徽章换行、页脚两栏；480 作品单列、按钮全宽 ≥44px；375 显式处理（hero 38px、玻璃数字 26px）。

## 三、有意偏离点及理由

1. **风格自选说明**：计划仅抽到 1 个风格，自选 nightward-v1 补足（零追问原则）；portfolio/travel 为可用类型/行业中与最近 8 页及同轮页均无冲突的组合。
2. **绿的使用密度**：hero 区绿=星点动画（内容主体，类比源页萤火幕）；kicker 特意用紫、logo 绿归导航区——比源页更严格地执行"每区至多一次"。
3. **星野场景的纯 CSS 绘制**：DESIGN.md 未定义图像语法；6 种场景全部以渐变/clip-path/repeating-conic 合成（无外部图片），山影统一 `#0a0614`（比深夜紫更深一档的页面内派生值，用于场景内剪影，不参与 UI 层级），在此显式声明。
4. **作品卡网格**：DESIGN.md「活动/场次用行式清单」指事件类内容；摄影作品墙属图像陈列，采用卡网格（与"卡片网格"禁令不冲突，该条仅约束事件清单）。
5. **荧光绿场景缺席**：黄道光场景使用暖黄（`#ffdFA0` 系）而非绿色气辉，主动避免绿色在作品场景中扩散，维持绿的稀缺性。
6. 无其他偏离：双色紫底、紫调边框、内凹按钮、玻璃卡、环境辉光、字体三役、低字重区题、圆点标题、行式团期、YAML 记录卡均逐项取自 nightward-v1 DESIGN.md。
