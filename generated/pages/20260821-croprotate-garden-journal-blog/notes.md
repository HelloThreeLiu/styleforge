## 三、有意偏离点及理由

1. **字体替换**：Cal Sans（Mark Davis 开源字体，不在 Google Fonts）→ **Sora**（几何展示体、600 档与紧字距气质最接近）；Inter / Roboto Mono 直载；中文回退链按平台底线。Cal Sans ≤24px 需 +0.2px 正字距的规则在本页通过"小字全部交给 Inter"规避（展示体只用于 ≥20px 标题）。
2. **中文 600 紧字距**：64px 中文标题以默认字距渲染（中文无 Cal Sans 式内建紧排，强加负字距会损伤可读性）；行高 1.10 纪律保留。
3. **CSS border 全禁**：严格遵循"ring 阴影替代 border"——全页分隔线、卡片、状态药丸、页脚顶线均用 box-shadow ring 实现，零 `border:` 声明（表单 focus 用 outline 蓝环）。
4. **产品 UI 卡替代**：文档"产品截图是主视觉"，本页以自绘"菜畦面板"卡（作物行 + mono 天数 + 状态药丸）作为产品 UI 等价物，纯 CSS 无外部图片。
5. 无其他偏离：灰阶纪律、三层阴影体系、inset 高光/凹陷、深主按钮 0.7 透明度 hover、药丸几何、80px+ 区距均逐项取自 DESIGN.md。
