## 二、本页面如何应用

- **导航**：吸顶黑底 + 药丸导航（活动项 `#1f1f1f` 底 + 700 字重，非活动 `#b3b3b3`）+ 右侧描边"登 录"与绿底大写"免费注册"。
- **英雄区**：64px/700 大标题（"专辑"一词染绿——绿色唯一装饰性让步，承担 CTA 语义引导）；右侧纯 CSS 黑胶唱片（conic-gradient + 24s 旋转动画 + 重阴影）承担"专辑艺术即色彩源"的角色。
- **城市专辑网格**：`#181818` 卡 + 6px 圆角封面 + hover 微亮 `#282828`；hover 时绿色圆形播放键浮现（50% 圆角 + 中阴影）——Spotify 标志性交互。封面全部用 CSS 渐变绘制，践行"无外部图片"底线。
- **田野笔记列表**：完全采用 tracklist 语法——`#` 序号 / 标题+副标题 / 播放量（tabular-nums）/ 时长；hover 行背景微亮且序号变绿。
- **底部正在播放条**：全宽固定 `#181818` 条，三段式布局（曲目信息 / 圆形控制键组 + 进度条 / 音质），进度已播段默认白色、hover 变绿——绿色始终功能性。
- **响应式**：768px 起：导航折叠、专辑两列、tracklist 隐藏播放量列、播放条精简为单行；480px：专辑保持两列、页脚单列、次级按钮隐藏。触控目标（播放键 44px）≥ 44px。

## 三、有意偏离点及理由

1. **英雄区标题字号**：DESIGN.md 的层级表最大为 24px（Section Title，播放器语境）。本页将英雄标题放大至 clamp(40–64px)/700 以符合"博客首页"的落地语境——字族、字重、行高风格（紧凑、负字距）均沿用，仅外推尺寸，在此显式声明。
2. **绿底按钮文字用黑色**：DESIGN.md 未规定绿底按钮的文字色（绿色仅列了用途）。参照 Spotify 实际惯例用黑字保证对比度（绿底白字对比度不足 3:1）。
3. **字体**：SpotifyMixUI/CircularSp 为私有钱夹字体，按平台底线以 Inter（400/600/700 对齐其字重体系）替代，字体栈首位保留原声明。
4. 无其他偏离：色板、圆角体系、阴影、字重策略、tracklist 与播放条模式均逐项取自 DESIGN.md。
