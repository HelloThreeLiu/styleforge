## 二、本页面如何应用

- **导航玻璃**：48px 半透明黑 + `saturate(180%) blur(20px)`；12px 白链接 hover 下划线——压在黑白两幕之上恒定不变。
- **暗幕 Hero（第一幕）**：17px kicker（演出季信息）→ 56px/600/1.07/-0.28px「整季九场，一次坐进音乐里。」→ 21px/1.19 副题 → **蓝实心 8px 按钮 + 白描边 980px 药丸**双 CTA → 12px 免责小注（学生半价/分期）。
- **亮幕档位（信息幕）**：40px/600 区题 + 三张 12px 圆角白卡（**唯一软阴影** 3px 5px 30px）：21px/700 档名 + 14px 定位语 + 40px/600 价格 + 12px 均价小注 + 权益行列表（6% 黑分隔线）+ 墨色实心按钮（主档用蓝）+ 12px 余票小注。
- **暗幕演出季（产品磁贴）**：`#272729` 暗卡 12px 圆角 ×6——12px 场次序号 + 28px/400/0.196px 曲目名 + 65% 白指挥信息 + 亮蓝链接（暗底链接色）。

## 三、有意偏离点及理由

1. **风格与类型自选说明**：计划抽取缺额（0 个），自选随机结果 apple；类型仅剩 pricing/e-commerce，取 pricing/entertainment。
2. **字体**：SF Pro 为苹果专有，直接采用文档自带回退栈（Helvetica Neue/Arial + 中文系统体）——零 CDN 的官方路径；SF Pro Display/Text 光学位移以"20px 上下分界使用同一栈"近似（字重与字距纪律照文档执行）。
3. **中文负字距**：-0.28/-0.374px 文档值用于中英混排（56px/17px 中文可承受）；375px 标题 34px 时停止收紧。
4. **产品摄影替代**：文档"产品为英雄"；演出季的"产品"= 曲目——暗幕磁贴以文字卡（曲目名即产品名）呈现，无外部图片，符合"对象在纯色场中"的原则。
5. **交互克制**：文档"卡片静态、链接交互"——档位按钮仅做「✓ 已加入购季单」轻反馈，无缩放/位移动画。
6. 无其他偏离：二元幕布节奏、唯一蓝、980px 药丸、导航玻璃、单软阴影、全字号负字距、左对齐正文均逐项取自 DESIGN.md。
