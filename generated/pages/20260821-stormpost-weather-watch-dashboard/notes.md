## 二、本页面如何应用

- **导航**：`#0b0b0b` blur + `#212121` 底线；红圈套蓝点 logo（风暴眼）；链接银 hover 电蓝；**珊瑚红药丸 CTA「上报观测」**（hover 变电蓝）。
- **页头**：状态药丸（霓虹绿在线点 + mono 同步时间）→ 48px/400/-1.68px「风暴前哨」→ 18px 银副文（"比预警短信早一步"）。
- **预警横幅**：`#212121` 底 + `#dd0000` 四边框与 4px 左粗条 + 纯红 mono 等级标签「YELLOW ALERT」+ ghost 按钮——仪表盘的第一眼警报层。
- **主体 board（2fr:1fr）**：
  - **站点监测表**：`#212121` 卡 + `#353535` 边 6px；mono 大写表头；行 = 站号 mono（行 hover 变电蓝）+ 位置白 + 读数银 + 状态药丸（绿 `#19d600` 10% 底/琥珀注意/纯红实底警报）；11px/600 大写标签按钮筛选（全部/警报/注意/正常）+ 搜索输入（**focus 蓝环 + 深青底 `#072227`**）。
  - **预警时间线**：56px mono 时间列 + 事件行，crit 事件标题染珊瑚红。
  - **24h 雨量图**：24 根 CSS 柱，三档色（灰干/电蓝湿/纯红强）——"电蓝=交互"在此作为数据色使用与纯红并置（数据可视化语境，非同组件按钮混色）。
  - **实时数据流**：mono 日志行（时间/站号/读数），JS 每 3 秒 prepend、超阈值读数染琥珀、上限 12 行滚动——"系统读数"美学的动态版。
- **联防网络区**：12px 圆角 feature 卡（认领气象站/校园哨兵/预警广播），mono 小标 + 24px/425 标题 + 底边线链接 hover 蓝。
- **页脚**：`#212121` 顶线四栏，13px mono 大写白栏题，链接银 hover 蓝。
- **响应式**：960 board 单列、联防卡单列；768 导航折叠、页脚两栏；480 页脚单列、搜索全宽；375 显式处理（标题 34px≥底线、卡 padding 收窄）。

## 三、有意偏离点及理由

1. **字体替换**：waldenburgNormal 为 Sanity 专有字体，按文档 §3 官方指定以 **Space Grotesk** 替代（"几何、微压缩感"）；IBM Plex Mono 直载；中文回退链按平台底线追加。OpenType 特性（cv01/cv11/ss07）为 waldenburg 专属字形集，Space Grotesk 无对应，声明不生效。
2. **中文负字距**：-1.68px/-1.14px/-0.24px 文档值应用于中英混排；375px 收至 -0.8px 防粘连。
3. **数据图电蓝使用**：雨量柱以电蓝表示"降雨档"，与文档"电蓝=交互色"的定义有语境差异——参照文档"卡片网格示例"中数据语境的自由度，视为数据可视化用法而非交互混用，在此显式声明。
4. **状态琥珀色 `#ffb224`**：文档灰阶未含"注意"级状态色（仅有绿/红二元）；新增一个琥珀作为黄警中间态，对应气象黄/橙/红三级预警的题材必需，色值未与品牌四色冲突，属内容必需的最小扩展。
5. 无其他偏离：近黑画布、无彩纪律、珊瑚红唯一 CTA、药丸/3–6px 圆角断层、色度深度、ring 焦点、mono 系统读数、区间距节奏均逐项取自 DESIGN.md。
