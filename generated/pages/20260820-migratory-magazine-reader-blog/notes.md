## 二、本页面如何应用

- **导航**：白底 + 粉紫蓝 conic 圆点 logo；「本期」药丸激活；深色 8px CTA"订阅纸刊"。
- **英雄区**：Outfit `clamp(38→80px)`/500/lh1.10"长文章，仍值得一个安静的夜晚"；蓝徽章"第 24 期"；**排序药丸分段**（编辑精选/最多共读/未读优先）——阅读器语境的分段控件。
- **本期封面（精选三件套）**：整卡 150° 渐变 + 紫辉光 + 深色徽章"本期封面"；左侧封面艺术为**纯 CSS 星点夜空 + 简笔候鸟**（双圆弧翅膀），色彩由"封面"供给；标题 Outfit 34px/600 + 摘要 15px/1.70 + 渐变头像与阅读时长（Roboto）。
- **本期深度**：六张白卡 20px 圆角（hover 上浮 + 抬升阴影）；分类药丸灰底；卡题 Outfit 22px/600/lh1.4；作者行 = 渐变头像圆 + DM Sans 名 + Roboto 字数/时长（"4,800 字"数据语境交 Roboto 的纪律落点）。
- **专栏作者**：16px 卡 + Poppins 角色行（"特稿部 · 夜行系列"——中段字体的分工）。
- **终章 CTA**：渐变大卡 24px + 紫辉光（精选卡待遇）+ 白底按钮。
- **页脚**：`#181e25` 四栏，"慢慢飞，慢慢读"。
- **响应式**：1024 起封面单栏（艺术区压缩）、文章/作者单列；768 起导航折叠、排序换行居中、页脚两栏；480：英雄 38px、CTA 全宽 ≥44px、页脚单列；375px 展示 38px（≥30px 底线）。

## 三、有意偏离点及理由

1. **同风格二次学习**：与回声岛（pricing/social）相比，本页类型（blog）、行业（media）、主题与结构完全不同；DESIGN.md 全文于本会话通读。
2. **排序分段无真实数据排序**：单文件静态页无后端，分段仅切换激活态；相比回声岛的计费切换（真实改写数值），此处交互深度受主题限制，在此说明。
3. **封面艺术**：平台禁外部图片，渐变卡内的"杂志封面"以 CSS 星点 + 简笔候鸟实现，颜色取自渐变卡同族深色。
4. 无其他偏离：白底纪律、渐变唯一色彩区、紫辉光、双轨按钮、四字体分工、1.50 行高、深页脚均逐项取自 DESIGN.md。
