## 二、本页面如何应用

- **导航**：奶油吸顶 + blur + 暖边；logo 为"书脊"记号（暖面方块 + 墨边 + 橙色书签条）；链接 hover 变暖绯红。
- **页头**：等宽眉题 `settings / 阅读偏好与书架`（橙色路径段）；36px/400/-0.02em 标题；衬线副文。
- **阅读方向与纸色卡**：三档翻页方向（日漫右→左 / 美漫左→右 / 条漫上下）与三档纸色（米纸/纯白/夜间墨色）均为药丸分段——**右侧是一张实时联动的 CSS 漫画预览页**：
  - 预览纸面接受三种纸色（米纸 `#fdfbf4` / 纯白 / 夜间墨色翻转为暖深底）；
  - 分格方向随翻页设置切换（`direction: rtl/ltr` + 条漫行流）；
  - 方向箭头（◀/▶）用品牌橙——橙色作为"导航信号"的最小存在；
  - 漫画语法全用 CSS 绘制：宽格金色太阳 + 对话气泡（伪元素小尾巴）、网点纸（`radial-gradient` 9px 网格）、集中线（`repeating-linear-gradient` 105°）、页码角标（等宽小字）。
- **书架管理卡**：分类标签药丸行（连载中/已完结/催更中/每年重读——"书架"主题的落点）+ 三条自动归档规则开关（暖面平面开关，开启态墨色）。
- **下载与缓存卡**：金色渐变计量条（2.1/8GB）+ Wi-Fi 开关 + 智能清理；保存行等宽元信息 + 暖面按钮（hover 变暖绯红，点击 ✓ 反馈）。
- **页脚**：等宽大写栏题 + 衬线品牌句 + 链接 hover 橙。
- **响应式**：768 起导航折叠、页脚两栏；480：标题 30px、卡片收紧、保存按钮全宽 ≥44px；375px 下展示 30px（恰守底线），药丸触控 ≥36px+。
