## 二、本页面如何应用

- **导航**：白底 sticky + `blur(12px)`，链接 14px/400 hover 变紫，右侧紫主按钮 + 浅紫描边 ghost——逐字复刻文档导航规范。
- **页头**：badge 行（成功徽章「第八期 · 进行中」+ 中性 pill）→ 48px/300/-0.96px 大标题「四万三千卷古籍，正在变成可检索的数据。」+ 18px/300 slate 副文。
- **统计卡 ×4**：蓝调多层阴影 + tnum 大数字（2,847,116 / 96.4% / 1,203 / 8,614）——Stripe 的"金融数据面板"转译为工程台账。
- **流水线表格（主交互）**：表头 10px 微标签、索书号用等宽 SourceCodePro、页数与置信度 tnum、置信度 = 紫色进度条 + 数字、三种状态徽章（成功绿/紫描边/灰描边）；tab 筛选 + 实时搜索 + 空态提示；行 hover 5% 紫底。
- **侧栏**：里程碑时间线（紫点 + 细线，日期 500 标签色）、破损修复队列（紫进度条）、志愿者招募卡（紫 CTA）。
- **深靛蓝区**：`#1c1e54` 底，32px/300/-0.64px 白标题 + 三张 10% 白描边卡（检索 API / 数据集 / 素材包）——文档"dark brand section"的直接落地。
- **响应式**：1280 收容器边距；992 主体单列、统计两列、语料卡单列；768 导航折叠、表格容器内横滚（页面无横向滚动）；480 统计单列、按钮全宽 ≥44px；375 显式处理（标题 30px、letter-spacing 收至 -0.6px、统计数字 24px）。

## 三、有意偏离点及理由

1. **主题自行改选**：建议主题「语言学习闪卡」与 wordpick 页（同类型同行业同主题）实质重复，仅因该页恰在 8 页窗口外而未被脚本拦截；改选「古籍数字化工程」，dashboard/education 照旧采纳且不与最近 8 页冲突。
2. **字体替换**：sohne-var 为 Söhne 专有商业字体，以 Google Fonts 的 Inter 替换（几何人文无衬线、有完整 300 细字重）；`font-feature-settings:"ss01"` 已按文档全局声明，但 Inter 无此样式集、实际不生效——字形个性无法完全复刻，在此显式声明。
3. **中文负字距**：-0.96px/-0.64px 沿用文档值用于中英混排标题（48px/32px 中文可安全承受）；375px 下显式收紧至 -0.6px 防止笔画粘连。
4. **tnum**：应用于全部数据数字（统计卡、页数、置信度、日期）——中文无表格数字需求，规则仅作用于阿拉伯数字。
5. 无其他偏离：蓝调双层阴影、4–8px 圆角、`#061b31` 标题、`#1c1e54` 深区、成功徽章、按钮规格（8px 16px padding / 4px 圆角 / hover `#4434d4`）均逐项取自 DESIGN.md。
