- **导航**：英雄区上透明（80% 白链接），滚动过 120px 转白底 + 羊皮纸底线（JS 切换）；奶油 CTA"与我们开工"。

## 三、有意偏离点及理由

1. **字体替换**：Super Sans VF 为私有可变字体，以 Inter 可变字重 **460/540/600/700** 精确复刻其"非常规字重轴"签名（Google Fonts 变量轴支持任意数值）；回退栈按文档声明。
2. **CJK 行高折衷**：展示行高 0.96 与卡片题 0.76 针对拉丁字身设计，中文整字会裁切；分别放宽至 1.04 与 1.1，负字距按文档比例（-1.32px@48px ≈ -0.0275em）换算保留。
3. **产品截图 → CSS 产品 UI**：平台禁外部图片，三个案例缩略图以纯 CSS 绘制的"产品界面"承担"UI 自己卖自己"的角色，配色全部取自本系统色板（紫暮/薰衣草/奶油/炭墨/羊皮纸）。
4. **导航滚动转白**：文档仅说"sticky with background transition"；120px 阈值与羊皮纸底线为按此原则的具体化。
5. 无其他偏离：单强调色纪律、双圆角制、奶油/炭墨双 CTA、边框式深度、460 默认字重均逐项取自 DESIGN.md。
