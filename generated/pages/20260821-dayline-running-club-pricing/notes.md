## 二、本页面如何应用

- **导航**：白底 blur + 8% 黑底线；渐变方块 logo（品红→橙→薰衣草，装饰性渐变的合法落点）+ mono 大写小注 `DAYLINE`；链接 16px/400/-0.16px；深蓝实心 4px CTA。
- **Hero**：三层径向粉彩云雾（品红 16% / 薰衣草 45% / 蓝 18%，溢出裁切）之上——mono 大写小标 `PRICING · 2026 秋季赛` → 64px/500/-1.92px「跑一个赛季，账单清爽得像清晨。」→ 40% 黑副文 → 深蓝主 CTA + 描边 CTA → **按季/按年切换器**（mono 药丸型：深蓝激活态；JS 实时重写三档价格，年付含品红 `省 18%` 注记——品牌色仅此一处文字级出场）。
- **会员三档卡**：8px 圆角 + 8% 黑边 + 蓝调阴影；中间档加薰衣草描边 + 薰衣草底 mono 徽章「最多人选」；价格 54px/500/-1.6px + mono 周期小注；权益行列表（8% 黑分隔）。
- **统计锚点条**：4,200 / 17 / 92% / **0**（零广告）——大数字 56px/500/-1.6px + 40% 黑小注。
- **费率拆解**：四行横向条形（薰衣草渐变填充 + mono 金额右对齐）+ 章程级透明度注记（"账上现金不得超过下季预算 110%"）。
- **深蓝公报区**：`#010120` 满宽 + 白 40px/-0.8px 标题 + 三张 12% 白边论文卡（跑量公报/安全白皮书/路线图集），薰衣草 mono 小标 + 60% 白正文 + 底边下划链接。
- **巨型页脚**：`dayline` 词标 clamp(64px, 14vw, 180px)/-4px，白色→25% 白渐变文字（background-clip）；四栏链接（mono 栏题）+ mono 页脚注记行。

## 三、有意偏离点及理由

1. **风格与类型自选说明**：计划抽取缺额（0 个风格），自选随机结果 together.ai；类型仅剩 pricing/e-commerce 可用，取 pricing/sports——"费率透明拆解"延续非商品化取向。
2. **字体替换**：The Future（Pangram Pangram 商业字体）→ Google Fonts **Archivo**（几何现代主义、400/500 档齐全）；PP Neue Montreal Mono → **Space Mono**（几何等宽、大写标签气质接近）；中文回退链按平台底线追加。
3. **中文负字距**：-1.92px/-0.8px 等文档值用于中英混排（64px 中文可承受）；479px 收至 -0.9px、375px 收至 -0.6px 防粘连。
4. **巨型页脚渐隐**：文档仅说"massive scale wordmark"；白色→透明的 background-clip 渐隐为自由度，色值仍为纯白系，在此声明。
5. **价格切换交互**：文档未定义交互；按季/按年切换为费率页常规构造，价格数字用 JS 重写，视觉 tokens 未越出文档范围。
6. 无其他偏离：双世界明暗、粉彩仅装饰、薰衣草唯一 UI 强调、锐利 4/8px、蓝调单阴影、mono 大写路标、无 700 字重均逐项取自 DESIGN.md。
