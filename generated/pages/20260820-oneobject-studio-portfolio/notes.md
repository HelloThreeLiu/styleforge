## 二、本页面如何应用

- **导航**：白底吸顶 + 阴影底边（无 border）；链接 14/500；暗色 6px 按钮"联系我们"。
- **英雄区**：极淡三色粉彩径向洗（蓝/粉/红各 ≤6% 透明度——"几乎不可见的氛围"）；48px/600/-0.038em 压缩标题；蓝底药丸徽章（新品状态）；20px/1.8 灰副文；暗主 + 白幽灵双 CTA。
- **作品网格**：三张阴影即边框卡（8px 圆角，hover 升级为完整四层卡片栈）；**器物全部纯 CSS 绘制**——陶杯（渐变坯体 + 边框把手）、台灯（黑灯罩 + 暖光晕 + 杆与底座）、音箱（金属腔 + 径向格栅网纹 + 物理旋钮）；mono 大写标签（`Ceramic / 2024`）做作品的"技术档案"行；卡题 24/600/-0.04em。
- **工作流管线**：把 vercel 的 Develop→Preview→Ship 签名组件翻译为器物工序——草图（蓝）→打样（粉）→量产（红），每步彩色圆点 + mono 大写彩色标签 + 白底描边使圆点压住连接线；**三色全页仅在此出现**。
- **指标卡**：48px/600/-0.05em 大数字 + 等宽数字（tnum），完整四层阴影栈容器。
- **渠道条**：上下浅线 + 灰字渠道名（`#808080`——de-emphasized 状态）。
- **引言**：`1px solid #171717` 全宽深顶线（文档的区块分隔手法）+ 32px/400/-0.04em 引句 + mono 大写署名。
- **页脚**：深顶线 + mono 大写栏题，链接 hover 变 Link Blue `#0072f5`。
- **响应式**：1024 起作品两列；768 起导航折叠、流程纵排（连接线移除）、指标单列、页脚两列；480：作品单列、英雄 38px、CTA 全宽 ≥44px、页脚单列；375px 下展示 38px（≥30px 底线）。

## 三、有意偏离点及理由

1. **字体直载**：Geist / Geist Mono 已上架 Google Fonts（Vercel 官方开源），按文档字重 400/500/600 与 `"liga"` 特性直载，无需替代——本页为纯血复刻。
2. **中文负字距折衷**：文档字距针对拉丁字身；中文按同比例换算并适度收敛（48px→-0.038em、24px→-0.04em→实际用 -0.04em/-0.03em 阶梯），压缩气质保留、避免整字并笔。
3. **英雄最大字号**：文档 Display Hero 为 48px，未做向上外推（区别于此前页面），以忠实源风格的小而精标题呈现。
4. **作品视觉件**：平台禁外部图片，"产品截图即内容"以纯 CSS 器物静物实现；器物自带的材质色（陶米色/金属灰/暖光）属内容色，界面色板保持无彩。
5. 无其他偏离：阴影即边框、四层卡片栈、三档字重、工作流三色纪律、药丸徽章、mono 大写标签、全宽深分隔线均逐项取自 DESIGN.md。
