## 二、本页面如何应用

- **导航**：透明叠于场景 + 自上而下黑渐变；字标 `KODA.LOG`（13px/700/1.17px）；幽灵小按钮"成就总览"。
- **场景一（英雄）**：**纯 CSS 摄影层**——十枚星点 radial-gradient 星野 + 底部 160vw 巨型行星弧（径向渐变 + 1px 星光白大气层描边 + 辉光）；压暗层保证文字可读；48px/700/0.96px `EXPEDITION LOG` + 中文宽字距"远征档案"（0.12em 承担钢印气质）+ 幽灵 CTA。
- **场景二（游戏库）**：CSS 透视网格地平线（`perspective + rotateX(62deg)` 双轴 repeating 渐变 + mask 渐隐 + 地平辉光线）充当"星表地面"；游戏清单做成**任务数据表**——纯文本行（游戏名 700 大写 + 副注 micro / 小时 / 完成度 tabular-nums），唯一直线分隔来自文字层自身的细底线（rgba 0.14，hover 无）。
- **场景三（成就墙）**：星云雾面背景；四列勋章框——1px 星光描边 + 4px 圆角 + 7% 星光底，中央衬线字符；**锁定态**为 12% 描边 + 22% 透明度"LOCKED"；勋章即内容本身（摄影层的等价物），非装饰件。
- **场景四（正在游玩）**：双层 clip-path 像素山脉 + 辉光小行星 + 星点；"本周远征"文案 + 幽灵按钮。
- **页脚**：1px 星光线 + 双侧 micro 大写版权行。
- **响应式**：全屏节拍在移动端保持（文档要求）；768 起导航折叠、数据表收窄、勋章三列；480：中文大标 30px（≥30px 底线）、幽灵按钮全宽（≥44px）、数据表隐藏末列、勋章两列；375px 无横向滚动。

## 三、有意偏离点及理由

1. **摄影层的 CSS 替代**：平台禁外部图片，"全屏摄影即设计"以四个纯 CSS 场景替代（星野行星弧/透视网格/星云/像素山脉），构图与压暗层逻辑严格照搬；宣言式偏离。
2. **中文的正字距折衷**：大写不适用于 CJK，中文标题以 0.12em 宽字距 + 700 字重承担同等"钢印"质感，拉丁部分严格 uppercase + 0.96–1.17px。
3. **字体**：D-DIN 为自由分发字体但不在 Google Fonts，按文档回退链使用 Arial/Verdana 系统栈（含中文回退）——零外部请求。
4. **数据表细底线**：文档"禁分隔线"指装饰性元素；数据表行底线为表格语义结构（最小存在 0.14 透明度），在此声明。
5. 无其他偏离：纯黑白 + 星光白双色制、全屏节拍、幽灵按钮唯一交互、零阴影零卡片、双字重纪律均逐项取自 DESIGN.md。
