## 二、本页面如何应用

- **导航**：米白 blur sticky + 燕麦底线；黑方块 + 橙色斜针 logo；链接 16px hover 白底；**橙色描边 mono 徽标「AI 估价 · 30 秒」**（Fin Orange 的品牌级出场）+ 深色 4px 按钮。
- **Hero**：mono kicker（AI 估价上线染橙）→ 80px/400/1.00/-2.4px「补丁不是伤疤，是简历。」→ 副文 → 深色主按钮 + 描边按钮（**hover scale 1.1 反白、active 绿底 scale 0.85**）。
- **服务三卡**：白底燕麦边 8px；report 色板轮换 mono 标签（织补=蓝 / 重造=粉 / 接长=青柠）；32px/-0.96px 卡题 + 起价 mono 行。
- **循环商店（e-commerce 核心）**：54px/-1.6px 区题 + 分类 tab（mono，激活黑底白字）+ **8 件商品卡**（CSS 虚线勾画衣物剪影 ×4 型 + report 色补丁方块；成色徽章 A/B/C 用蓝/粉/青柠轮换；衬线体一句商品故事 + 价格含划线原价 +「加入循环篮」描边小按钮）——JS 分类筛选 + 空态提示 + 按钮点击「✓ 已加入」反馈。
- **补丁故事（编辑体块）**：Serrif 位——衬线 17px/300/-0.16px 正文 + **首字下沉**，三段风衣三代人的叙事。
- **数据条**：report 色大数字（蓝 12,400 / 绿 3,800 / 青柠 4.6 吨）——"报告色板只用于数据"的直接落地。
- **寄衣四步**：燕麦边卡网格，第二步「AI 估价」的步骤号染 Fin Orange（AI 特性专用色）。
- **深色 CTA 盒**：`#111111` 8px 圆角 + 橙 mono 标签 + 白 54px/-1.6px 标题 + 白按钮 hover 变橙。

## 三、有意偏离点及理由

1. **风格与类型自选说明**：计划抽取缺额（0 个风格），自选随机结果 intercom；类型仅剩 pricing/e-commerce 可用，取 e-commerce/fashion，以循环修补叙事对冲"商品展示"套路。
2. **字体替换**：Saans / Serrif / SaansMono 均为 Intercom 专有字体，分别以 Google Fonts 的 **Instrument Sans**（几何无衬线）/ **Source Serif 4**（编辑衬线，300 细字重档）/ **IBM Plex Mono**（等宽大写标签）替换；中文回退链按平台底线追加。
3. **中文负字距与行高 1.00**：80px/1.00/-2.4px 的超压缩行高用于中文标题时以手动 `<br>` 换行保证可读；断点递减字距（-1.2/-0.9px）防粘连。
4. **商品剪影**：DESIGN.md 未定义商品图语法；以虚线 border 勾画衣物剪影（四型变体）+ report 色补丁方块表达"修补过的旧衣"，纯 CSS 无外部图片，属内容层自由度。
5. **active 态绿 `#2c6415`**：按文档按钮规范原样实现（deep green 按下态）。
6. 无其他偏离：暖米白画布、燕麦边框 8px 无阴影卡、4px 锐利按钮、scale 物理交互、report 色板仅数据与标签、Fin Orange 仅品牌/AI 时刻均逐项取自 DESIGN.md。
