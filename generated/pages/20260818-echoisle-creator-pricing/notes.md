## 二、本页面如何应用

- **导航**：白底吸顶 + `#f2f3f5` 发丝线；链接 DM Sans 14px/500；「定价」用 `rgba(0,0,0,0.05)` 药丸激活指示；右侧文字"登录"+ 深色 8px 圆角 CTA"免费开始"。Logo 圆点用粉→紫→蓝 conic 渐变（品牌粉的合法栖息地）。
- **英雄区**：Outfit `clamp(38→80px)`/500/lh1.10 展示标题"选择你的创作节奏"；徽章药丸（30px 圆角、6% 品牌蓝底）；计费切换为 9999px 分段药丸（激活项白底 + 标准阴影），JS 同步改写价格与计费说明。
- **定价卡三联**：自由启程（白卡 20px 圆角 + 浅灰次级按钮）/ 全速创作（**精选卡**：150° 粉→紫→蓝渐变、24px 圆角、紫调品牌辉光、"最受欢迎"深色药丸徽章、白底 CTA）/ 工作室（白卡 + 深色 CTA）。卡题 Outfit 28px/600，价格 Outfit 44px/600，权益清单 ✓ 用 `#1456f0`，hover 统一上浮 4px + 抬升阴影。
- **逐项对比表**：16px 圆角白卡 + 标准阴影；表头 Outfit，权益列 DM Sans，**数字全部 Roboto + tabular-nums**（"数据语境用 Roboto"的忠实执行）；精选列衬 3.5% 品牌蓝底色。
- **创作者说**：16px 圆角证言卡 ×3，头像为三套品牌渐变圆（粉紫/橙粉/蓝青）+ 姓氏首字，正文 14px/lh1.70。
- **FAQ**：原生 `<details>` 折叠，"+"旋转 45° 指示，`#f2f3f5` 分隔线。
- **终章 CTA**：整块粉→紫→蓝渐变大卡（24px 圆角 + 品牌紫辉光——精选产品卡待遇），白底主按钮 + 半透明白玻璃次按钮。
- **页脚**：`#181e25` 深色四栏，链接 `rgba(255,255,255,0.8)`，底栏 50% 白版权行。
- **响应式**：1024 起定价/证言卡单列、精选卡置顶；768 起导航折叠、切换条全宽、区块距 64-80→48px；480 起按钮全宽（≥44px 触控）、页脚单列。对比表在窄屏用容器内横向滚动（页面本身无横向滚动条），375px 下展示标题 38px（≥30px 底线）。

## 三、有意偏离点及理由

1. **精选卡内文字用深色**：DESIGN.md 的渐变产品卡未规定文字色；粉→紫→蓝 150° 渐变亮度较高，白字对比不足，故卡内统一用品牌近黑 `#18181b` 系（与"按钮文字 #18181b"一致），对比达 WCAG AA。
2. **对比表容器内滚动**：词表未含表格塌缩策略；按平台"页面禁止横向滚动"底线，选择表格容器 `overflow-x: auto` + `min-width`，页面级不产生横向滚动条。
3. **FAQ 用 Poppins 副标题、问题用 DM Sans**：文档的 Section Heading（Outfit 31px/600）+ Feature Label（Poppins 18px/500）分层照搬；问题行按 Nav/Link 层级（DM Sans 500）处理。
4. 无其他偏离：色板、双轨按钮几何、圆角与阴影体系、多字体分工、1.50 行高、白底纪律均逐项取自 DESIGN.md；中文以 PingFang SC / Microsoft YaHei 回退保证渲染。
