## 二、本页面如何应用

- **导航**：深色 `#1a1a1a` sticky；方框钟标 logo（CSS 时针分针）；**18px/900 导航** hover 蓝；右端白字 + 1px 白底边按钮。
- **暗 Hero（展厅第一拍）**：60px/300/uppercase「TIME, RESTORED.」（restored 用银灰）、22px 中文副标、银灰副文（1.15 紧行高）；双白底边按钮；右侧 **CSS 表盘装置**——3px 白圆环 + repeating-conic 分钟刻度 + 时/分针静态 + **蓝秒针 60s 步进扫秒动画**（`steps(60)`，机械秒针的跳动感）+ 白轴点。
- **白色内容区（工艺三卡）**：零圆角无边界卡——`#1a1a1a` 方形图位内 CSS 机械图形（齿轮双环/游丝椭圆/表盘刻度）；20px/700 标题 + 1.15 行高灰描述 + 蓝色文字链。

## 三、有意偏离点及理由

1. **主题改选**：建议主题撞白露页，改为「古董钟表维修工作室」；marketing/consumer 采纳。
2. **字体**：BMWTypeNextLatin 专有，直接采用文档自带回退栈（Helvetica/Arial + 中文系统体）——零 CDN 且为官方指定路径；300/400/700/900 四档字重全部由系统字体承担。
3. **大写展示的中文处理**：uppercase 对中文无效——主标用英文大写（TIME, RESTORED.）+ 中文副标的组合，保留"大写纪念碑"气质的同时不造生硬翻译，在此声明。
4. **表盘圆形豁免**：零圆角纪律约束 UI 元素；hero 表盘与图位机械图形为**内容图形**（等价于 BMW 的汽车摄影），圆形是钟表本体而非 UI 装饰，在此显式声明豁免边界。
5. **无阴影纪律**：全页零 box-shadow——深度完全由暗/白分区与底边线承担，与文档一致。
6. 无其他偏离：零圆角、300/900 极差、1.15–1.30 紧行高、BMW 蓝仅交互、暗面白底边按钮、展厅明暗节奏均逐项取自 DESIGN.md。
