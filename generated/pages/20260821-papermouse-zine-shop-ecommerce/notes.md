## 二、本页面如何应用

- **导航**：暖底 sticky + sage 底线；简笔"纸耗子" logo（圆角块 + 尾巴斜线）；15px/600 深橄榄链接 hover 下划线；深色 CTA「邮购目录」（hover 半透明 + 琥珀字）。
- **Hero（双栏）**：40px/800/-0.75px「薄薄一本，重过热搜。」（"重过热搜"加 4px 暖棕底划）+ 17px/1.56 正文 + 深色/sage 双按钮 + 数据小注；右侧 **手绘感邮购明信片**（rotate 1.6° 微倾、双 dashed 内框、圆形邮戳（径向双色圆）、书写线、sage 按钮）——posthog"手绘插画"的 CSS 转译。
- **书架（e-commerce 核心）**：大写分类标签 `SORTED BY` + 36px/700/1.5 区题 + 药丸筛选 tab（激活深色、hover 橙闪）+ **8 本 zine 卡**（1px sage 边 6px 圆角，hover 边框加深墨）：封面 = 每本一套手作色块 + 简笔几何（圆环/双弧/三线/虚线圆/双块/胶囊）+ mono 期号药丸 + 白字标题；信息区 21px/700 书名 + 14px/1.5 描述 + 价格（划线原价）+ sage「放入邮购篮」按钮（hover 橙闪 +「✓ 放进去了」反馈）。
- **手作承诺（sage 面区）**：上下 sage 边夹住 `#eeefe9` 区——三张 bordered 卡（人手装订 / 油印封面 / 手写编号），mono 步骤小标。
- **编辑体块**：36px/700/1.5 提问式标题 + **1.71 行高正文**（"纸会用完 / 纸会留下来"）——为长读而生的排版。
- **页脚**：sage 顶线四栏（大写 700 栏题）、链接 hover 橙。
- **响应式**：1024 hero 单列、书架两列；768 导航折叠、手作卡单列；640 书架单列；375 显式处理（hero 28px、明信片取消倾斜）。

## 三、有意偏离点及理由

1. **风格与类型自选说明**：计划抽取缺额（0 个），自选随机结果 posthog；类型仅剩 e-commerce，取 e-commerce/media。
2. **字体**：IBM Plex Sans 与 Source Code Pro 均直载（与文档一致，无字体偏离）；中文回退链按平台底线追加。
3. **手绘插画的 CSS 转译**：文档的手绘刺猬为位图插画；以"倾斜明信片 + dashed 缝线 + 圆形邮戳 + 简笔几何封面"等 CSS 手作语汇替代插画功能（反企业的人格载体），无外部图片，在此声明。
4. **hover 橙纪律**：橙严格只出现在 hover/active（按钮、tab、页脚链接），静止界面零橙色——与文档"静止不出现"的隐藏品牌定义一致。
5. 无其他偏离：暖底不透明表面、sage 边框容器、深色 CTA 半透明 hover + 琥珀、粗字重宽行高、大写栏目标签、4–6px/9999px 圆角双轨均逐项取自 DESIGN.md。
