## 二、本页面如何应用

- **导航**：云灰半透 + blur + 薰衣草底边；黑字标 `焊点 solder.`（黑块内嵌云灰芯片——logo 记号）；链接 15/500 药丸 hover 白底；右侧**绿点状态徽章**"全部现货 · 当日发货"（36px 药丸）+ 黑药丸"注册"。
- **英雄区**：64px/800/-0.045em 纯黑压缩标题；18px/1.4 Slate 副文（含"47 分钟点亮"数据）；黑药丸主 CTA + 白边药丸次 CTA；下方 mono 一行 `npm i @solder/sdk`（钴蓝 code + 6px 圆角白底）。
- **商品网格**：白卡 + 薰衣草边 + 8px 圆角，hover 耳语阴影 + 2px 上浮；**产品图全部纯 CSS 且带色**（界面无彩、产品即色彩——PCB 绿 + 金手指引脚 + 红 LED、墨水屏灰阶、深色键阵、灰机身 + 琥珀灯）；标签三制：新品黑药丸 / 预售紫药丸（10% 紫底）/ 热销灰药丸；卡题 20/600/-0.0125px 字距；"加入购物车"为 6px 功能圆角白边钮，点击 1.2s ✓ 反馈。
- **SDK 区**：三特性白卡 + JetBrains Mono 代码卡（关键字钴蓝、注释 Silver）；呼应"买了就点亮"。
- **设备预览网格**：手机（深色 UI 面板）/ 网页仪表盘（云灰内屏 + 绿数据条）/ 墨水屏（灰阶行）三种 CSS 设备框——Expo "Device Preview Grid" 签名的直译。
- **深色促销横幅**：`#171717` 16px 圆角容器 + Legal Blue 链接。
- **页脚**：云灰底 + 薰衣草顶边，链接钴蓝，Silver 底栏。
- **响应式**：1024 起商品两列、特性/设备单列；768 起导航折叠（状态徽章隐藏）、区块距 56px、横幅收紧、页脚两栏；480：商品单列、英雄 38px、CTA 全宽 ≥44px、购物车按钮 ≥44px；375px 下展示 38px（≥30px 底线）。

## 三、有意偏离点及理由

1. **字体直载**：Inter 与 JetBrains Mono 均按文档家族直载 Google Fonts；字重取 400–800 覆盖文档的 400–900 表现区间（900 在中文正文无对应字形，未单独加载）。
2. **中文压缩字距折衷**：-3px@64px 换算为 -0.045em 并对中文适度收敛，密实块气质保留。
3. **产品带色**：文档"产品截图是界面唯一色彩来源"——平台禁外部图片，故以纯 CSS 绘制的带色产品图（PCB 绿/LED 红/琥珀灯）承担此角色；界面色板严格无彩。
4. **购物车反馈**：词表无电商交互规格；以 1.2s 瞬时按钮态实现（与此前页面一致的克制模式），未引入 toast。
5. 无其他偏离：云灰/白双浅色制、药丸几何阶梯、耳语阴影、单字体全字重、深横幅、零渐变均逐项取自 DESIGN.md。
