## 二、本页面如何应用

- **导航**：紫黑透明 + 玻璃 + 紫调底线；荧光绿菱形 logo（带辉光——全页绿的第一处）；内凹紫按钮"加入夜巡"。
- **英雄区**：紫调环境辉光之上，**六枚荧光绿萤火**（`fly` 动画：位移 + 呼吸 + 辉光）——萤火即内容本体，也正好是"高可见信号绿"的语义化使用；88px"数萤火的人。"；白底实心 CTA（hover 紫、focus 珊瑚）+ 内凹紫按钮；三张玻璃数据卡（夜巡员/城市/记录数）。
- **观察方法区**：`#150f23` 深区 + 紫边框卡 ×3（计数/样线/光污染），标题圆点紫/绿/粉分卡不混用；荧光绿大写区标。
- **记录格式代码卡**：Monaco 的 YAML 观测记录——注释灰白、关键字荧光绿（种类/计数/天光星等）、字符串代码黄；状态行 `● 128,406 records`。
- **公众观测夜**：行式列表（日期 22px 展示字重 + 领队信息 + 状态徽章：绿边"报名开放"、灰紫边"已满员"）。
- **终章/页脚**："今晚，就数一次萤火。" + 白 CTA；`#150f23` 页脚栏题紫、链接 hover 紫。
- **响应式**：992 起特性/玻璃单列；768 起导航折叠、观测夜行收窄（徽章换行）、页脚两栏；480：英雄 42px、按钮全宽 ≥44px、页脚单列；375px 展示 42px（≥30px 底线）。

## 三、有意偏离点及理由

1. **类型/行业/主题自行改选**：计划建议（landing/music/电台直播间）与当日声呐页四维撞车（该页在最近 8 页内），触发 §11 改选条款；改选为 marketing/science/夜间生态——marketing 与 science 均不在最近 8 页，且与同轮候鸟页互不雷同。
2. **萤火的绿色密度**：六枚动画萤火集中在英雄区一"幕"内，作为内容主角（而非 UI 装饰）出现；其余各区仍守"绿至多一次"纪律。在此显式声明。
3. **字体替换**：与前例一致（Space Grotesk 替 Dammit Sans、Rubik 直载、Monaco 回退链 + IBM Plex Mono）；大写字距仅作用于拉丁字，中文标签保留 0.2–0.25px 字距。
4. 无其他偏离：双色紫底、紫调边框、内凹按钮、玻璃面、环境辉光、语义四色纪律均逐项取自 DESIGN.md。
