## 二、本页面如何应用

- **导航**：白底 blur + 1px 黑底线；正圆 logo（黑圆内白色斜杠——"举起的手"抽象）；**药丸 tab 条**（1px 黑边框内嵌，激活黑底白字）；链接 1px 下划线；黑药丸 CTA；768 折叠为独立下拉面板。
- **Hero（满宽多彩渐变——内容色唯一主场）**：118° 五停渐变（电光绿→亮黄→橙→热粉→深紫）；玻璃白 mono 药丸「THIS WEEK · 214 场」→ 86px/400/-1.72px 白标题「一周十分钟，举手之劳。」→ 20px/330 白副文 → 白药丸 + **玻璃白药丸**（16% 白 + blur）。
- **白画廊活动区**：mono 大写区标（18px/0.54px）+ 64px/-0.96px 区题 + 药丸筛选 tab（户外/室内/线上/紧急）+ **8 张活动卡**（1px 黑描边 8px 圆角：上半 = 活动专属渐变块 + 白色几何 glyph，下半 = 白底 mono 类型行 + 20px/700 卡题 + 15px/330 描述 + 黑药丸报名钮 + mono 名额）——色彩全部由活动内容供给，黑白画廊挂彩画。
- **三步运转**：黑白描边卡 + mono 药丸步骤号 + 26px/540 标题——"不面试、不培训、不打卡"的低门槛叙事。
- **数字区**：72px/340 大数字（12,600 举手者 / 340 社区 / 96% 到场率）。
- **黑色页脚**：64px 白标题 + 白药丸 CTA；四栏（mono 栏题白 20% 分隔线）+ mono 页脚注记。
- **交互**：tab 筛选 + 空态；报名按钮「✓ 已举手」1.6s 反馈（满员按钮不响应）；**全站虚线焦点**（hero 内自动换白色虚线）。
- **响应式**：960 活动两列/三步单列；768 导航折叠、数字单列；560 活动单列；375 显式处理（hero 34px≥底线、字距 -0.6px、按钮全宽）。

## 三、有意偏离点及理由

1. **字体替换**：figmaSans 为 Figma 专有可变字体，以 Google Fonts **Inter 可变版（wght 100–900）** 替换——CSS 直接书写 320/330/340/450/480/540 非标字重档，可变字体原生支持，字重纪律完整保留；figmaMono 按文档回退链（ui-monospace/SF Mono/Menlo）零 CDN 加载；中文回退链按平台底线追加。
2. **中文负字距**：-1.72px/-0.96px/-0.14px 文档值应用于中英混排；560px 收至 -0.9px、375px 收至 -0.6px 防粘连。
3. **内容渐变色值**：文档描述"electric greens, bright yellows, deep purples, hot pinks"未给精确值；色值按描述选取（绿 #14f195、黄 #ffd60a、橙 #ff8a00、粉 #ff2e88、紫 #5e17eb），仅用于 hero 与活动卡内容层，不触 chrome，在此声明。
4. **活动卡 glyph**：以白色几何圆点作渐变块内的抽象图形（CSS 绘制，无外部图片），尺寸逐卡变化，属内容层自由度。
5. 无其他偏离：界面层绝对黑白、药丸/正圆几何、虚线焦点、8px 卡圆角、玻璃黑/白面、黑色页脚、轻字重美学、kern 全局均逐项取自 DESIGN.md。
