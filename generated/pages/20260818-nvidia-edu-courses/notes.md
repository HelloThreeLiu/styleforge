## 二、本页面如何应用

- **导航**：纯黑吸顶，logo 用 CSS 平行四边形做"绿色斜切"记号；链接全部 14px/700/大写，hover 蓝 `#3860be`；右侧购物车角标用绿底黑字小方块（1px 圆角）。
- **英雄区**：黑底 + 右上绿色径向渐变叠加（文档 Image Treatment："green gradient overlays on dark hero"）；标题中"生产力"一词用 2px 绿下划线；右侧纯 CSS 绘制 GPU 芯片（绿色网格 die + 引脚栅格 + 核心亮斑）；CTA 为绿描边按钮对。
- **课程目录**：白底浅色区；产品卡按文档 Product Cards 范式——2px 圆角、`0 0 5px` 阴影、课程标题绿下划线、粗标题+浅描述、"加入学习车"绿描边薄按钮；精选徽章用橙 `#df6500` 大写小标。
- **学习路径**：完整采用 Tech Spec Tables 范式——黑表头（推荐路径列表头染绿）、隔行 `#fafafa`、粗体规格名、绿色高亮关键指标（课时数/H100 实验/专家证书）、删除线原价。
- **提示条**：`#feeeb2` 暖底 + 橙左边线，促销信息。
- **企业培训**：黑区 + `#1a1a1a` 卡片列表（绿色左边线），延续深色区的克制。
- **响应式**：768px 起导航折叠、课程两列、规格表横向滚动（保持表格完整性）；480px 课程单列、CTA 全宽。购物车文字在移动端隐藏仅留角标。

## 三、有意偏离点及理由

1. **英雄区标题字号**：DESIGN.md 层级表最大 36px（Display Hero），本页用 clamp(36–52px)——下限严格等于 36px，上浮部分用于首页落地语境，字重 700 与 1.25 行高完全遵循。
2. **字体**：NVIDIA-EMEA 为私有字体，直接采用文档自带的官方回退栈 `Arial, Helvetica, sans-serif`（无需 CDN，离线可用）。
3. **斜切 logo 记号**：文档未定义 logo 图形（原文为"prominent wordmark"），以纯 CSS 平行四边形绿色记号呼应 NVIDIA 视觉记忆点，属最小限度的品牌暗示，在此声明。
4. 无其他偏离：绿色使用纪律（只描边/下划线/高亮）、1–2px 圆角、阴影、字重与行高体系、规格表范式均逐项取自 DESIGN.md。
