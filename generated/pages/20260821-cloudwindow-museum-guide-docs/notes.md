## 二、本页面如何应用

## 三、有意偏离点及理由

1. **字体替换**：WF Visual Sans Variable 为 Webflow 专有字体，以 Google Fonts 的 Inter（400–700 可变，含 550/600 档）替换；Arial 之外的中文回退链（PingFang SC/微软雅黑）按平台底线追加。
2. **-0.8px/-0.16px 字距**：文档值原样应用于中英混排（80px/16px 中文均可承受）；375px 下 hero 收紧至 -0.4px 防止笔画粘连。
3. **CTA 深色区**：DESIGN.md 未提及深色 section；`#080808`（文档的主文本色）反用作 CTA 背景属色彩角色的延伸复用，未引入任何新色值，在此显式声明。
4. **文档篇幅限制说明**：webflow 的 DESIGN.md 仅 92 行（无组件交互态/响应式细节），本页的手风琴、搜索跳转等交互为文档站题材的常规构造，视觉 tokens 未越出文档声明范围。
5. 无其他偏离：白底 + `#080808` 文本、蓝色唯一主 CTA、次级色仅标记用途、4–8px 圆角、5 层阴影、translate(6px) hover、Inconsolata 代码均逐项取自 DESIGN.md。
