第 1 章 · 快速开始

二十分钟，上线你的第一个展厅。

云窗的内容结构只有三层：场馆 → 展厅 → 展品。先建场馆、再划展厅、最后给每件展品挂讲解词——观众端页面会随内容自动生成，无需任何设计工作。

1

创建场馆

填写场馆名称与开放时间，上传平面图。免费版支持 1 座场馆、50 件展品。

2

划分展厅

在平面图上圈出展厅范围，系统自动生成观众端的室内定位锚点。

3

挂载讲解词

为每件展品撰写 60–90 秒的语音脚本，或直接上传录音。支持一稿多语言。

提示：讲解词的黄金时长是 75 秒。后台会实时显示预估时长，超过 120 秒的稿件会被标记为「偏长」。

第 2 章 · 讲解词编辑

一稿多语言，一处修改处处生效。

讲解词以导览点（stop）为单位组织。每个导览点包含标题、正文、时长与媒体附件；翻译跟随同一结构，不会错位。

导览点数据结构

{
  "id": "stop-0117",
  "title": "曾侯乙编钟 · 下层甬钟",
  "duration": 78,            // 秒，语音版时长
  "narration": {
    "zh-CN": "请听，这是两千四百年前的声音…",
    "en":    "Listen — this is a sound from 2,400 years ago…"
  },
  media": ["audio-zh.mp3", "asl-video.mp4"]
}

修改任意语言稿后，观众端在 30 秒内热更新——不需要重新张贴展厅二维码。详见导览点字段参考。

第 3 章 · 无障碍

上线前的八项检查。

云窗的观众端按 WCAG 2.1 AA 构建，但内容侧的无障碍需要编辑团队配合完成。以下清单会出现在每个展厅的发布确认页：

  • 语音讲解全部配有同步字幕（含标点与语气停顿）
  • 关键展品提供手语视频（ASL / CSL）
  • 图片附件填写 alt 描述文本
  • 字号调节器可用且不影响版式
  • 色盲模式下的展厅地图仍然可辨识
  • 语音播放支持外接助听设备（蓝牙 HAC）
  • 触觉导引路径在平面图上标注完整
  • 儿童版讲解词覆盖全部常设展
