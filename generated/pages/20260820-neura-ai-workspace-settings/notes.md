## 二、本页面如何应用

- **导航**：白底吸顶 + `rgba(91,97,110,.2)` 底线；品牌 `◆ neura`（蓝方块旋转 45° + 小写字标）；「设置」项纯蓝文字激活；右侧蓝链接"登录" + 深卡底 56px 药丸"免费试用"（hover 变 `#578bfa`）。
- **页头**：大写小字眉题 `settings / 工作台`（品牌蓝）+ 64px/行高 1.00 超紧 Display 标题 + 18px/1.56 正文。
- **设置布局**：左侧粘性侧栏（药丸激活项：冷灰底 + 蓝字）+ 右侧面板；五个分区 JS 真实切换（团队/模型/成员/安全/API）。
- **表单卡**：白底 16px 圆角 + 蓝灰边；输入框 focus 变蓝；标题 18/600、说明 14px。开关为 56px 圆角轨道，**开启态纯蓝**（功能色）。
- **模型与推理**：三张可选模型卡（选中态：蓝边 + 4% 蓝染底 + 蓝圆点）；用量双计量条——填充纯蓝、圆角 56px 延伸到微组件。
- **成员与权限**：药丸输入框 + 蓝描边"发送邀请"（点击 1.4s ✓ 反馈）；成员表（表头冷灰底、角色药丸——所有者用 10% 蓝底蓝字）。
- **API 密钥**：等宽掩码 + 蓝描边"重新生成"两段确认。
- **账单深色分区**：`#0a0b0d` 全宽（白↔黑交替的核心手法）内放 `#282b31` 24px 圆角深卡：蓝底"团队版"药丸 + 52px 白色 Display 价格 + 六根 `#578bfa` 用量柱（当月纯蓝高亮）+ 发票行（链接用 hover 蓝保证暗底可读）。CTA：白底药丸（深底上的主行动）+ 蓝描边变体。
- **页脚**：延续深色分区，链接 hover 蓝。
- **响应式**：1024 起设置布局转单列（侧栏变横滚）、模型卡/账单卡单列；768 起导航折叠、成员表隐藏活跃列；480：CTA 全宽 ≥44px、页脚单列；375px 下 Display 标题 36px（≥30px 底线）。

## 三、有意偏离点及理由

1. **字体替换**：CoinbaseDisplay/Sans/Text 四字族为私有字体，以 Manrope（展示/UI：几何感、600/700 字重对应）+ Inter（正文阅读：18px/1.56）双族替代，字重与行高纪律照搬。
2. **深色区上的蓝色链接用 `#578bfa`**：文档建议深色区用 `#0052ff` 链接，但其在 `#0a0b0d` 上对比度约 2.6:1 不足；按同文档的 hover 蓝提亮以保证可读，属可访问性优先的显式调整。
3. **药丸开关**：词表无开关规格；按"56px 圆角 + 纯蓝功能色"推导，未引入阴影。
4. **小写签名仅应用于拉丁字**：中文无大小写，小写气质由品牌字标 `neura`、眉题小写 `settings` 承载。
5. 无其他偏离：蓝白黑三色制、56px CTA 药丸、行高 1.00 展示标题、深浅交替分区、蓝只做功能均逐项取自 DESIGN.md。
