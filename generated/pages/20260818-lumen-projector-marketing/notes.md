## 二、本页面如何应用

- **导航**：固定纯黑条 + 底缘发丝线（`rgba(255,255,255,.08)`）；链接 Inter 15px/400，hover 磨砂药丸化；右侧白药丸"立即预订"+ Ghost"登录"。
- **英雄区**：居中构图。`clamp(40→110px)`/500/-0.04em 压缩大标题"把影院/装进口袋"（两行，行高 1.02）；磨砂徽章胶囊；白药丸主 CTA + 磨砂次 CTA（均 ≥44px 触控）。
- **产品场景（英雄艺术的替代实现）**：因平台禁止外部图片，用纯 CSS 绘制"投影仪 + 光墙"——`#090909` 机身 + 径向渐变镜头（蓝光辉晕）、梯形 clip-path 光束、16:9 光墙内三组径向渐变充当"放映内容"（产品输出即全页唯一色彩源，呼应 framer "产品截图即英雄"），墙外衬蓝色 radial 辉光 aura（低透明度 0.16）。
- **特性区 ×3**：全部 40/60 非对称网格，交替翻转。视觉件均做成"产品读出物"而非装饰插画——A：六向梯形校正图（虚线墙 + 蓝色校正手柄 + 中心十字）；B：色域光谱条 + Rec.709/P3/2020 刻度 + 数据徽章；C：续航横条图（蓝色渐变填充）。容器统一 `#090909` + 蓝环描边 + 15px 圆角。
- **参数条 / 终章**：56px/500/-0.04em 大数字四联（通用 8px 基距）；终章"熄灯。开场。"85px 压缩标题 + 居中蓝色椭圆辉光。
- **蓝色纪律**：全页蓝色只出现在——链接、焦点环、卡片环描边、辉光、镜头/LED/数据读出（产品发光件），无一处装饰性蓝字蓝块。
- **响应式**：1024 收窄光束与间距；768 起：导航折叠、场景改单列（光墙全宽 + 投影仪居中缩小、光束隐藏）、特性区堆叠、参数 2 列、按钮全宽化（≥44px）；480：页脚单列、Ghost 按钮隐藏、色域刻度末列隐藏。

## 三、有意偏离点及理由

1. **展示字体替换**：GT Walsheim 为私有钱夹字体，以 Google Fonts 的 `Inter Tight`（同族压缩感 grotesk、500 字重）替代，字重纪律（仅 500）与负字距比例（≈-0.05em）严格保留。
2. **中文负字距折衷**：DESIGN.md 的 -5.5px@110px 针对拉丁字形；中文整字负边距过大会并笔，故统一收至 -0.04em、行高 1.02（拉丁部分 `em` 内保留 -0.05em）。压缩气质保留，可读性优先。
3. **磨砂药丸用白字**：文档写磨砂药丸为黑字，但在 `rgba(255,255,255,.1)` 叠纯黑的底上黑字不可读；按文档"frosted surfaces on dark"语境改用白字，hover 提亮至 0.2（文档 hover 0.5 幅度过大，跳跃生硬）。
4. **产品截图 → CSS 产品场景**：平台禁止外部图片，"产品即英雄"以纯 CSS 投影仪+光墙场景实现，构图逻辑（全宽、8–12px 圆角、蓝环+悬浮阴影、辉光衬底）与文档一致。
5. 无其他偏离：色板、药丸几何、环阴影体系、40/60 布局、区块间距均逐项取自 DESIGN.md。
