## 二、本页面如何应用

- **导航**：透明暗底 + `blur(18px) saturate(180%)` 玻璃 + 紫调底线；Rubik 15/500，hover 变交互紫；logo 荧光绿菱形带辉光（全页绿色的第一处：品牌记号）。
- **英雄区**：88px/700/1.2 展示标题"设备异常，/ 更早知道。"（对源品牌口号"Code breaks. Fix it faster."的语气致敬）；背后 `rgba(22,15,36,.9)` 径向环境辉光；白底实心 CTA（hover 变紫、focus 变珊瑚——文档三态齐备）+ 内凹紫按钮；三张**玻璃数据卡**（数据带玻璃化）。
- **特性区**：`#150f23` 深区 + 紫调边框卡 2×2；标题圆点分别用紫/荧光绿/紫/粉——绿与粉不同卡不违反"同组件不混用"；区标用荧光绿大写（文档示例模式）。
- **告警规则代码卡**：Monaco 层的落地——YAML 告警规则（注释灰白、关键字荧光绿、字符串代码黄 `#dcdcaa`、数值纯白），底部 `● 3 rules active` 状态行；把 sentry 的"代码即内容"翻译为告警配置语境。
- **定价区**：计费切换用深紫罗兰激活态；三卡紫边框玻璃底；**精选卡**：紫边 + 玻璃 hover 底 + 荧光绿 `MOST POPULAR` 18px 药丸徽章（该区唯一绿点）+ 白底 CTA hover 变荧光绿；权益箭头 `→` 交互紫；JS 联动月付/年付改价（1,299→1,104 / 4,999→4,249）。
- **客户条**：`#362d59` 灰紫字（hover 变白——文档"dark context links"模式）。
- **页脚**：`#150f23` 深区，栏题紫、链接 hover 紫。
- **响应式**：992 起定价/特性单列（精选置顶）；768 起导航折叠、容器内距 24px、区块距 56px；480：英雄 42px（≥30px 底线）、按钮全宽 ≥44px、页脚单列。

## 三、有意偏离点及理由

1. **字体替换**：Dammit Sans 为私有展示字体，以 Space Grotesk 700 替代（保留个性态度与 88px 冲击）；Rubik 为 Google Fonts 可直载（按文档四档字重 400/500/600/700）；Monaco 无 CDN，按文档回退链书写并加载 IBM Plex Mono 保证 Windows 渲染。
2. **大写字距的中文适配**：中文无大小写，uppercase 仅作用于拉丁字（logo/徽章/标签的英文部分）；中文标签保留 0.2–0.25px 字距以延续"技术标签"质感。
3. **玻璃数据卡**：词表未给数据带规格，按"玻璃面 + 12px 圆角 + 表面阴影"三原则组合，未引入新色。
4. 无其他偏离：双色紫底、紫调边框、内凹按钮、荧光绿纪律、珊瑚焦点、环境辉光、Monaco 代码层、1152px 容器均逐项取自 DESIGN.md。
