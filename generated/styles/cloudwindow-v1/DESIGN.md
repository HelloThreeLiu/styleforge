# Design System: 云窗手册蓝 CloudWindow（派生自 webflow）

> 血统：`webflow` → `20260821-cloudwindow-museum-guide-docs`（★4）→ 本风格。
> 核心命题：把 Webflow 的"白底蓝字 + 富次级色"语言固化为**内容手册/帮助中心**的专用范式——三栏文档骨架、编号步骤卡、代码示例卡与检查清单，一切服务于"让外行团队也能照着做完"。

## 1. 视觉主题与氛围

白纸上的操作手册。纯白画布 + 近黑 `#080808` 文本 + Webflow Blue `#146ef5` 唯一主 CTA；紫粉绿橙黄六色次级板只在"标记"场合出场（步骤编号、版本徽章、提示条）。整体像一本印制精良的机构手册：信息密度不低，但每页只讲一件事。

氛围关键词：手册、章节、清单、照做就行。标题大而紧（80px/600/-0.8px），正文规矩（16px/1.6/-0.16px）。

**关键特征：**
- 三栏文档骨架：分组侧栏（激活项左蓝条 + 10% 蓝底 + scrollspy）+ 内容主栏 + 本页 TOC
- 步骤卡承载 5 层级联阴影（全页最大浮起），编号方块用次级色轮换
- JSON/配置代码卡：键蓝/字符串紫/注释灰 + 顶栏绿色状态行
- 黄色左边条提示卡；绿底白勾自绘检查清单
- FAQ 手风琴 + `translate(6px)` 箭头按钮
- 近黑 `#080808` 满宽 CTA 区反白收尾
- 10% 蓝底徽章；4–8px 保守圆角

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 文本 | `#080808` 近黑 | 白底主文本 |
| 主蓝 | `#146ef5` / hover `#0055d4` / 亮蓝 `#3b89ff` | 唯一 CTA、链接、激活态 |
| 次级色板 | 紫 `#7a3dff` 粉 `#ed52cb` 绿 `#00d722` 橙 `#ff6b00` 黄 `#ffae13` 红 `#ee1d36` | 仅标记：步骤编号、版本徽章、提示条、完成勾 |
| 灰阶 | `#222 / #363636 / #5a5a5a / #ababab` | 深文/正文/次要/占位 |
| 边框 | `#d8d8d8` / hover `#898989` | 卡与分隔 |
| 徽章底 | 蓝 10% 透明 | 信息徽章 |
| 阴影 | 5 层级联 `rgba(0,0,0,0) 0 84px 24px → .09 0 3px 7px` | 大步骤卡签名浮起 |

## 3. 字体规则

WF Visual Sans 不可用时以 Inter（400–700 可变，含 550/600 档）替代，Arial 与中文系统字体入回退链。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero | 80px | 600 | 行高 1.04、-0.8px |
| 区题 | 56px / 32px | 600 / 500 | 手册章节标题 |
| feature 标题 | 24px | 600 | |
| 正文 | 16px | 400–500 | 1.6 行高、-0.16px |
| 大写标签 | 15px/10px | 500–600 | 1.5px/1px 字距，章节引导与页脚栏题 |
| 代码 | Inconsolata | 400–600 | 配置卡与版本号 |

## 4. 组件样式

- **三栏骨架**：220px 侧栏 + 内容 + 170px TOC（sticky）；768 以下侧栏转顶部横滚 chip、TOC 隐藏
- **步骤卡**：白底 `#d8d8d8` 边 8px 圆角 + 5 层阴影；28px 编号方块（蓝/紫/绿轮换白字）；20px/600 标题 + 14px 灰正文
- **提示卡**：`#d8d8d8` 边 + 4px 黄色左边条，14px 正文、关键词加粗近黑
- **代码卡**：`#d8d8d8` 边 8px 圆角；顶栏 mono 文件名 + 绿色状态；正文 Inconsolata 15px/1.7，键蓝、字符串紫、注释 `#ababab`
- **检查清单**：行式 16px + 20px 自绘复选框（完成项绿底白勾 `#00d722`），行间灰线
- **FAQ 手风琴**：1px 灰边 8px 圆角容器；问题 600 hover 蓝；▾ 旋转
- **箭头按钮**：透明底蓝字 + hover `translateX(6px)` 行进感
- **徽章**：10% 蓝底蓝字 4px 圆角 12.8px/550 大写

## 5. 布局原则

- 1200px 容器；三栏 48px 间距；卡网 3→1 列
- 章节结构：大写 kicker → 区题（32px/500）→ 正文 → 组件；每章一个 `id` 供 scrollspy
- 近黑 CTA 满宽区（`#080808` 白字 56px/600）打断白色节奏

## 6. 深度与阴影

白底体系内唯一的大阴影 = 5 层级联（步骤卡）；其余容器一律 1px 灰边无阴影——"边框即容器"，阴影留给"你要照着做的那几步"。

## 7. Do's & Don'ts

### Do
- 手册必须三栏起步（侧栏/内容/TOC），侧栏激活项带左蓝条
- 把"操作步骤"做成带编号的阴影卡——全页最浮起的元素 = 最重要的事
- 代码/配置示例永远用代码卡 + 语法高亮 + 顶栏状态行
- 上线/发布类内容配检查清单，完成项绿底白勾
- 次级色只做标记（编号/徽章/提示），主 CTA 永远蓝
- 箭头按钮 hover 右移 6px

### Don't
- 不要用次级色做按钮或链接
- 不要圆角超 8px、不要药丸（徽章除外 4px）
- 不要让正文行高超过 1.6 或字距为正
- 不要省略大写 kicker——章节导航是手册的骨架
- 不要在白底上再加浅灰底分区（用边框分隔）

## 8. 响应式行为

992 收起右 TOC、步骤卡单列；768 侧栏转顶部横滚 chip、导航折叠；479 按钮全宽 ≥44px、页脚单列；375 显式处理（hero ≥32px、字距收窄）。代码卡窄屏容器内横滚，页面无横向滚动。

## 9. Agent 提示词指南

**起手式**：白底 + `#080808` 文本 + `#146ef5` 唯一 CTA → 搭三栏（侧栏/内容/TOC）→ 每章 = kicker + 32px 区题 + 组件 → 步骤做阴影编号卡 → 页尾近黑 CTA 区。

**示例提示词**：
- "三栏文档布局：左 220px 分组侧栏（激活项左 2px 蓝条 + 10% 蓝底 + scrollspy），中间内容，右 170px TOC 左边线。"
- "步骤卡：白底 #d8d8d8 边 8px 圆角 + 5 层级联阴影 rgba(0,0,0,0) 0 84px 24px … rgba(0,0,0,.09) 0 3px 7px；28px 编号方块蓝底白字；标题 20px/600。"
- "检查清单：16px 行 + 20px 复选框描边灰，完成项 #00d722 绿底白 ✓，行间 1px #d8d8d8 线。"

**适配题材**：产品手册、帮助中心、运营 SOP、策展/编辑团队指南、机构操作规程——面向"非工程师照着做"的一切文档。
