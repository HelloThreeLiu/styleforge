# Design System: Pastel Gallery（粉彩画廊 · 白底产品卡风）

> 派生自页面 `20260818-echoisle-creator-pricing`（★4，study of `minimax`）。
> 核心命题：白底画廊语言在**定价/转化型页面**上的完整落地——色彩全部由"渐变产品卡"供给，按钮走"药丸导航 + 方角 CTA"双轨制，数据交给专门的等宽感字体。

---

## 1. 视觉主题与氛围

白色画廊。`#ffffff` 是结构色而非背景色——内容区永远白，彩色只允许出现在"产品卡"上。粉→紫→蓝的柔和渐变卡像手机主屏上的应用图标，在白画布上一张张"挂"出来；品牌紫阴影给精选卡一圈淡淡的辉光。气质：轻盈、亲和、可信——Apple 式的清晰 + 一点卡通的友好。

本风格的增量在于**转化页语法**：

- 英雄区展示标题（80px 级、500 字重、行高 1.10）直接压在白底上，不配插画，靠字重与留白撑场；
- "精选"是一个视觉等级而非标签：整卡渐变 + 紫辉光 + 深色小徽章 + 桌面端略微放大/置顶；
- 计费/规格切换用分段药丸控件，切换即时改写价格与说明（功能性 JS，非装饰）。

**关键特征**：
- 白是结构色，内容区禁止彩色底
- 渐变产品卡是唯一自由色彩区（150° 粉→紫→蓝为默认配方）
- 药丸（9999px）只给导航与切换控件；CTA 按钮是 8px 圆角的"方感"
- 品牌紫阴影 `rgba(44,30,116,0.16) 0 0 15px` 只给精选物
- 四字体分工：DM Sans（UI）/ Outfit（展示）/ Poppins（中段）/ Roboto（数据）

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 画布 | `#ffffff` | 全站结构底色 |
| 主文本 | `#222222` | 标题、价格 |
| 次文本 | `#45515e` | 正文、说明 |
| 弱文本 | `#8e8e93` | 元信息、占位、角色说明 |
| 深色面 | `#181e25` | 主 CTA 按钮、页脚背景、徽章 |
| 品牌蓝 | `#1456f0` | ✓ 勾选、徽章文字、精选列表头、链接态 |
| 动作蓝 | `#3b82f6` / hover `#2563eb` | 焦点环、交互蓝 |
| 品牌粉 | `#ea5ec1` | **仅**装饰：logo 圆点、渐变配方起点，不上文字/按钮 |
| 渐变配方 | `linear-gradient(150deg, #f5c5ec, #c9b8f7 38%, #8fb4fb)` | 精选卡/CTA 大卡默认底（可微调色相，保持粉→紫→蓝次序与低饱和） |
| 边框 | `#e5e7eb` 组件级 / `#f2f3f5` 分隔级 | 卡边框与发丝线 |
| 辅底 | `rgba(0,0,0,0.05)` | 药丸激活底、次级按钮 `#f0f0f0` |
| 精选列衬底 | `rgba(20,86,240,0.035)` | 对比表中被推荐的那一列 |

**渐变卡内文字一律用近黑 `#18181b` 系**（渐变亮度高，白字对比不足）；卡内次级信息用 `rgba(24,30,37,0.6-0.82)` 分层。

## 3. 字体规则

| 角色 | 字体 | 规格 |
|---|---|---|
| 展示标题 | Outfit 500 | `clamp(38px, 6vw, 80px)` / lh 1.10 |
| 区块标题 | Outfit 600 | 31px / lh 1.50 |
| 卡片题/价格 | Outfit 500–600 | 28px 卡题；44px 价格数字 |
| 中段副题/分组标签 | Poppins 500 | 18–24px |
| 正文/UI/按钮 | DM Sans 400–500 | 14–16px / lh 1.50 |
| 数据单元格 | Roboto 400–500 | 14px + `font-variant-numeric: tabular-nums` |

纪律：**500 是默认强调**，600 给区块题，700 只留给正文强条与 ✓ 记号——标题永不加粗到 700。正文行高统一 1.50（长说明 1.70）。中文回退 `PingFang SC` / `Microsoft YaHei` 必须进字体栈。

## 4. 组件样式

**按钮（双轨制）**
- 主 CTA：`#181e25` 底白字、**8px 圆角**、`11px 20px` 内距、min-height 44px
- 次级：`#f0f0f0` 底 `#333` 字，8px 圆角
- 渐变卡上的 CTA：白底 `#18181b` 字，hover 上浮 1px + 抬升阴影
- 药丸（9999px）**只**用于：导航项、计费/规格分段切换、小徽章——绝不用于主行动按钮

**精选卡（渐变产品卡）**
- 150° 三停渐变底、24px 圆角、品牌紫辉光 `rgba(44,30,116,0.16) 0 0 15px`
- 桌面端 `order: -1` 置顶或 `margin-top: -16px` 微抬升
- 右上角深色药丸徽章（如"最受欢迎"）
- hover：上浮 4–6px，辉光扩散为 `0 12px 26px -6px`

**普通卡**
- 白底 + `#f2f3f5` 1px 边框、20px 圆角、标准阴影 `rgba(0,0,0,0.08) 0 4px 6px`
- hover：上浮 4px + 抬升阴影 `rgba(36,36,36,0.08) 0 12px 16px -4px`

**分段切换控件**
- 容器 `rgba(0,0,0,0.05)` 底、9999px、内距 4px；选项为药丸按钮
- 激活项：白底 + 标准阴影 + 近黑字；非激活 `#45515e`
- 切换行为真实联动数据（价格/说明文本随 data 属性改写）

**对比表**
- 16px 圆角白卡 + 标准阴影；表头 `#fafbfc`、Outfit 16px/600
- 数字列一律 Roboto + tabular-nums；✓ 用品牌蓝 700，缺项用 `—` 浅灰
- 精选列整列衬 3.5% 品牌蓝，hover 行整体 1.5% 黑
- 窄屏：容器内 `overflow-x: auto` + 表格 `min-width`，页面级不产生横向滚动

**FAQ 折叠**：`#f2f3f5` 分隔线；问题 16px/500；"+"指示器开合旋转 45°。

## 5. 布局原则

- 容器 max-width 1160px、24px 内边距；8px 基距
- 区块节奏 64–80px（移动端 48px）
- 三卡画廊：桌面 3 列等距 / ≤1024 单列且**精选卡置顶** / 移动端全宽
- 画廊式留白：卡片之间靠间距区分，不靠边框堆叠；每张卡内部 16–24px 呼吸
- 页脚 `#181e25` 深色四栏 + 50% 白底栏；页脚是唯一允许的大面积深色

## 6. 深度与阴影

| 层级 | 处理 | 用途 |
|---|---|---|
| L0 | 无阴影 | 文本块、纯白区 |
| L1 | `rgba(0,0,0,0.08) 0 4px 6px` | 普通卡、表格、分段激活项 |
| L3 | `rgba(44,30,116,0.16) 0 0 15px` | 精选渐变卡（签名辉光） |
| L4 | `rgba(36,36,36,0.08) 0 12px 16px -4px` | hover 抬升态 |

纪律：**一切阴影不透明度 ≤ 0.16**。阴影是"发光"而非"下坠"——紫调辉光向上、环境影极浅。

## 7. Do's & Don'ts

### Do
- 每页至少一张渐变产品卡/大卡承担"色彩锚点"，其余保持白
- CTA 按钮统一 8px 圆角 + 深色 `#181e25`；药丸只给导航与切换
- 数据（价格、表格、统计）交给 Roboto + tabular-nums
- 精选物三件套：渐变底 + 紫辉光 + 深色徽章
- 分段切换控件必须真实联动可见数据
- 渐变卡内文字用近黑系分层

### Don't
- 不要给内容区上彩色底——白是结构，彩色只属于卡
- 不要把主 CTA 做成药丸（双轨制不可互换）
- 不要标题用 700 字重，不要行高突破 1.50 体系
- 不要阴影超过 0.16 不透明度（轻盈感即品牌）
- 不要品牌粉上文字或按钮（它只活在 logo 与渐变里）
- 不要同一区块混用两种展示字体（Outfit 或 Poppins，二选一）

## 8. 响应式行为

| 断点 | 关键变化 |
|---|---|
| >1024（基准） | 三卡并排、精选微抬升、表格全宽 |
| ≤1024 | 卡组单列（max-width 460px 居中）、精选卡 `order: -1` 置顶 |
| ≤768 | 导航折叠抽屉；展示标题 `clamp(38px, 9vw, 48px)`；切换控件全宽、选项等分；区块距 48px；页脚两栏 |
| ≤480 | 按钮全宽（min-height 44px）；卡内边距收紧；页脚单列 |

底线：展示标题 375px 下 ≥ 38px；触控目标 ≥ 44px；对比表容器内滚动而非页面横向滚动。

## 9. Agent 提示词指南

**起手式**：全页铺白 → 决定哪一张是"精选"→ 给它渐变+紫辉光+徽章 → 其余组件用 1px 浅边框+标准阴影 → CTA 全部深色 8px 圆角 → 数据换 Roboto。

**示例组件提示词**：
- "精选定价卡：150° 粉紫蓝渐变底、24px 圆角、rgba(44,30,116,0.16) 0 0 15px 辉光，右上角 #181e25 药丸徽章'最受欢迎'，卡题 Outfit 28px/600 近黑，价格 Outfit 44px，权益列表每行品牌蓝 ✓，白底 8px 圆角 CTA。"
- "计费切换：外层 rgba(0,0,0,0.05) 9999px 胶囊内两个药丸选项，激活项白底+rgba(0,0,0,0.08) 0 4px 6px 阴影，点击后改写卡片价格与计费说明。"
- "对比表：16px 圆角白卡，表头 #fafbfc，数字列 Roboto tabular-nums，精选列衬 rgba(20,86,240,0.035) 底色，✓ 品牌蓝 700，缺项浅灰 —。"

**迭代心法**：
1. 先问"这页的精选是谁"——渐变与辉光只给它
2. 药丸出现在按钮区 = 立即纠偏（那是导航的形状）
3. 每处阴影超 0.16 就剪掉一半
4. 中文字体栈别忘 PingFang SC / Microsoft YaHei 回退

**适配题材**：定价页、订阅档位、会员体系天然契合；应用矩阵、模板商城、课程套餐同样成立——凡"一排可选方案、其中一个要被推荐"的页面都适用。
