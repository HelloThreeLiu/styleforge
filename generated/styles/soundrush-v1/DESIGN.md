# Design System: 声浪荧光冲 SoundRush（派生自 clickhouse）

> 血统：`clickhouse` → `20260821-soundrush-compose-marathon-landing`（★4.5）→ 本风格。
> 核心命题：把 clickhouse 的"纯黑 + 荧光黄绿 + 巨型性能数字"语言用于**限时挑战与极限活动**——作曲马拉松、黑客松、即兴戏剧节、24 小时漫画日。速度感即视觉本身。

## 1. 视觉主题与氛围

纯黑 `#000000` 画布上，荧光黄绿 `#faff69` 像荧光笔划过控制台——唯一彩色，只做点缀、描边、CTA 与巨型数字。96px/900 的标题有物理质量；72px+ 的统计数字把"成绩"写成宣言；倒计时是页面的心脏。

氛围关键词：48 小时、极限、通宵、公开试听。文案短促带秒表腔（"错过即出局"、"早交不加分，晚交不存在"）。

**关键特征：**
- 纯黑画布（永不用深灰替代）+ 荧光 `#faff69` 唯一彩色（每区一两次点睛）
- Inter 900 超重标题（96px/行高 1.0）——字重即武器
- 巨型统计数字（72px/700–900，一项染荧光为 hot）
- 实时倒计时（等宽荧光数字，天/时/分/秒）
- 森林绿 `#166534` 次级 CTA；按压态 pale yellow `#f4f692` + 内凹阴影
- 炭黑描边卡 `rgba(65,65,65,.8)` 8px 圆角 + 荧光描边 featured 卡
- Inconsolata 终端卡（提交清单/规则）
- 链接 hover 一律变荧光
- 无渐变——对比即张力

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 纯黑 | `#000000` | 画布 |
| 荧光黄绿 | `#faff69` | CTA 底（黑字）、描边、hover、关键字、hot 数字、倒计时 |
| 按压态 | `#f4f692` | active 文字色（配内凹阴影） |
| 森林绿 | `#166534` + `#141414` 边 | 次级转化按钮 |
| 橄榄 | `#4f5100` | ghost 按钮描边 |
| 近黑面 | `#141414` / hover `#3a3a3a` | 深按钮底/终端卡 |
| 炭黑边 | `rgba(65,65,65,.8)` / 深炭 `#343434` 分隔 | 卡与分隔 |
| 文本 | 白 / 银 `#a0a0a0` | 主/次 |

## 3. 字体规则

Inter（400–900，900 为武器档）+ Inconsolata（600，终端卡）。中文回退链按平台底线。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero | 96px | 900 | 行高 1.0；至多一个词染荧光 |
| 区题 | 36px | 600 | |
| 卡题 | 24px | 700 | |
| 巨型数字 | 72px | 700–900 | hot 项 900 荧光 |
| 倒计时 | 44px | Inconsolata 600 | 荧光、tabular |
| 正文 | 16–18px | 400 | 银 |
| 终端 | 15px | Inconsolata 600 | 行高 1.6 |
| 大写标签 | 14px | 600 | 1.4px 字距（silver 区标） |

## 4. 组件样式

- **荧光主 CTA**：`#faff69` 底黑字 4px 圆角；hover 反转深底；active 文字变 `#f4f692` + 内凹 `rgba(0,0,0,.06) 0 4px 4px, rgba(0,0,0,.14) 0 4px 25px inset`
- **森林绿次 CTA** / **橄榄描边 ghost**（同 hover/active 纪律）
- **统计条**：炭边上下夹住的四格数字，hot 项染荧光 900
- **赛道/挑战卡**：`#141414` 底 + 炭边 8px 圆角；featured = 荧光描边 + 反白荧光底药丸标签；卡底 Inconsolata 荧光格式注脚（`solo_track.wav → -14 LUFS`）
- **倒计时**：大写银标签 + 等宽荧光数字 44px + 单位小字
- **终端卡**：顶栏文件名 + `● checked` 荧光状态；正文关键字荧光、注释 `#585858`
- **时刻表**：五格炭边卡，小时数（H+0/H+12…）Inconsolata 荧光 28px
- **冠军墙/档案墙**：四列炭边小卡，届数荧光等宽 + 名字 700 白

## 5. 布局原则

1160px 容器；炭黑上下线夹住统计条（无底色区切换）；卡网 3–5 列 → 1；hero 倒计时紧跟标题。黑底无边框分区——分隔靠 1px 深炭线。

## 6. 深度与阴影

边框即深度（黑底阴影不可见）；唯一阴影 = 按压内凹。荧光描边卡 = 最大强调。

## 7. Do's & Don'ts

### Do
- 每区只给一两处荧光——稀缺即冲击
- 倒计时/巨型数字是页面心脏，必做且要大
- 规则/清单用 Inconsolata 终端卡（含荧光状态行）
- 全部按钮 active 变 pale yellow + 内凹（按压感）
- 链接 hover 一律荧光；文案用秒表腔

### Don't
- 不要荧光大面积背景、不要渐变
- 不要深灰画布（必须纯黑）、不要第二种彩色
- 不要圆角超 8px、不要轻字重标题（display ≥700）
- 不要软阴影（黑底不可见）
- 不要让 hot 数字超过一项（一页一个焦点）

## 8. 响应式行为

1280 时刻表 3 列/墙 3 列；1024 统计 2 列、赛道 2 列、提交区单列；768 导航折叠、时刻表 2 列、倒计时 36px；640 赛道单列；480 全单列、按钮全宽 ≥44px；375 hero ≥34px、倒计时 30px。

## 9. Agent 提示词指南

**起手式**：铺纯黑 → hero 96px/900 标题（一个词染荧光）+ 荧光 CTA + 等宽倒计时 → 炭边统计条（hot 一项荧光）→ 赛道卡（featured 荧光边）→ 时刻表 + 终端卡 → 页脚。

**示例提示词**：
- "hero：#000000 底，96px/900/行高 1.0 白标题（一个关键词 #faff69）；荧光 CTA（#faff69 底黑字 4px 圆角，hover 深底反转，active #f4f692+内凹）+ 倒计时（Inconsolata 44px 荧光 tabular，天/时/分/秒）。"
- "featured 赛道卡：#141414 底 + 1px solid #faff69 边 8px 圆角；药丸标签荧光底黑字；卡底 Inconsolata 荧光格式行。"
- "时刻表卡：炭边卡 + H+0/H+12 小时数（Inconsolata 28px 荧光）+ 白标题 + 银说明。"

**适配题材**：作曲/写作/编程马拉松、黑客松、48 小时漫画日、即兴戏剧节、限时挑战赛——一切"倒计时 + 极限 + 公开成果"的活动页。常规商品页不适用。
