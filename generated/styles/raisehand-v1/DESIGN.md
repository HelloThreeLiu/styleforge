# Design System: 举手画廊 RaiseHand（派生自 figma）

> 血统：`figma` → `20260821-raisehand-volunteer-signup-landing`（★4）→ 本风格。
> 核心命题：把 Figma 的"黑白画廊 + 彩色内容"语言用于**社区活动与参与**类页面——志愿报名、活动一览、社区计划。界面退成画廊白墙，活动本身像画一样发光。

## 1. 视觉主题与氛围

界面层只有黑与白（`#000000` / `#ffffff`），绝不掺第三色。全部色彩来自"内容"：满宽多彩渐变 hero（绿→黄→橙→粉→紫的五停撞色）与每个活动卡专属的渐变色块——画廊的墙越素，画越亮。药丸与正圆的几何、320–540 的微字重、虚线焦点框，让整套 UI 有"设计工具选框"般的精密手感。

氛围关键词：画廊、举手、报名、顺手。文案低门槛反仪式（"不面试、不培训、不打卡"）。

**关键特征：**
- 界面绝对黑白；色彩只来自 hero 渐变与活动内容块
- 可变字体微字重档：320/330/340/450/480/540/700（正文基线 330）
- 药丸（50px）按钮/tab + 正圆（50%）logo/图标钮
- 虚线 2px 焦点描边（编辑器选框隐喻；深/彩底自动换白）
- 1px 黑描边 8px 圆角活动卡：渐变色块 + 白色几何 glyph + 白底信息区
- mono 大写标签（12px/0.6px）
- 黑色满宽页脚 + 白药丸 CTA 收尾
- 玻璃面：黑 8%（浅面）/ 白 16%（彩面）

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 界面双色 | `#000000` / `#ffffff` | 全部 chrome：文本、描边、按钮 |
| hero 渐变 | 电光绿 `#14f195` → 亮黄 `#ffd60a` → 橙 `#ff8a00` → 热粉 `#ff2e88` → 深紫 `#5e17eb` | 满宽五停 118° |
| 活动内容色 | 每卡独立渐变（撞色三停内自由） | 内容块的唯一色彩来源 |
| 玻璃黑 | `rgba(0,0,0,0.08)` | 浅面次级圆钮 |
| 玻璃白 | `rgba(255,255,255,0.16)` | 彩面上药丸/标签（mono 徽章） |

## 3. 字体规则

figmaSans 不可用时以 Inter 可变（wght 100–900）直载，CSS 书写 320/330/340/450/480/540 非标档；figmaMono 用系统链（ui-monospace/SF Mono/Menlo）零 CDN。`font-feature-settings: "kern"` 全局。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero | 86px | 400 | -1.72px、行高 1.00（彩底白字）|
| 区题 | 64px | 400 | -0.96px、行高 1.10 |
| 卡题 | 20px | 700 | 全站唯一 700 处 |
| 正文/副文 | 15–20px | 330 | -0.14px |
| 小标/按钮 | 14–16px | 400–480 | |
| mono 标签 | 10–12px | 400 | uppercase + 0.6px |

## 4. 组件样式

- **活动卡（内容单元）**：1px 黑描边 8px 圆角双段式——上：aspect 16:9 渐变色块 + 白色几何 glyph（圆点/圆环尺寸逐卡变化）；下：白底 mono 类型行 + 20px/700 卡题 + 15px/330 描述 + 黑药丸报名钮 + mono 名额行
- **药丸 tab 条**：1px 黑边框容器内嵌药丸；激活黑底白字；筛选用同构小药丸
- **hero**：满宽五停渐变 + 玻璃白 mono 药丸徽章 + 86px 白标题 + 白药丸/玻璃白药丸双 CTA
- **三步卡**：1px 黑描边 8px 圆角 + mono 药丸步骤号 + 26px/540 标题
- **数字区**：72px/340 大数字（340 的"轻而大"）+ 330 小注
- **黑色页脚**：64px 白标题 + 白药丸 CTA + 四栏（白 20% 分隔线 + mono 栏题）
- **焦点**：`outline: 2px dashed` + 3px offset；彩底元素自动换白色虚线

## 5. 布局原则

1280px 容器；活动网格 4 列 → 2（960）→ 1（560）；画廊式留白（每区像一件展品独立呼吸）；色彩区（hero）与素色区（画廊）交替形成节奏。

## 6. 深度与阴影

背景对比即深度（白卡浮于黑/彩底）；阴影克制到几乎没有——深度来自描边与底色切换。

## 7. Do's & Don'ts

### Do
- 每个内容单元一套独立渐变色块——色彩由活动供给
- 界面元素永远黑白；彩面上的文字/边框用白或玻璃白
- 报名/参与按钮用黑药丸 + 「✓ 已举手」式轻反馈
- 焦点必须虚线；正文字重压在 330 左右
- 页脚用黑色满宽 + 白药丸收尾

### Don't
- 不要给 chrome 加任何第三色（按钮描边内容色也不行）
- 不要方角按钮、不要实线焦点框
- 不要字重跳到 500+/600 的常规档位——用可变字体的微差档
- 不要让活动卡无描边或换圆角（1px 黑边 8px 是画框）
- 不要阴影堆叠

## 8. 响应式行为

960 活动两列/三步单列；768 导航折叠（独立下拉面板）、数字单列；560 活动单列；375 hero ≥34px、按钮全宽、字距收窄。

## 9. Agent 提示词指南

**起手式**：界面全黑白 → hero 铺五停撞色渐变 → 活动做成"渐变块 + 白底信息"的双段描边卡 → 药丸 tab 筛选 → 黑页脚白药丸。

**示例提示词**：
- "活动卡：1px 黑描边 8px 圆角；上半 16:9 渐变块（自选撞色）+ 白色几何圆点 glyph；下半 mono 类型行 + 20px/700 标题 + 15px/330 描述 + 黑药丸钮 + mono 名额。"
- "满宽 hero：118° 五停渐变（#14f195→#ffd60a→#ff8a00→#ff2e88→#5e17eb）；玻璃白 mono 药丸徽章（rgba(255,255,255,.16)+blur）+ 86px/400/-1.72px 白标题 + 白药丸 CTA。"
- "虚线焦点：*:focus-visible { outline: 2px dashed #000; outline-offset: 3px }；彩底元素换 dashed #fff。"

**适配题材**：志愿报名、社区活动一览、工作坊日历、开源项目墙、作品征集——一切"很多内容单元并列、各自值得一张画"的参与型页面。
