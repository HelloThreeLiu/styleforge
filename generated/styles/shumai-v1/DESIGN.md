# Design System: 书脉档案蓝 ShuMai（派生自 stripe）

> 血统：`stripe` → `20260821-shumai-manuscript-dashboard`（★4）→ 本风格。
> 核心命题：把 stripe 的"金融级精密"语言用于**文化与公共档案的进度面板**——古籍数字化、口述史工程、城市档案开放计划。让"慢工程"的台账拥有银行级的确信感。

## 1. 视觉主题与氛围

白净画布上，细字重（300）+ 负字距的大标题压住整个页面；蓝调多层阴影让统计卡像悬浮在黄昏天光里；数字全部 tnum 等宽对齐——"每一页都有账"。深靛蓝区（`#1c1e54`）承载"开放语料"式的公共承诺。

氛围关键词：台账、公开、慢工程、可核对。文案工程化（"每工作日新增约 4,200 页"）而立场坚定（"扫描完成的每一页，都向所有人开放"）。

**关键特征：**
- 深海军蓝 `#061b31` 标题 + slate 正文（`#64748d`/`#273951`）
- 紫色 `#533afd` 唯一交互色；浅紫描边 `#b9b9f9` ghost
- 细字重 300 大标题（48px/-0.96px、32/-0.64px）——轻即权威
- 蓝调双层阴影（`rgba(50,50,93,.25) 0 30px 45px -30px` + 黑近层）——品牌色阴影
- tnum 数字表格 + 索书号等宽字（Source Code Pro）
- 成功徽章（20% 绿底/`#108c3d`）做"进行中"状态
- 深靛蓝 `#1c1e54` 区 + 10% 白边卡（公共开放承诺）
- 侧栏 TOC（激活紫左条 + 5% 紫底）+ 环境阴影表格卡
- 4–6px 保守圆角

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 品牌紫 | `#533afd` / hover `#4434d4` | CTA、链接、进度条、激活态 |
| 深海军蓝 | `#061b31` | 标题 |
| slate | `#64748d` / `#273951` | 正文/标签 |
| 深靛蓝 | `#1c1e54` | 开放承诺区底 |
| 成功绿 | `rgba(21,190,83,.2)/#108c3d/.4` 边 | 状态徽章 |
| 边框 | `#e5edf5` | 卡与分隔 |
| 阴影 | 蓝调双层（远紫近黑）+ 环境 `rgba(23,23,23,.08) 0 15px 35px` | 统计卡/表格卡 |
| 等宽 | Source Code Pro 12px/500 | 索书号/编号/代码 |

## 3. 字体规则

Inter（300/400/500）+ Source Code Pro。`"ss01"` 声明（Inter 无效）。中文回退链按平台底线。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| 大标题 | 48px | 300 | -0.96px、行高 1.15 |
| 区题 | 32px | 300 | -0.64px |
| 卡题 | 22px | 300 | -0.22px |
| 表头 | 10px | 400 | 0.4px 字距微标签 |
| 正文 | 14–18px | 300–400 | |
| 数字 | 全部 tnum | | 统计/表格/日期 |
| 等宽 | 12–13px | 500 | 编号/代码 |

## 4. 组件样式

- **统计卡**：白底 `#e5edf5` 边 6px + 蓝调双层阴影；30px/300/-0.6px tnum 大数字 + 13px slate 小注
- **进度表格卡**：环境阴影 + 10px 微标签表头；行 hover 3% 紫底；编号列等宽；置信度/进度 = 紫色 4px 进度条 + tnum 数字；状态徽章（成功绿/紫描边/灰描边）；tab 筛选 + 搜索 + 空态
- **侧栏 TOC**：激活项 2px 紫左条 + 5% 紫底 + scrollspy
- **时间线**：紫点 + 细线 + 500 字重日期标签
- **深靛蓝开放区**：10% 白边卡 ×3 + 白 ghost 链接（hover 浅紫）
- **徽章行**：成功徽章「第 N 期 · 进行中」+ 中性徽章串开页
- **行式队列**：任务行（名称 + 紫进度条 + 百分比 tnum）

## 5. 布局原则

1080px 容器；两栏主体（200px 侧栏 + 内容）在 992 转单列；统计 4 列 → 2 → 1；白/深靛蓝两段式节奏。

## 6. 深度与阴影

蓝调双层阴影是唯一的大浮起（统计卡）；表格用环境阴影；深区靠 10% 白边。负 spread 保持阴影纵向收束。

## 7. Do's & Don'ts

### Do
- 用 tnum 处理一切数字——档案面板的对齐即诚实
- 每个条目配可核对的编号（等宽字索书号/档案号）
- 进度用细紫条 + 数字，不用粗块
- 深靛蓝区放"开放承诺"（API/数据集/素材包三卡）
- 大标题用 300 细字重——工程越严肃，标题越轻

### Don't
- 不要粗字重大标题（300/细是身份）
- 不要中性灰阴影（必须蓝调）
- 不要圆角超 8px、不要药丸
- 不要纯黑标题（必须 `#061b31`）
- 不要让表格溢出页面（容器内横滚）

## 8. 响应式行为

992 主体单列、统计两列、深区卡单列；768 导航折叠、表格容器内横滚；480 统计单列、按钮全宽；375 标题 ≥30px、字距 -0.6px。

## 9. Agent 提示词指南

**起手式**：白底 → 徽章行 + 48px/300/-0.96px 标题 → 蓝调阴影统计卡 ×4（tnum）→ 两栏：TOC 侧栏 + 表格卡（tab+搜索+徽章+进度条）→ 深靛蓝开放承诺区 → 页脚。

**示例提示词**：
- "统计卡：白底 1px #e5edf5 边 6px 圆角 + rgba(50,50,93,.25) 0 30px 45px -30px, rgba(0,0,0,.1) 0 18px 36px -18px 阴影；数字 30px/300 tnum + slate 小注。"
- "档案表：10px 微标签表头；行 = 等宽档案号 + 名称（附 10px 小字副注）+ 紫色 64px×4px 置信度条 + tnum 百分比 + 状态徽章（绿/紫描边/灰描边）。"
- "深靛蓝开放区：#1c1e54 满宽，32px/300/-0.64px 白标题 + 三张 1px rgba(255,255,255,.1) 边卡 + 白链接 hover #b9b9f9。"

**适配题材**：古籍/档案数字化、口述史工程、开放数据计划、公共图书馆工程、博物馆数字化——一切"慢工程 + 公开台账"的文化基建。
