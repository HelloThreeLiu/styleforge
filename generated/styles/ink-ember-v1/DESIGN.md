# Design System: Ink & Ember（墨与烬 · 炉火报纸风）

> 派生自页面 `20260818-original-ink-ember-radio`（★4.5，original——本风格为该页原创语言的正式沉淀）。
> 核心命题：一张被炉火照亮的旧报纸。编辑排版的骨架（衬线巨字、粗墨线、分栏）注入篝火的温度（烬火橙）与手工的顽皮（贴纸、微斜、硬投影）。

---

## 1. 视觉主题与氛围

奶油纸底上的活字印刷。`#f6efe2` 的纸、`#221b12` 的焦墨、`#f4481e` 的烬火橙——三种材料讲完整个故事。2px 粗墨线是结构语言（边框、分隔、栏线一视同仁），阴影是**无模糊的硬偏移**（`5px 5px 0`），像铅字压在纸上的痕迹。整体气质：安静但不冷淡，复古但不怀旧，克制中带一点手工的顽皮。

标志性的三重顽皮：

- **贴纸徽章**：白底墨边 + 硬投影 + `rotate(-2.5°)`，像随手贴上去的标签；
- **微斜卡片**：关键装置（播放机/表单/插图）整体旋转 1–1.5°，打破网格的严肃；
- **描边空心大数字**：章节序号用 88px `-webkit-text-stroke` 空心衬线，透明度 0.35，报纸副刊的版面记忆。

**关键特征**：
- 奶油纸 × 焦墨 × 烬火橙三色材料，全站唯一彩色是橙
- 2px 墨线贯穿一切结构（边框即设计）
- 硬偏移投影、无模糊、无圆角（≤2px）
- 衬线巨字标题（斜体 + 橙 = 词级强调公式）
- 贴纸徽章与微斜卡片的手工顽皮
- 焦墨反转页脚（墨底纸字，hover 变橙）

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 纸底 | `#f6efe2` | 全站画布 |
| 深纸 | `#efe5d1` | 分区背景（特性行/次级区） |
| 焦墨 | `#221b12` | 标题、正文、边框、页脚底 |
| 淡墨 | `#6f6250` | 次级文本 |
| 极淡墨 | `#c9bda8` | 行内分隔线 |
| 烬火橙 | `#f4481e` | **全站唯一彩色**——只给"热"的东西：行动按钮、直播灯、强调词、hover |
| 烬火深 | `#c93512` | 橙的按压态 |
| 焦墨反转 | 墨底 + `rgba(246,239,226,0.45–0.85)` 纸字 | 页脚、跑马灯条 |

橙色纪律：一次页面上橙色出现在——主 CTA、斜体强调词、live 指示灯、波形采样、hover 态。**橙色 = 温度与行动**，从不当大面积底色（页脚的"热"由墨承担，橙色只做链接 hover）。

## 3. 字体规则

| 角色 | 字体 | 规格 |
|---|---|---|
| 展示巨字 | Fraunces 700 | `clamp(48px, 6.5vw, 84px)` / lh 1.02 / ls -0.015em |
| 区块标题 | Fraunces 700 | `clamp(36px, 4.5vw, 56px)` / lh 1.05 |
| 卡片/装置标题 | Fraunces 700 | 24px |
| 词级强调 | Fraunces italic 700 | 继承宿主字号，染烬火橙 |
| 章节序号 | Fraunces italic 700 | 88px，空心描边，透明度 0.35 |
| 正文/UI | Inter 400–600 | 13–17px / lh 1.6–1.65 |
| 眉题/徽章字 | Inter 600 | 12px / ls 0.12–0.22em / uppercase |

**强调公式**：标题里挑**一个词**做成斜体 + 烬火橙——每级标题至多一处，两处即破。回退栈：Fraunces → Georgia / Songti SC / SimSun；Inter → 系统无衬线。

## 4. 组件样式

**贴纸徽章（sticker）**
- 白纸底 + 2px 墨边 + `3px 3px 0` 硬投影 + `rotate(-2.5°)`
- 12px/600/0.12em 字距；橙底变体（`--ember` 底纸字）用于"热"的标签，可反转旋转角

**按钮**
- 2px 墨边 + 纸底墨字 + `5px 5px 0` 硬投影
- hover：`translate(2px,2px)` + 阴影缩至 `2px 2px 0`——**按压感**代替浮起感
- 主行动：橙底纸字，hover 加深为 `--ember-deep`
- 无圆角（或 ≤2px），字距 0.04em

**卡片（装置卡/内容卡）**
- 2px 墨边 + 纸底 + 硬投影；关键装置整体 `rotate(1.2°)`
- hover 位移逻辑与按钮一致（右下位移 + 阴影收缩）
- 卡内分区用 2px 墨线或 1px 极淡墨线分层

**跑马灯条（ticker）**
- 焦墨底反白，上下 2px 墨边，`width: max-content` 双份内容 + `translateX(-50%)` 26s 无限滚动
- 关键词（今晚/新增/预告）用 `<b>` 染橙

**波形/脉冲（声音隐喻）**
- 波形：flex 条组，高度 18%↔92% 呼吸动画，每 3 根染 1 根橙
- LIVE 灯：9px 橙点 1.6s 透明度脉冲

**CSS 场景画（无图片封面）**
- 卡片封面区高 ~150px + 2px 墨边下缘，用渐变 + 伪元素作画：
  - 雨夜：深底 + 75° 细密雨纹（repeating-linear-gradient）+ 描边灯箱字
  - 灯下：深底 + 径向橙光晕
  - 火焰：橙色三角 + drop-shadow 辉光 + 柴堆横条
- 纪律：每幅画只允许"墨 + 一处橙"

**页脚（焦墨反转）**：墨底、纸字四栏、栏题 12px/0.18em 半透明纸色，链接 hover 变橙。

## 5. 布局原则

- 容器 max-width 1120px；8px 基距；区块距 72–96px
- 英雄区双栏 1.15fr : 1fr（左字右装置）；纸面点阵纹理（`radial-gradient` 22px 网格、13% 墨点）只给英雄区
- 内容网格 3 列 → 2 列（≤768）→ 1 列（≤480）
- 特性行：深纸分区 + **左墨线分栏**（首栏无线），报纸经济版的栏式
- 章节头：左题右描边大数字的图文配重
- 页脚四栏 2fr : 1fr : 1fr : 1fr

## 6. 深度与阴影

| 层级 | 处理 | 用途 |
|---|---|---|
| L0 | 无 | 纸面平铺 |
| L1 | `3px 3px 0 var(--ink)` | 贴纸、小控件 |
| L2 | `5px 5px 0 var(--ink)` | 按钮、卡片、装置 |
| 反转 | 焦墨底 | 跑马灯、页脚 |

**唯一阴影形态**：硬偏移、零模糊、墨色。禁止 `blur`、禁止半透明软影——模糊是屏幕的，不是纸的。深度感来自"按压"：hover 向右下位移同时阴影收缩，模拟被按进纸里。

## 7. Do's & Don'ts

### Do
- 2px 墨线贯穿一切结构——边框、分隔、栏线粗细一致
- 每个标题用"斜体 + 橙"强调至多一个词
- 关键装置微斜 1–1.5°、贴纸徽章 -2.5°，其余保持水平
- hover 一律"按压"（右下位移 + 阴影收缩）
- 场景画只用墨 + 一处橙
- 动效只保留与内容语义同构的三种：脉冲（在场）、波形（声音）、跑马灯（播出）

### Don't
- 不要模糊阴影与软渐变投影（毁掉印刷感）
- 不要第二彩色（火焰只有一种温度）
- 不要圆角 > 2px（火柴盒没有圆角）
- 不要白底纯白 `#ffffff`（纸是奶油色）或纯黑 `#000000`（墨是暖的）
- 不要无衬线标题或衬线正文（字角色不可互换）
- 不要滥用橙色——橙色出现即意味着"热/行动/在场"

## 8. 响应式行为

| 断点 | 关键变化 |
|---|---|
| >768（基准） | 英雄双栏、场景 3 列、特性行 4 栏 |
| ≤768 | 导航折叠（墨边按钮）；英雄单栏；场景 2 列；特性 2 栏；页脚 2 栏 |
| ≤480 | 场景/特性单列；按钮全宽；**装置卡旋转归零**（微斜在小屏显得错位）；描边数字缩至 56px |

底线：展示字号 375px 下 ≥ 48px clamp 下限；触控目标 ≥ 44px；跑马灯与波形在移动端保留（它们是气质本体）。

## 9. Agent 提示词指南

**起手式**：铺奶油纸 → 全站拉好 2px 墨线骨架 → 选定"热"元素（主 CTA + 强调词 + 指示灯）给橙 → 关键装置贴上贴纸与微斜 → 页尾焦墨反转。

**示例组件提示词**：
- "贴纸徽章：#f6efe2 底、2px #221b12 边框、3px 3px 0 硬投影、rotate(-2.5deg)，字 12px/600/字距 0.12em。"
- "主按钮：橙底 #f4481e 纸色字、2px 墨边、5px 5px 0 墨色硬投影；hover 时 translate(2px,2px) 且阴影缩为 2px 2px 0。"
- "跑马灯：#221b12 底反白 14px，双份内容无缝 26s 滚动，关键词 b 标签染 #f4481e。"
- "场景卡封面：高 150px 深色底，75° repeating-linear-gradient 雨纹，中央描边灯箱字 OPEN + 32px 纸色辉光。"

**迭代心法**：
1. 截图眯眼看——应该只剩"纸、墨、一点橙"三个层次
2. 每处阴影问一句"它是铅字压出来的吗"——不是就删
3. 橙色每多一处，页面冷一度；多余的橙换成墨
4. 中文长标题慎用斜体强调（CJK 斜体是伪斜），可只染橙不斜

**适配题材**：电台/播客/音乐/夜间产品天然契合；独立出版物、咖啡/精酿品牌、手作市集、文学杂志同样成立——凡"有人味、有温度、反数字化光滑"的内容都适用。
