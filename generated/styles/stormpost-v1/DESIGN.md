# Design System: 风暴指挥台 StormPost（派生自 sanity）

> 血统：`sanity` → `20260821-stormpost-weather-watch-dashboard`（★4.5）→ 本风格。
> 核心命题：把 Sanity 的"近黑指挥中心 + 珊瑚红 CTA + 电蓝信号"语言用于**公民监测网络**——天气联防、空气质量、水位观测、地震预警。让业余站点的数据拥有专业控制室的权威感。

## 1. 视觉主题与氛围

`#0b0b0b` 近黑画布上，无彩灰阶承载全部结构，三个信号色各司其职：珊瑚红 = 行动（上报按钮）、电蓝 = 激活（hover/焦点）、纯红 = 警报。站点表是主体，预警时间线与实时 mono 数据流是心跳。琥珀黄作为绿/红之间的"注意"中间态。

氛围关键词：联防、阈值、哨所、比官方快。文案有社区底气（"比预警短信早一步，比新闻快一夜"）并附免责（"避险请以官方预警为准"）。

**关键特征：**
- 近黑画布 + 纯无彩灰阶（`#212121` 卡 + `#353535` 边）
- 珊瑚红 `#f36458` 药丸唯一 CTA（hover 电蓝）；电蓝 `#0052ef` 全局 hover/focus
- 纯红 `#dd0000` 警报（横幅四边框 + 4px 左粗条 + 等级标签）；霓虹绿 `#19d600` 在线态；琥珀 `#ffb224` 注意态
- 站点监测表：mono 站号（行 hover 变电蓝）+ 三态药丸 + tab 筛选 + 搜索（focus 蓝环 + 深青底 `#072227`）
- 预警时间线：mono 时间列 + 事件行（crit 标题染珊瑚红）
- **实时 mono 数据流**：每 2–5 秒 prepend 一行，超阈值读数染琥珀，上限滚动
- 三档柱图（灰干/电蓝湿/纯红强）
- 48px/-1.68px 极端负字距标题；药丸 99999px + 卡 6px 圆角断层

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 画布/表面/边 | `#0b0b0b` / `#212121` / `#353535` | 色度深度三阶 |
| 文本 | 白 / 银 `#b9b9b9` / 灰 `#797979` | 三层 |
| 珊瑚红 | `#f36458` | 唯一 CTA（上报/上报观测） |
| 电蓝 | `#0052ef` | hover/激活/focus ring + 数据"湿润"档 |
| 纯红 | `#dd0000` | 警报横幅/警报药丸实底/柱图强档 |
| 霓虹绿 | `#19d600`（10% 底药丸） | 在线/正常态 |
| 琥珀 | `#ffb224`（10% 底） | 注意态/超阈值读数 |
| 深青 | `#072227` | 输入 focus 底 |

## 3. 字体规则

Space Grotesk（sanity 官方替身）+ IBM Plex Mono。字重 400/425 为主，600 仅 11px 大写标签。

| 角色 | 字号 | 备注 |
|---|---|---|
| 页题 | 48px/400/-1.68px | 行高 1.08 |
| 卡题 | 24px/425/-0.24px | |
| 正文 | 15–18px/400/1.5 | 银灰 |
| mono | 11–13px | 站号/时间戳/读数/表头；数据流 12px/1.7 |

## 4. 组件样式

- **预警横幅**：`#212121` 底 + 纯红 1px 四边框 + 4px 左粗条 + 纯红 mono 等级标签 + 白标题 + ghost 按钮——仪表盘第一眼
- **站点表**：mono 表头；行 = mono 站号 + 白位置 + 银读数 + 三态药丸（绿 10% 底/琥珀 10% 底/纯红实底白字）；行 hover 白、站号变电蓝
- **实时数据流**：mono 行（时间/站号/读数三列），新行 prepend、上限裁剪、warn 读数琥珀
- **时间线**：56px mono 时间 + 事件（700 白标题 + 灰说明），crit 染珊瑚红
- **柱图**：24 根 3px 柱三档色 + mono 刻度行
- **ghost 按钮**：`#212121` 底 5px 圆角 hover 电蓝
- **状态药丸**（页头）：绿点 + 银字 + mono 同步时间

## 5. 布局原则

1280px 容器；board 2fr:1fr（主表 + 侧栏时间线/柱图/数据流）；联防计划 12px 圆角三卡；8px 基础、区间 64–88px。

## 6. 深度与阴影

色度深度（表面阶）+ 边框容器，零偏移阴影；唯一阴影 = focus 蓝环。

## 7. Do's & Don'ts

### Do
- 预警横幅置顶（红色纪律：纯红只在警报）
- 数据流必须"活"——定时 append 是页面心跳
- 站号/时间/读数全 mono；tabular 对齐
- 页脚放免责声明（民间监测的诚实）
- 珊瑚红 CTA 全页仅一个主入口

### Don't
- 不要灰阶加冷暖偏色；不要偏移阴影
- 不要圆角 13px–99998px（6px 直跳药丸）
- 不要绿/红同组件混用
- 不要让数据流无限增长（上限裁剪）
- 不要 700+ 字重

## 8. 响应式行为

960 board 单列；768 导航折叠、页脚两栏；480 搜索全宽、表格容器横滚；375 页题 34px、卡 padding 收窄。

## 9. Agent 提示词指南

**起手式**：铺 `#0b0b0b` → 页头状态药丸 + 48px/-1.68px 标题 → 纯红预警横幅 → board（站点表 + 时间线/柱图/数据流）→ 联防三卡 → 免责页脚。

**示例提示词**：
- "预警横幅：#212121 底 + 1px solid #dd0000 + 4px 左粗条；#dd0000 底 mono 标签「YELLOW ALERT」+ 白 16px 标题 + 灰说明 + ghost 按钮。"
- "实时数据流：mono 12px/1.7 三列（时间 #797979/站号/读数白），JS 每 3 秒 prepend，超阈值读数 #ffb224，超 12 行裁尾。"
- "三态药丸：正常 = #19d600 字 + rgba(25,214,0,.1) 底；注意 = #ffb224 字 + 10% 底；警报 = #dd0000 实底白字。"

**适配题材**：天气/空气/水位/地震联防网、社区环境监测、观鸟记录台、业余无线电网络——"民间传感器 + 阈值警报 + 比官方快"的监测面板。
