# Design System: 榫卯暖木 SunMao（派生自 zapier）

> 血统：`zapier` → `20260821-sunmao-workflow-login`（★4）→ 本风格。
> 核心命题：把 zapier 的"奶油白 + 橙色强调 + 三字体"语言用于**开源/社区工具的登录与入口页**——自托管引擎、社区平台、互助网络的门面。温暖的手工感对冲开发者工具的冷感。

## 1. 视觉主题与氛围

奶油白 `#fffefb` 像木工台上的图纸，沙色边框是榫卯的缝，橙色 `#ff4f00` 是唯一的钉子。登录卡居右、叙事居左——左边讲"我们是谁"的故事，右边是进门的门。集成对卡（app 图标 + 箭头）把"连接"具象化，inset 下划线 tab 是签名细节。

氛围关键词：连接、社区、自托管、非营利。文案有木工隐喻（"两块木头咬合，不用一根钉子"）与社区立场（"数据不出门"）。

**关键特征：**
- 奶油白画布 + 暖近黑 `#201515` + 沙色边框 `#c5c0b1`（零阴影结构）
- Zapier Orange `#ff4f00` 唯一强调（主 CTA/激活下划线/focus）
- 三字声：宽几何展示（Bricolage 替 Degular，56px/500/行高 0.90）+ Inter UI + 细衬线编辑体（Cormorant，-1.6px）
- **inset box-shadow 下划线 tab**（橙激活/沙 hover，无 border-bottom）
- 集成对卡：色块 app 图标 + 箭头 + 触发说明 + 大写运行数微标
- 登录卡：沙边 5px 圆角 + 橙主按钮（4px）+ 深色大 CTA（20px 24px/8px，hover 沙底）
- 反向下划线链接（默认无、hover 有）
- 深色页脚 `#201515` 反白 + 14px 圆角社交钮

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 奶油白 | `#fffefb`（次级面 `#fffdf9`） | 画布 |
| 暖近黑 | `#201515` | 文本/深按钮/页脚 |
| 橙 | `#ff4f00`（hover `#e64700`） | 唯一强调 |
| 暖中性 | 正文 `#36342e` / 弱 `#939084` / 沙 `#c5c0b1` / 浅沙 `#eceae3` | 边框即结构 |
| tab 下划线 | `rgb(255,79,0) 0 -4px 0 0 inset` / 沙 hover | 签名 |

## 3. 字体规则

Degular → Bricolage Grotesque（宽几何 500/600）；Inter（400–600）；GT Alpina → Cormorant（300 细衬线 + -0.8~-1.6px）。中文回退链按平台底线。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| 展示 | 56px | 500 | 行高 0.90 压缩块；≤40px 移动 |
| 编辑体 | 40px | 300 | -1.6px 细衬线位 |
| 卡题 | 24px | 600 | -0.48px |
| 正文 | 16px | 400 | -0.16px |
| 大写微标 | 11–12px | 600 | 0.5px（运行数/编号）|

## 4. 组件样式

- **登录卡**：`#fffdf9` + 沙边 5px；输入（focus 橙边）；橙主按钮（8px 16px/4px）+ 「或」分隔（沙线）+ 深色大 SSO 按钮（20px 24px/8px，hover 沙底黑字）；页脚小字链接
- **inset tab**：透明底 12px 16px；激活 `rgb(255,79,0) 0 -4px 0 0 inset`；hover 沙下划线
- **集成对卡**：34px 品牌色圆角块（首字母/单字）+ 箭头 + 16px/500 名称 + 触发说明 + 大写运行数微标（`本周运行 12,408 次`）
- **叙事统计**：48px/500 数字（680+ 连接器 / 1.2M 运行 / 3,400 模板）
- **编辑体块**：40px/300/-1.6px 大字（一句斜体染橙）+ 三段正文
- **深色页脚**：链接沙色 hover 白；14px 圆角社交圆钮（沙边）

## 5. 布局原则

1200px 容器；登录区 1.1fr:1fr 双栏（991 单列卡居中）；集成卡 3 列（450 单列）；沙线分隔各区（无底色切换）。

## 6. 深度与阴影

零投影——沙色边框即容器；唯一"阴影"是 tab 的 inset 下划线。触觉来自边框与字重。

## 7. Do's & Don'ts

### Do
- 登录页配左栏叙事（统计 + 编辑体）——门面要有故事
- 集成/连接用"图标对 + 箭头"卡具象化
- tab 用 inset 阴影下划线（不用 border-bottom）
- 大 CTA 保持宽绰 padding（20px 24px）
- 品牌色 app 图标块是内容数据（可为多色）

### Don't
- 不要投影卡、不要药丸主按钮
- 不要橙做大面积背景或边框装饰
- 不要冷灰中性（永远沙色暖调）
- 不要衬线体做功能 UI（编辑体仅叙事）
- 不要正字距展示标题（0.90 行高 + 紧排是身份）

## 8. 响应式行为

991 登录区单列、编辑区单列、集成 2 列；768 导航折叠；600 统计缩小；450 集成单列、按钮全宽、卡减 padding；375 标题 34px、编辑体字距收窄。

## 9. Agent 提示词指南

**起手式**：铺奶油白 → 左叙事（大写 kicker + 56px/0.90 标题 + 细衬线句 + 统计）右登录卡（沙边 5px + 橙/深双按钮）→ inset tab 集成区 → 编辑体块 → 深色页脚。

**示例提示词**：
- "登录卡：#fffdf9 底 1px #c5c0b1 边 5px 圆角；输入沙边 focus 橙；橙主按钮（#ff4f00 4px 圆角 8px 16px）+ 沙线「或」分隔 + 深色大按钮（#201515 底 20px 24px 8px 圆角 hover #c5c0b1）。"
- "inset tab：透明底 12px 16px；激活 box-shadow rgb(255,79,0) 0 -4px 0 0 inset；hover rgb(197,192,177) 同款。"
- "集成对卡：34px 品牌色圆角块（首字）+ → + 下一块；16px/500 名称 + 14px 沙说明 + 12px/600/0.5px 大写运行数。"

**适配题材**：开源工具登录页、社区平台入口、自托管服务门面、互助网络首页——"温暖 + 连接 + 有立场"的工具门面。
