# Design System: 百家薄荷棚 ShedShare（派生自 mintlify）

> 血统：`mintlify` → `20260821-shedshare-tool-library-marketing`（★4.5）→ 本风格。
> 核心命题：把 mintlify 的"绿白云雾 + 全药丸 + 文档级清爽"语言用于**社区共享与互助网络**——工具棚、技能交换、邻里计划。轻盈得让"加入"这件事看起来毫不费力。

## 1. 视觉主题与氛围

白底上浮着一团绿白云雾（径向浅绿→白渐变），像清晨社区花园的雾气。一切可交互的形状都是完整药丸（9999px），一切标签都由 Geist Mono 大写书写——"技术档案感"与"邻里温暖"的反差是本风格的趣味核心。

氛围关键词：共享、邻里、零门槛、非营利。文案直接给出价值观数字（"¥0 会员费"、"0 条广告"）。

**关键特征：**
- 绿白云雾大气渐变 hero（径向浅绿 `#d4fae8` → 透明）
- 全药丸签名：按钮/输入/徽章/周期切换器一律 9999px
- 5% 透明边框白上白（无灰底色区）；16px 卡 / 24px 特写卡
- Geist Mono 12px/uppercase/0.6px 技术标签（`avg pickup: 4 min` 式数据注脚）
- 紧负字距标题（64px/600/-1.28px）+ 三字重（400/500/600）
- 品牌绿 `#18E299` 仅 CTA/hover/focus，从不当装饰填充
- trust bar：`#fafafa` 16px 圆角灰度徽标网格
- 深色 CTA 圆角盒（`#0d0d0d` 24px 圆角 + 药丸邮箱输入 focus 绿边）

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 近黑 | `#0d0d0d` | 文本与深色 CTA 盒 |
| 白 | `#ffffff` | 画布 |
| 品牌绿 | `#18E299` / 浅绿面 `#d4fae8` / 深绿字 `#0fa76e` | 唯一强调：CTA、hover、focus、徽章底 |
| 灰阶 | `#333/#666/#888` | 正文/次级/占位 |
| 边框 | `rgba(0,0,0,.05)` 标准 / `.08` 交互 | 白上白分离 |
| 阴影 | 卡 `rgba(0,0,0,.03) 0 2px 4px`；按钮 `.06 0 1px 2px` | 耳语级 |

## 3. 字体规则

Inter（400/500/600）+ Geist Mono（500/600 大写标签）。中文回退链按平台底线。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero | 64px | 600 | -1.28px、行高 1.15 |
| 区题 | 40px | 600 | -0.8px |
| 步骤题 | 20px | 600 | -0.2px |
| 正文 | 14–18px | 400 | 1.5 行高 |
| mono 标签 | 12px | 500 | uppercase + 0.6px（数据注脚、状态行）|

## 4. 组件样式

- **步骤/feature 卡**：白底 5% 边框 16px（特写 24px）圆角 + 耳语阴影，hover 边框加深至 8%；浅绿圆角图标块
- **数据注脚**：Geist Mono 大写一行（`fixed rate: 87%`）置于卡底——统计的档案化表达
- **trust bar**：六格 `#fafafa` 5% 边框 16px 圆角灰字徽标（社区/合作方名）
- **数字条**：48px/600/-1px 大数字（含"¥0"式价值观数字）+ 灰小注
- **周期/分段切换**：mono 药丸分段器（深色激活态）
- **深色 CTA 盒**：`#0d0d0d` 24px 圆角、`#141414` 药丸输入（8% 白边，focus 绿边）+ 绿药丸按钮 +「✓」反馈
- **徽章**：10% 绿底绿字药丸（`· 27 个社区 ·` 式中点分隔数据串）

## 5. 布局原则

1200px 容器；区距 48–96px；步骤卡 3 列 → 1 列；hero 云雾以径向渐变居中渲染溢出裁切。白上白全页无灰底分区。

## 6. 深度与阴影

几乎无阴影——5% 边框 + 留白承担分离；唯一的深色区是页尾 CTA 盒（对比反转）。绿云雾是唯一的"大气层"。

## 7. Do's & Don'ts

### Do
- 用数据注脚（mono 一行）给每个功能区收尾
- 数字条里放一个价值观数字（¥0 / 0 广告 / 0 门槛）
- 合作方/社区做成灰度 trust 徽标格
- 加入/订阅的邮箱输入永远药丸 + focus 绿边
- 文案零门槛化（"没有管理员，只有一块共享白板"）

### Don't
- 不要灰底色分区、不要重阴影
- 不要把绿色做成大面积填充（CTA 盒内绿按钮除外）
- 不要方形按钮、不要 600 以上的字重
- 不要让 mono 标签说人话（保持数据腔：`join: open-day · sat 10:00`）

## 8. 响应式行为

1024 卡片两列/trust 三列；768 导航折叠、统计/卡片单列、CTA 盒收边距；480 邮箱输入全宽；375 hero ≥30px、字距收窄。

## 9. Agent 提示词指南

**起手式**：白底 → hero 顶部绿白云雾（浅绿径向）→ 全药丸交互 → 每卡配 mono 数据注脚 → 页尾深色 CTA 圆角盒。

**示例提示词**：
- "hero：白色背景 + 1100px 径向浅绿云雾（#d4fae8 90%→40%→透明）；浅绿药丸徽章 + 64px/600/-1.28px 标题 + 深色/白色双药丸 CTA。"
- "步骤卡：24px 圆角白卡 + 药丸步骤号（浅绿底深绿字 mono）+ 20px/600 题目 + 4px 圆角行内代码标签。"
- "深色 CTA 盒：#0d0d0d 24px 圆角 + 药丸邮箱输入（#141414 底 8% 白边 focus 绿）+ 绿药丸按钮 + ✓ 反馈。"

**适配题材**：工具共享、技能交换、社区互助、开放街道计划、志愿网络——一切"让加入变得轻"的社区型产品。
