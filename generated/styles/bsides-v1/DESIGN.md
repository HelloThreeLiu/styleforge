# Design System: B面曲目志 BSides（派生自 vinyl-noir-v1）

> 血统：`spotify` → `spotify-travel-blog`（★4）→ `vinyl-noir-v1` → `20260821-bsides-recordstore-blog`（★4.5）→ 本风格。
> 核心命题：把"近黑播放器语言"再向前推一步——**一切长内容皆专辑、一切章节皆曲目**。口述史、播客、课程、导览，凡能"一集一集听/读"的内容，都装进这套语法。

## 1. 视觉主题与氛围

近黑 listening room。三层炭黑（`#121212 / #181818 / #1f1f1f`）构成房间，UI 无彩，色彩只由内容封面供给。每个内容单元（一期、一家店、一个故事）拥有一套独立的三停撞色渐变封面，像唱片架上并肩而立的不同专辑。页面底部永远横着一条"正在播放"——它告诉访客：这个网站是用来**听**的，不是用来刷的。

氛围关键词：深夜电台、口述、档案馆、慢内容。文案是录音质感的（"每家唱片店，都有一张你没听过的 B 面"），数据是严肃的（217 位讲述者、400 小时原始录音）。

**关键特征：**
- 三层炭黑 + 唯一功能绿 `#1ed760`（播放/激活/CTA/进度，绿底黑字）
- 内容单元 = 专辑卡：三停撞色渐变封面 + EP mono 角标 + hover 浮现 44px 绿色播放键
- tracklist 章节语法：`#` 序号（hover 绿）｜标题 700 + 讲述人 12px 灰｜关键词列｜时长 tabular 右对齐
- 固定"正在播放"条：左封面缩略+信息省略、中播放键+进度条、右状态 mono
- 首屏旋转唱片：conic 唱纹 + 三停渐变 label + 20–30s 慢转 + 重阴影
- 绿黑渐变订阅盒是绿色唯一大面积形态
- 药丸按钮 + 大写字标（uppercase + 1.4–2px 字距）

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 画布/容器/交互面 | `#121212` / `#181818` / `#1f1f1f` | 三层舞台 |
| hover 微亮 | `#282828` / `rgba(255,255,255,.03)` | 唯一亮化手段 |
| 功能绿 | `#1ed760`（hover `#3be477`） | 播放键、CTA、进度、序号 hover、徽章 |
| 文本 | 白标题 / `#b3b3b3` 次级 | 字重二进制 700/400 |
| 分隔 | `#4d4d4d` / 行间 6% 白 | 表头线 / 行分隔 |
| 封面渐变 | 135°–160° 三停饱和撞色 + 底部 45% 黑压暗 | 每个内容单元一套，页面唯一自由色彩 |
| 订阅盒 | `linear-gradient(135deg, #1f4e3e, #233b2b)` | 绿色唯一大面积例外 |
| 徽章 | 2px 圆角、绿字绿边 12% 绿底 | "最新上线"类状态 |

## 3. 字体规则

回退栈：`'SpotifyMixUI', 'Inter', 'Helvetica Neue', 'PingFang SC', 'Microsoft YaHei', sans-serif`（必须带系统回退）。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| 英雄大标题 | clamp(40px, 5vw, 64px) | 700 | 行高 1.08、-0.02em；至多染绿**一个行动语义词** |
| 区块标题 | 24px | 700 | |
| 卡片标题 | 16px | 700 | |
| 正文/列表 | 14–16px | 400 | 次级一律 `#b3b3b3` |
| 按钮 | 13–14px | 700 | uppercase + 1.4–2px 字距 |
| mono 角标/状态 | 10–12px | 700 | EP 号、时长、许可状态 |
| 数据列 | tabular-nums | 400 | 时长、序号必须等宽对齐 |

## 4. 组件样式

- **专辑卡（内容单元）**：`#181818` 底 8px 圆角无描边；封面 aspect 1:1 渐变 + 压暗 + 白色 mono EP 角标；hover 背景 `#282828` 并右下浮现 44px 绿圆播放键（重阴影 `rgba(0,0,0,.3) 0 8px 8px`）
- **tracklist（章节单）**：`#181818` 容器 8px 圆角；表头 12px 灰 + `#4d4d4d` 底线；行 = 序号（hover 绿）+ 标题/讲述人 + 关键词 + 时长右对齐 tabular；行 hover 3% 白
- **正在播放条（签名）**：fixed 全宽 76px + `#181818` + 顶 1px 黑描边 + `rgba(0,0,0,.5) 0 8px 24px`；三段式（信息/控制/状态）；36px 白圆播放键 hover 绿；4px 进度条已播白 hover 绿可点击跳转
- **旋转唱片（首屏装置）**：conic 唱纹渐变 + inset 暗角 + 中心三停渐变 label + `rgba(0,0,0,.5) 0 8px 24px`；24s 线性匀速旋转
- **按钮**：全药丸；主 = 绿底黑字 hover 提亮放大 1.04；描边 = `#7c7c7c` hover 白；一律大写
- **绿黑订阅盒**：渐变底 + 邮箱药丸（focus 绿边）+ 绿底黑字按钮

## 5. 布局原则

- 容器 max-width 1160px / 24px padding；区块间距 48px；网格间距紧凑 16–18px（暗色压缩）
- 首屏左文右盘（1.2fr : 1fr）；内容网格 4 列 → 2 列（≤768）→ 2 列窄距 12px（≤480）
- 播放条固定占位（body padding-bottom 76px），任何尺寸不可删除只可精简
- 阴影纪律：暗底阴影必须重（0.3–0.5 不透明度），轻阴影等于没有

## 6. 深度与阴影

L0 `#121212` 平铺 → L1 `#181818`/`#1f1f1f` 容器 → L2 `rgba(0,0,0,.3) 0 8px 8px`（浮现播放键）→ L3 `rgba(0,0,0,.5) 0 8px 24px`（播放条、唱片）。悬浮感 = 黑上加黑。

## 7. Do's & Don'ts

### Do
- 每个内容单元一套独立撞色渐变封面，色彩由内容供给
- 长内容切成 tracklist 章节单，讲述人/作者作副标题
- 底部永远保留"正在播放/正在阅读"条，把收听上下文钉在最后一屏
- 绿色只在能回答"它指示什么功能"时出现；绿底永远黑字
- 数字列（时长/序号/期数）tabular-nums 等宽对齐
- 首屏放唱片或等效旋转装置，"播放中"前置

### Don't
- 不要白底/浅色大面积区域；不要绿色装饰性铺陈（订阅渐变盒除外）
- 不要方角按钮、细字重标签；不要在绿底上放白字
- 不要让专辑卡出现描边（hover 靠背景微亮）
- 不要轻描淡写的阴影（暗底上不可见）
- 不要把 tracklist 做成普通文章列表——序号、时长、讲述人缺一不可

## 8. 响应式行为

| 断点 | 关键变化 |
|---|---|
| ≤1280 | 网格间距 16px，其余基准 |
| ≤768 | 导航抽屉；首屏单栏、唱片缩至 230px；网格 2 列；tracklist 隐藏关键词列；播放条精简为"信息+状态"两段 |
| ≤480（覆盖 375） | 英雄标题 ≥34px；页脚单列；描边按钮隐藏；网格 2 列窄距 12px |

触控 ≥44px（浮现播放键恰为 44px）。

## 9. Agent 提示词指南

**起手式**：铺 `#121212` → 内容装进 `#181818`（8px 圆角无描边）→ 每个内容单元设计三停撞色封面 → 切 tracklist 章节单 → 钉一条正在播放条。

**示例提示词**：
- "口述史专辑卡：#181818 底 8px 圆角，封面 135° 三停渐变（自选撞色）+ 底部 45% 黑压暗 + 白色 mono 角标「EP.042 · 广州」，标题 16px/700 白，副标 12px 灰，hover 右下浮现 44px 绿圆播放键。"
- "章节曲目单：#181818 容器，表头（#/章节·讲述人/关键词/时长）12px #b3b3b3；序号 hover 变 #1ed760，时长 tabular 右对齐，行 hover rgba(255,255,255,.03)。"
- "正在播放条：fixed 76px，#181818 底 + rgba(0,0,0,.5) 0 8px 24px；左 46px 封面缩略 + 信息省略截断；中 36px 白圆播放键（hover 绿）+ 4px 可点击进度条。"

**适配题材**：口述史、播客、电台、有声书、课程连载、导览音频——凡"一集一集"的慢内容。商品展示不适用。
