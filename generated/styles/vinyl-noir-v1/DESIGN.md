# Design System: Vinyl Noir（黑胶暗调 · 播放器编辑风）

> 派生自页面 `20260818-spotify-travel-blog`（★4，study of `spotify`）。
> 核心命题：把"内容优先的近黑播放器语言"移植到**非音频的编辑/社区类内容**上——文章当曲目排，城市当专辑卖，页脚永远有一条"正在播放"。

---

## 1. 视觉主题与氛围

近黑剧场。页面由 `#121212 → #181818 → #1f1f1f` 三层炭黑构成舞台，UI 自身无彩，唯一的纯色是**功能性强调绿**，真正的色彩来自内容自带的"封面艺术"（CSS 渐变绘制的专辑/主题封面）。氛围关键词：沉浸、温暖的黑、触感化、夜航。

与原版 Spotify 语言相比，本风格的增量在于**编辑化外推**：

- 英雄区允许 40–64px / 700 的大标题（原语言最大 24px），但保留紧凑行高（1.08）与负字距（-0.02em），"大而不松"；
- 英雄区可用一枚**纯 CSS 旋转唱片/圆盘**作为氛围装置（conic-gradient + 重阴影 + 20–30s 慢速旋转），把"播放中"的感觉前置到首屏；
- 内容列表采用 **tracklist 语法**（序号 / 标题+副标题 / 数据列 / 时长或日期），把任何清单都做成"曲目单"。

**关键特征**：
- 三层炭黑画布，UI 退场、内容发光
- 唯一强调色仅用于功能（播放、激活、CTA、进度），从不当装饰
- 药丸按钮 + 大写字标（uppercase + 1.4–2px 字距）
- tracklist 语法的内容列表 + 全宽底部"正在播放"条
- CSS 渐变封面艺术是页面主要色彩来源

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 画布 | `#121212` | 页面最底层背景 |
| 容器 | `#181818` | 卡片、列表容器、底部播放条 |
| 交互面 | `#1f1f1f` | 按钮、导航活动态 |
| hover 微亮 | `#282828` | 卡片/行 hover（唯一的"亮化"手段） |
| 强调绿 | `#1ed760`（变体 `#1db954`） | **仅功能**：播放键、激活态、CTA、进度已播段、序号 hover |
| 主文本 | `#ffffff` | 标题、强调 |
| 次文本 | `#b3b3b3` | 副标题、说明、非活动导航 |
| 分隔线 | `#4d4d4d`（列表行可用 35% 透明） | 行分隔、表头底线 |
| 描边 | `#7c7c7c` | 描边按钮，hover 变白 |
| 语义色 | 红 `#f3727f` / 橙 `#ffa42b` / 蓝 `#539df5` | 仅错误 / 警告 / 通知 |
| 封面渐变 | 135°–160° 三停渐变，饱和撞色 | 每张"专辑"一套，是页面唯一自由色彩区 |

绿底按钮上的文字一律用**黑色**（绿底白字对比不足 3:1）。英雄区标题至多染绿**一个词**，且该词须承担行动语义（如"专辑"呼应收听 CTA）。

## 3. 字体规则

字体族：CircularSp 系不可用时，用 `'SpotifyMixUI', 'Inter', 'Helvetica Neue', 'PingFang SC', 'Microsoft YaHei', sans-serif` 回退栈（必须带系统回退）。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| 英雄大标题 | clamp(40px, 5vw, 64px) | 700 | line-height 1.08，letter-spacing -0.02em（编辑化外推，见 §9） |
| 区块标题 | 24px | 700 | |
| 卡片标题 | 16px | 700 | |
| 正文/列表 | 14–16px | 400 | 次级信息一律 `#b3b3b3` |
| 按钮 | 13–14px | 700 | uppercase + letter-spacing 1.4–2px（大写字标按钮） |
| 徽章/标签 | 10–12px | 600–700 | 徽章圆角仅 2px |
| 数据列 | 12–14px | 400 | `font-variant-numeric: tabular-nums` |

层级靠**字重二进制**（700 vs 400，600 慎用）而非字号梯度；数字列必须等宽对齐。

## 4. 组件样式

**按钮（全部药丸）**
- 主 CTA：绿底 `#1ed760` + 黑字，radius 9999px，hover 放大 1.04 且提亮 `#3be477`
- 次级：`#1f1f1f` 底白字，hover 微亮
- 描边：透明底 + `1px solid #7c7c7c`，hover 边框变白
- 一律 uppercase、700、1.4–2px 字距

**专辑卡（内容卡）**
- `#181818` 底、8px 圆角、无描边；hover 背景 → `#282828`
- 封面：aspect-ratio 1/1、6px 圆角、135°–160° 三停渐变 + 底部 45% 处黑色压暗渐变（保证封面上的字可读）
- hover 时右下浮现 44px **绿色圆形播放键**（50% 圆角 + 中阴影）——本风格的标志性交互

**tracklist 列表**
- 容器 `#181818`、8px 圆角；表头 12px/400/`#b3b3b3`
- 列语法：`#` 序号（hover 变绿）｜标题 700 + 副标题 12px `#b3b3b3`｜数据列（tabular-nums）｜时长/日期右对齐
- 行 hover 背景 `rgba(255,255,255,0.03)`

**底部正在播放条（Now Playing Bar）**
- fixed 全宽、76px 高、`#181818` 底 + 顶部 1px 黑描边 + 重阴影
- 三段式：左（46px 封面缩略 + 曲目信息，溢出省略）｜中（圆形控制键组：白色播放键 hover 变绿 + 进度条，已播段白色、hover 变绿）｜右（音质/状态）
- 此条是本风格的"签名组件"：非音频站点也可用作"最近浏览/正在阅读"条

**徽章**：2px 圆角、12px/700、绿字绿边半透明底（`rgba(30,215,96,.12)` 底 + 35% 绿边）。

## 5. 布局原则

- 容器 max-width 1160px、24px 内边距；区块间距 48px
- 8px 基础间距单位
- 内容网格 4 列（桌面）→ 2 列（≤768px）→ 2 列窄距（≤480px）
- "暗色压缩"：网格间距紧凑（18px），靠黑的呼吸感而非大留白
- 英雄区：左文右盘双栏（1.2fr : 1fr）；订阅/CTA 区可用绿黑渐变盒（`linear-gradient(135deg, #1f4e3e, #233b2b)`）——这是绿色唯一允许大面积出现的形态
- 页脚 4 栏链接 + 细分隔线 `#232323`

## 6. 深度与阴影

| 层级 | 处理 | 用途 |
|---|---|---|
| L0 | `#121212` 平铺 | 页面背景 |
| L1 | `#181818` / `#1f1f1f` | 卡片、容器、播放条 |
| L2 | `rgba(0,0,0,0.3) 0 8px 8px` | hover 浮层、浮现的播放键 |
| L3 | `rgba(0,0,0,0.5) 0 8px 24px` | 播放条、浮层、唱片装置 |

暗底上阴影必须**重**（0.3–0.5 不透明度），轻阴影等于没有。悬浮感 = 黑上加黑。

## 7. Do's & Don'ts

### Do
- 绿色只给功能：播放、激活、CTA、进度、hover 序号——每次用绿前自问"它能不能被点/是不是状态"
- 所有按钮药丸化、标签大写加宽字距
- 每张内容卡配一套独立的饱和渐变"封面"，让色彩由内容供给
- 列表用 tracklist 语法 + tabular-nums 数字列
- hover 反馈 = 背景微亮 `#282828` 或 `rgba(255,255,255,0.03)`，而非描边/阴影变化
- 页尾保留全宽"正在播放/正在阅读"条，把产品气质钉在最后一屏

### Don't
- 不要把绿色当装饰大面积铺（唯一例外：CTA 区的深绿渐变盒）
- 不要白底/浅色大面积区域——近黑沉浸是根基
- 不要方角按钮、细字重标签、松弛行高
- 不要用轻描淡写的阴影（暗底上不可见）
- 不要在绿色按钮上放白字
- 不要增加第二种品牌色（语义红/橙/蓝只用于错误/警告/通知）

## 8. 响应式行为

| 断点 | 关键变化 |
|---|---|
| ≤1280（基准） | 4 列专辑网格、完整三段式播放条 |
| ≤768 | 导航折叠为抽屉；英雄区单栏、唱片缩至 230px；网格 2 列；tracklist 隐藏数据列；播放条精简为"信息 + 状态"两段，隐藏控制组 |
| ≤480（覆盖 375） | 英雄标题 ≥ 36px；页脚单列；次级描边按钮隐藏；网格保持 2 列但间距收窄 12px |

底线：触控目标 ≥ 44px（浮现播放键恰为 44px）；播放条在所有尺寸保留（可精简不可删除）。

## 9. Agent 提示词指南

**起手式**：整页铺 `#121212` → 内容装进 `#181818` 容器（8px 圆角）→ 选定一个功能性强调绿 `#1ed760` → 为每个内容单元设计三停渐变封面 → 全部按钮药丸 + 大写。

**示例组件提示词**：
- "深色内容卡：#181818 底、8px 圆角，封面为 135° 三停渐变（自选撞色）+ 底部 45% 处黑压暗，标题 16px/700 白色，副标题 12px/400 #b3b3b3，hover 背景变 #282828 并在封面右下浮现 44px 绿色圆形播放键。"
- "曲目式列表：#181818 容器，表头（#/标题/数据/时长）12px #b3b3b3；行内序号 hover 变绿、数据列 tabular-nums、时长右对齐，行 hover 背景 rgba(255,255,255,0.03)。"
- "底部正在播放条：fixed 全宽 76px 高 #181818 底、rgba(0,0,0,0.5) 0 8px 24px 阴影；左 46px 封面缩略 + 曲目信息省略号截断；中白色 36px 圆形播放键（hover 变绿）+ 4px 进度条（已播白、hover 绿）。"

**迭代心法**：
1. 先把一切做成黑的，再让内容自己发光
2. 每用一次绿色都要能回答"它在指示什么功能"
3. 把清单想象成曲目单、把内容包想象成专辑，播放器语法自然浮现
4. 英雄大标题是对原语言的**显式外推**（24px→64px），行高字距纪律不变；在 notes 中声明即可

**适配题材**：声音/播客/音乐站天然契合；旅行、阅读、学习、摄影等"合集型内容"同样成立——凡是能把内容打包成"一张专辑 + 一列曲目"的产品都适用。
