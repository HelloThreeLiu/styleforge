# Design System: 夜巡紫夜 NightWard（派生自 Sentry）

> 血统：`sentry`（种子）→ `20260820-nightward-firefly-watch-marketing`（★4）→ 本风格。
> 核心转译：把 Sentry 的"深夜调试 IDE"语言移植到**公民科学 · 夜间生态观察**场景——紫色不再是代码编辑器的氛围，而是入夜后的城市本身；荧光绿从"高可见 CTA"转义为**夜色中的生物发光信号**；代码卡从"报错堆栈"转义为**田野观测记录**。

## 1. 视觉主题与氛围

紫夜公民科学（Night Citizen Science）。整个画面是入夜后的城市：双色紫黑画布（`#1f1633` 主底 / `#150f23` 深区），永不使用纯黑——夜晚是有温度的。在这片夜色之上，荧光绿（`#c2ef4e`）不是按钮装饰，而是**会发光的生命体**：萤火、信号灯、开放的报名状态。玻璃质感的计数卡像夜间观测站的数据面板，等宽字体的 YAML 观测卡把"田野笔记"写成"代码提交"。

氛围关键词：夜巡、样线、微光、计数、公民科学。文案是短句诗意的（"数萤火的人。"），但数据是严肃的（128,406 条记录）——这种"诗意外壳 + 工程内核"的反差就是本风格的灵魂。

**关键特征：**
- 双色紫黑画布 `#1f1633` / `#150f23`，紫调结构线 `#362d59`，拒绝中性灰与纯黑
- 荧光绿 `#c2ef4e` = 夜色中的光（生命体、信号、开放状态），每区至多出现一次
- 紫色环境辉光：径向渐变（紫 32% → 深底 90%）+ blur，营造"夜大气层"
- 玻璃计数卡：`rgba(255,255,255,.18)` + `blur(18px) saturate(180%)`，像观测站面板
- 等宽观测卡：YAML 格式的田野记录 + 语法高亮（关键字=荧光绿、字符串=黄）
- 内凹阴影紫按钮：可按压的触感主操作
- 大写字母间距标签系统（0.2–0.25px），技术标签语气

## 2. 色彩与角色

### 画布与结构
- **夜幕紫** `#1f1633`：页面主背景——夜晚的主体色
- **深夜紫** `#150f23`：深区、页脚、特性区——层次更深的夜
- **结构紫** `#362d59`：所有边框、分隔线、卡片描边——紫调，拒绝中性灰

### 交互紫谱系
- **交互紫** `#6a5fc1`：链接、hover、栏目标题——紫谱系的中间支点
- **按钮紫** `#79628c` + 边框 `#584674`：主按钮底色，配内凹阴影
- **深紫罗兰** `#422082`：高强调表面（下拉、激活态）

### 信号色（语义纪律：同一组件内绿不与粉/珊瑚混用）
- **生物光绿** `#c2ef4e`：夜色中的发光体——萤火、logo 辉光、开放状态徽章、YAML 关键字。**每区至多一次**
- **珊瑚** `#ffb287`：焦点态背景——手电扫过般的暖光
- **粉** `#fa7faa`：装饰圆点、次级点缀

### 文本与代码
- **正文白** `#ffffff`：主文本
- **灰白** `#e5e7eb`：次级文本、YAML 注释主体
- **代码黄** `#dcdcaa`：YAML 字符串值
- **注释灰** `rgba(229,231,235,.45)`：YAML 注释

### 表面
- **玻璃白** `rgba(255,255,255,.18)`：玻璃卡底 + `blur(18px) saturate(180%)`
- **玻璃悬停** `rgba(54,22,107,.14)`：玻璃/卡片 hover 覆盖层
- **卡面紫** `rgba(54,45,89,.35)`：特性卡半透明底

## 3. 字体规则

三役制（与 Sentry 同构，选角可换但分工不变）：

| 角色 | 本风格实现 | 规格 |
|---|---|---|
| 展示 | 个性几何无衬线（原页用 Space Grotesk 替 Dammit Sans） | hero `clamp(42px, 7.4vw, 88px)` / 700 / 行高 1.2 |
| UI | 圆角功能无衬线（Rubik 直载） | 四档字重 400/500/600/700 |
| 等宽 | Monaco / Menlo / Consolas / IBM Plex Mono 链 | 12–14px，行高 1.7 |

层级要点：
- 区标（Section Label）：12–14px / 600 / uppercase / 0.2–0.25px 字距，荧光绿或紫——每区开头一次
- 区题：30px / 400 / 行高 1.2——**低字重大标题**制造"平静的夜"
- 卡题：24px / 500，前置 9px 圆点（紫/绿/粉各卡一色）
- 正文：16px / 400 / 1.5，灰白
- 玻璃卡数字：展示字体 30px / 700——数据即装饰
- 中文大写字距仅作用于拉丁字符段；中文标签保留 0.2–0.25px

## 4. 组件样式

### 按钮
- **内凹紫按钮（主）**：底 `#79628c`，边 `1px solid #584674`，圆角 13px，内凹阴影 `rgba(0,0,0,.1) 0 1px 3px inset`，白字 14px/700/uppercase/0.2px；hover 升起 `rgba(0,0,0,.18) 0 .5rem 1.5rem`
- **白实心 CTA（每页至多 1–2 处）**：底 `#ffffff`，字 `#1f1633`，圆角 8px；hover 变交互紫、focus 变珊瑚——"夜中最亮的东西"
- 全部触控目标 ≥44px，移动端全宽

### 玻璃计数卡（签名组件）
- 三联条状排布，底 `rgba(255,255,255,.18)` + `blur(18px) saturate(180%)`，圆角 12px，内边距 22px 24px
- 内容 = 展示字体大数字（30px/700）+ 一行灰白说明——把"参与人数 / 覆盖范围 / 累计记录"做成观测站面板

### 观测代码卡（签名组件）
- 深底（`#1f1633`）+ 紫边框卡，顶栏文件名 + 状态行 `● N records`（绿点绿字）
- 正文 YAML/等宽，语法高亮：关键字=荧光绿、字符串=黄、数字=白、注释=半透明灰白
- 用途：任何"记录格式 / 数据结构 / 协议"的展示——把田野工作写成代码

### 特性卡
- 底 `rgba(54,45,89,.35)` + `1px solid #362d59`，圆角 12px；hover 玻璃悬停层 + 卡片阴影
- 标题前 9px 圆点，紫/绿/粉逐卡分配，一卡一色

### 行式清单（活动/场次）
- 行栅格 `日期列(展示字体 22px/700) + 标题说明列 + 状态徽章列`，行间紫底线
- 状态徽章：描边药丸 12px/700/uppercase——开放=荧光绿边绿字，满员=灰白字紫边

### 导航
- 紫黑透明 `rgba(31,22,51,.82)` + `blur(18px) saturate(180%)`，紫调底线
- logo = 荧光绿菱形（rotate 45° + 辉光 shadow）+ 展示字体名 + 灰白中文小注——绿的第一处
- 链接 15px/500，hover 变紫；768px 以下折叠汉堡

## 5. 布局原则

- 容器 max-width 1152px，左右 32px（移动 24px）
- 节奏：全屏紫夜 hero（含辉光 + 光点动画 + 玻璃卡条）→ `#150f23` 深区特性带（含观测代码卡）→ 主底行式清单 → 居中终章 CTA → `#150f23` 页脚
- 区块间 64–80px 垂直呼吸，让夜色成为留白
- 玻璃卡条与特性卡均三列，992px 起单列堆叠
- 行式清单 768px 起收窄为两行布局（徽章换行）

## 6. 深度与阴影

| 层 | 处理 | 用途 |
|---|---|---|
| -1 内凹 | `rgba(0,0,0,.1) 0 1px 3px inset` | 主按钮——可按压触感 |
| 0 平面 | 无 | 夜色画布 |
| 1 表面 | `rgba(0,0,0,.08) 0 2px 8px` | 玻璃卡 |
| 2 浮起 | `rgba(0,0,0,.1) 0 10px 15px -3px` | 观测代码卡、hover 卡 |
| 3 悬停升起 | `rgba(0,0,0,.18) 0 .5rem 1.5rem` | 按钮 hover |
| 4 环境辉光 | 径向渐变 `rgba(106,95,193,.32) → rgba(22,15,36,.9)` + blur(18px) | hero 夜大气层 |

阴影哲学：阴影都是黑紫调的，辉光才有颜色——**界面沉入夜，只有"生物"发光**。光点（萤火/信号）自带 `box-shadow: 0 0 12px 2px` 同色辉光。

## 7. Do's & Don'ts

### Do
- 荧光绿只作为"夜色中的光"使用：生命体、信号、开放状态、代码关键字——每区至多一次
- hero 必有紫调环境辉光径向渐变，让夜有"大气层"
- 用玻璃计数卡承载参与数据（人数/覆盖/累计），大数字用展示字体
- 用等宽 YAML 卡展示"记录格式"，语法高亮沿用绿/黄/灰白分工
- 按钮保持内凹触感 + 大写字距；白实心 CTA 是夜中的最高亮度，节制使用
- 文案走"诗意短句 + 严肃数据"反差：标题像诗，数字像账本
- 动画光点用 `ease-in-out` 呼吸式（透明度 + 小位移 + 辉光），不做急速运动

### Don't
- 不要用纯黑 `#000` 或中性灰边框——夜是紫的，结构线是紫调的
- 不要让绿与粉/珊瑚出现在同一组件
- 不要把荧光绿用在大型表面（底色、大块面）——它只属于点和字
- 不要用卡片网格展示活动/场次清单——行式列表才是本风格的事件语言
- 不要给标题加粗超过 500（区题 400 为主）——夜是平静的，噪的是数据不是标题
- 不要让观测代码卡脱离等宽字体与语法高亮——纯文本会失去"工程内核"
- 不要在 375px 下让 display 字号低于 30px 或按钮触控目标小于 44px

## 8. 响应式行为

- 断点：992 / 768 / 480（375 兜底）——从桌面优先向下收缩
- 992px：三列玻璃卡与特性卡 → 单列
- 768px：导航折叠汉堡 + 下拉面板；行式清单收窄（徽章换至第二行）；页脚两栏；容器 24px
- 480px：hero 展示字 42px（≥30px 底线）；按钮全宽 ≥44px；页脚单列
- 光点动画在所有断点保留（pointer-events: none，纯装饰）
- 玻璃 blur 在不支持 backdrop-filter 的环境退化为半透明底色

### 适用题材
