# Design System: 缝补工坊 MendWell（派生自 intercom）

> 血统：`intercom` → `20260821-mendwell-upcycle-fashion-ecommerce`（★4.5）→ 本风格。
> 核心命题：把 Intercom 的"暖米白 + 物理按钮 + report 色板"语言用于**修补、循环、再利用**类题材——反快时尚的修补工坊、二手循环商店、旧物改造计划。温暖的手工感对冲商业感。

## 1. 视觉主题与氛围

暖米白 `#faf9f6` 画布像一张未漂白的帆布工作台，燕麦色 `#dedbd6` 边框是缝线，近黑 `#111111` 是顶针。按钮按下去会真的"缩一下"（active `scale(0.85)` 绿）——像缝纫机的落针。唯一的橙色 `#ff5600` 只给"AI/技术时刻"，其余色彩全部由 report 六色板以**标签与数据**形式供给。

氛围关键词：缝补、循环、旧物、慢。文案讲物品的生平（"一件风衣的三次补丁"），数字讲减量（4.6 吨免于填埋）。

**关键特征：**
- 暖米白画布 + 燕麦边框 8px 圆角卡 + **无阴影**
- 极端负字距标题（80px/400/1.00/-2.4px），行高一律 1.00
- 物理按钮：hover `scale(1.1)` 反色、active `scale(0.85)` 绿底 `#2c6415`
- Fin Orange `#ff5600` 仅品牌/AI 时刻（徽章、CTA 盒标签）
- report 色板（蓝绿红粉青柠橙）只做标签与数据大数字
- 衬线编辑体块（首字下沉）承载"物的故事"
- CSS 剪影商品卡（虚线勾画 + report 色补丁方块）
- 近黑 CTA 盒 8px 圆角反白

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 近黑 | `#111111` | 文本/主按钮/CTA 盒 |
| 暖米白 | `#faf9f6` | 画布与卡面 |
| Fin Orange | `#ff5600` | 唯一品牌色：AI 徽章、CTA 盒标签、链接 hover |
| 燕麦 | `#dedbd6` / 暖沙 `#d3cec6` | 边框体系（拒绝冷灰） |
| 暖中性 | `#313130 / #626260 / #7b7b78 / #9c9fa5` | 四层文本 |
| report 板 | 蓝 `#65b5ff` 绿 `#0bdf50` 红 `#c41c1c` 粉 `#ff2067` 青柠 `#b3e01c` 橙 `#fe4c02` | 仅标签/成色/数据 |
| 按钮绿 | `#2c6415` | active 态专用 |

## 3. 字体规则

Saans/Serrif/SaansMono 不可用时：Instrument Sans（几何无衬线）+ Source Serif 4（编辑衬线 300）+ IBM Plex Mono（大写标签 0.6px 字距）。中文回退链按平台底线。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero | 80px | 400 | 行高 1.00、-2.4px；手动换行 |
| 区题 | 54/40px | 400 | -1.6/-1.2px、行高 1.00 |
| 卡题 | 32/24px | 400 | -0.96/-0.48px |
| 正文 | 16px | 400 | 1.5 行高（正文是唯一超 1.0 行高处）|
| 衬线编辑体 | 17px | 300 | -0.16px、1.7 行高、首字下沉 |
| mono 标签 | 11–12px | 500 | uppercase + 0.6px |

## 4. 组件样式

- **按钮**：4px 圆角近矩形；深色主钮（hover 白底黑字 scale1.1 / active 绿 scale0.85）、描边钮同行为、暖米白卡钮
- **服务/内容卡**：白底或米白底 + 燕麦边 8px 圆角无阴影；report 色 mono 标签 + 32px/-0.96px 标题 + 起价 mono 行
- **循环商品卡**：燕麦边 8px；上部 = CSS 虚线剪影（衣物轮廓变体）+ report 色补丁方块；下部 = 成色徽章（report 色轮换）+ 标题 16px/500 + 衬线一句故事 + 价格（划线原价）+ 描边小按钮
- **分类 tab**：mono 大写，激活黑底白字 4px
- **编辑体块**：白底燕麦上下边区，衬线正文 + 首字下沉 52px
- **数据条**：report 色大数字 56px/400/-1.6px + 暖灰说明
- **CTA 盒**：`#111111` 8px 圆角 + 橙 mono 标签 + 白 54px/-1.6px 标题 + 白钮 hover 橙

## 5. 布局原则

1160px 容器；服务卡 3 列、商品 4 列（→2→1）；编辑体块两栏（题+文）；流程 4 列；8px 基础间距、区距 80–88px。暖米白贯穿全页，白色卡在米白上做一层微差。

## 6. 深度与阴影

无阴影。深度 = 暖边框 + 表面色差（白卡浮于米白）。触觉反馈全靠 transform。

## 7. Do's & Don'ts

### Do
- 商品/物品用 CSS 剪影 + 补丁方块表达"修补过的旧物"
- 每件物品配一句衬线体"物的故事"与成色徽章
- report 色只出现在标签、成色、数据——永不进按钮与正文
- 按钮的 scale 物理反馈必须完整（1.1 hover / 0.85 绿 active）
- 用数据条讲减量成果（修补数/循环数/减吨数）
- 编辑体块做首字下沉，讲一件具体物品的生平

### Don't
- 不要冷灰边框（永远燕麦色系）
- 不要圆角超 8px、不要药丸按钮
- 不要阴影、不要 Fin Orange 装饰性铺陈
- 不要让正文行高超过 1.5（标题 1.00 的纪律不可破）
- 不要商品化的"促销红"——红色只是 report 数据色

## 8. 响应式行为

896 服务单列/商品两列/编辑单栏；768 导航折叠、数据条单列；640 流程单列；425 商品单列、hover scale 取消（触控防误触）；375 hero ≥30px、卡题 26px。

## 9. Agent 提示词指南

**起手式**：铺 `#faf9f6` → 一切容器燕麦边 8px 圆角无阴影 → 标题 80px/-2.4px/行高 1.00 → 按钮装 scale 物理反馈 → report 色只做标签 → 页尾近黑 CTA 盒。

**示例提示词**：
- "循环商品卡：#faf9f6 底 + #dedbd6 边 8px 圆角；上半 CSS 虚线衣物剪影（border-dashed 轮廓）+ report 色补丁方块；下半成色徽章（蓝/粉/青柠轮换 mono）+ 16px/500 标题 + 衬线故事一句 + 价格含划线原价 + 描边按钮。"
- "物理按钮：#111111 底白字 4px 圆角；hover 白底黑字 transform scale(1.1)；active #2c6415 绿底 scale(0.85)。"
- "编辑体块：白底燕麦上下边，Source Serif 17px/300/-0.16px 正文 + 52px 首字下沉，讲一件物品的三次修补。"

**适配题材**：修补工坊、二手循环商店、旧物改造、共修工作坊、慢时尚、图书漂流——一切"让旧物再活一次"的循环叙事。快闪促销不适用。
