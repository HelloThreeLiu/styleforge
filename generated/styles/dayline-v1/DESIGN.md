# Design System: 晨昏粉彩账 Dayline（派生自 together.ai）

> 血统：`together.ai` → `20260821-dayline-running-club-pricing`（★4）→ 本风格。
> 核心命题：把 together.ai 的"粉彩渐变 + 深午夜蓝双世界"语言用于**社区组织的钱与账**——会费、费率、互助金、公开账目。让"谈钱"的页面像清晨一样坦荡。

## 1. 视觉主题与氛围

白画布上浮着一层粉彩云雾（品红→薰衣草→蓝的径向渐变，仅装饰），标题压缩而克制（64px/500/-1.92px），深午夜蓝 `#010120` 的"公报区"像天亮前的最后一段夜。数字很大、很轻（56px/500），账目像天气一样被平静地陈述。

氛围关键词：透明、会费、公报、清晨。文案直接谈钱（"你的 ¥68，每一分都对得上账"），并给章程级承诺（"账上现金不得超过下季预算 110%"）。

**关键特征：**
- 双世界：白区（费率/档位）↔ 深午夜蓝 `#010120` 区（公报/论文式内容）
- 粉彩渐变仅装饰（hero 云雾、logo 方块），永不进 UI chrome
- 薰衣草 `#bdbbff` 唯一允许的 UI 软强调
- 全负字距（-1.92@64 → -0.16@16）；字重仅 400/500
- 锐利 4px 按钮 / 8px 卡（无药丸）
- 蓝调阴影 `rgba(1,1,32,0.1) 0 4px 10px` 全站唯一
- mono 大写标签（10–11px/0.05–0.08px）做技术路标
- 巨型页脚词标（渐隐收束）
- 档位卡 + 费率拆解条形 + 统计锚点三件套

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 白 / 深蓝 | `#ffffff` / `#010120` | 双世界画布 |
| 品红 / 橙 | `#ef2cc1` / `#fc4c02` | 仅渐变装饰与文字级注记（"省 18%"） |
| 薰衣草 | `#bdbbff` | 热门档描边、深区关键字、条形填充、徽章底 |
| 文本 | 黑 / 40% 黑 | 浅区；深区用白与 60% 白 |
| 边框 | 浅区 8% 黑 / 深区 12% 白 | 分离机制 |
| 阴影 | `rgba(1,1,32,0.1) 0 4px 10px` | 唯一蓝调浮起 |

## 3. 字体规则

The Future / PP Neue Montreal Mono 不可用时：Archivo（几何现代 400/500）+ Space Mono（等宽大写标签）。中文回退链按平台底线。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| Hero | 64px | 500 | -1.92px、行高 1.10 |
| 区题 | 40px | 500 | -0.8px |
| 档位名 | 28px | 500 | -0.42px |
| 价格 | 54px | 500 | -1.6px + mono 周期小注 |
| 正文 | 16–18px | 400 | -0.16~-0.18px |
| mono 标签 | 10–11px | 400–500 | uppercase + 0.05–0.08px |

## 4. 组件样式

- **档位卡**：8px 圆角白卡 + 8% 黑边 + 蓝调阴影；热门档薰衣草描边 + 薰衣草底 mono 徽章；权益行列表（8% 黑分隔）+ 全宽深蓝/描边按钮
- **周期切换器**：mono 药丸型分段（深蓝激活态；年付档可带品红文字注记）
- **费率拆解**：横向条形（薰衣草渐变填充 + mono 金额右对齐）+ 章程透明度注记
- **统计锚点**：56px/500/-1.6px 大数字 + 40% 黑小注（含"0 条广告"式的价值观数字）
- **公报区卡**：深蓝满宽 + 12% 白边卡 + 薰衣草 mono 小标 + 白 22px/-0.22px 标题 + 60% 白正文 + 底边线链接
- **巨型页脚词标**：clamp(64px, 14vw, 180px)/-4px，白→25% 白渐隐（background-clip）
- **按钮**：4px 圆角；深蓝实心（浅区主）/ 描边 8% 黑（次）/ 12% 白玻璃（深区）

## 5. 布局原则

1200px 容器；区距 80–120px（不低于 48px）；档位 3 列 → 1 列居中；统计 4 列 → 2 → 1；hero 粉彩云雾以径向渐变叠加渲染（溢出裁切）。

## 6. 深度与阴影

蓝调单阴影全站唯一；深区靠 12% 白边与表面色差。无第二阴影。

## 7. Do's & Don'ts

### Do
- 谈钱的页面要有"费率拆解"条形——透明度即设计
- 深蓝公报区放论文式内容（报告/白皮书/章程/公报）
- 统计里放一个价值观数字（0 广告 / 0 隐藏费）
- mono 标签做每个区块的路标
- 价格必配周期 mono 小注；周期切换实时重写价格

### Don't
- 不要把品红/橙做成 UI 色（仅渐变与文字注记）
- 不要药丸按钮、不要 700 字重
- 不要灰黑深区（必须深午夜蓝 #010120）
- 不要通用黑阴影（必须蓝调）
- 不要在白区使用第二强调色（薰衣草之外）

## 8. 响应式行为

992 档位卡单列居中、统计两列、公报卡单列；768 导航折叠、条形行堆叠、页脚两栏；479 统计单列；375 hero ≥30px、价格 44px、字距收窄。

## 9. Agent 提示词指南

**起手式**：白底 → hero 顶部三层径向粉彩云雾 → 档位卡三列（薰衣草热门档）→ 费率条形拆解 → 深蓝公报区 → 巨型渐隐页脚词标。

**示例提示词**：
- "档位卡：白底 1px rgba(0,0,0,.08) 边 8px 圆角 + rgba(1,1,32,.1) 0 4px 10px 阴影；价格 54px/500/-1.6px + mono 周期注；热门档边框换 #bdbbff + 薰衣草底 mono 徽章。"
- "费率拆解：行 = 16px/500 项目名 + 8px 高薰衣草渐变条 + mono 金额右对齐；底部附章程级透明度注记。"
- "深蓝公报卡：#010120 满宽区，卡 1px rgba(255,255,255,.12) 边 8px 圆角；#bdbbff mono 小标 + 白 22px 标题 + 60% 白正文。"

**适配题材**：社区会费、公益费率、互助金、公共设施收费、时间银行、合作社账目——一切"需要把账摊开讲清楚"的组织页面。
