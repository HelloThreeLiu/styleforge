# Design System: 牧星紫夜 StarHerder（派生自 nightward-v1）

> 血统：`sentry` → `nightward-v1` → `20260821-starherder-darksky-guide-portfolio`（★4.5）→ 本风格。三代派生链的第三环。
> 核心命题：把"紫夜公民科学"语言落到**星空向导/夜色自然作品集**——环境辉光下展示用眼睛拍的"片子"，观测记录写成 YAML，团期排成行式清单。紫夜 + 萤光绿 + 玻璃面板的组合自然生长出的"个人IP 化"变体。

## 1. 视觉主题与氛围

紫黑双底（`#1f1633`/`#150f23`）上的个人展廊：环境辉光径向渐变是"夜大气层"，呼吸星点是"夜色中的光"，玻璃计数卡是"观测站面板"。作品是 CSS 绘制的星野场景（银河拱桥、流星、星轨、月升、黄道光、深空天体）——**风景用渐变画，数据用等宽写**。

氛围关键词：暗夜保护、向导、作品集、可预约。文案诗意标题 + 认真数据（"214 个观星夜"）。

**关键特征：**
- 双色紫黑画布 + 紫调结构线 `#362d59`（继承 nightward-v1）
- 环境辉光径向渐变 + 呼吸星点动画（绿=夜色中的光，每区一次）
- 玻璃计数卡（`rgba(255,255,255,.18)` + `blur(18px) saturate(180%)`）
- **CSS 星野作品卡**：每幅一个天文场景（渐变/clip-path 山影/repeating-conic 星轨/径向光斑）+ 等宽摄影参数行（`14mm f/1.8 · 15s · ISO3200`）
- 观星 YAML 记录卡（关键字绿/字符串黄/注释半透明白）
- 行式团期清单（日期大字 + 地点 + 状态徽章：绿边开放/紫边成团/灰边候补）
- 内凹紫按钮 + 白实心 CTA（夜中至亮）

## 2. 色彩与角色

继承 nightward-v1 全套：`#1f1633`/`#150f23` 双底、`#362d59` 结构线、`#6a5fc1` 交互紫、`#79628c`+`#584674` 按钮、`#c2ef4e` 生物光绿（每区一次）、`#ffb287`/`#fa7faa`、玻璃白面、环境辉光 `rgba(106,95,193,.32)→rgba(22,15,36,.9)`。新增内容色：星野场景深空底 `#0d0918` 与山影 `#0a0614`（场景剪影专用，不参与 UI 层级）。

## 3. 字体规则

三役制同 nightward-v1：Space Grotesk 展示（clamp(42px,7.4vw,88)/700/1.2）+ Rubik UI 四档 + Monaco 链等宽（12–14px/1.7）。区题 30px/400 低字重；圆点标题 9px 紫绿粉一卡一色。

## 4. 组件样式

- **星野作品卡**：`rgba(54,45,89,.35)` 底 + 紫边 12px 圆角；上半场景（aspect 4:3，六型渐变语法见 §9）+ 下半信息（等宽参数行 + 19px/500 卡题 + 灰白描述）；hover 玻璃悬停层 + 卡阴影
- **场景语法六型**：银河拱桥（斜渐变带+山影 clip-path）/ 流星（星点+斜尾迹线）/ 星轨（repeating-conic 同心弧）/ 月升（径向圆+辉光）/ 黄道光（conic 锥光+暖黄）/ 深空天体（椭圆光斑+核心亮点）
- **玻璃计数卡 ×3**：向导资历数据（年数/场次/同行者）
- **观星 YAML 卡**：站点/限星等/视宁度/目标清单/团组——语法高亮三色
- **行式团期清单**：`日期列（展示 22px/700）+ 团名集合点 + 状态徽章`
- **终章白 CTA**：「预约私人导览」+ 暗夜保护叙事（收入抽成注入保护基金）

## 5. 布局原则

1152px 容器；hero 左文右呼吸星点 + 辉光；作品网格 3 列（992 两列/480 单列）；YAML 卡居中于深区；团期行式不卡格。

## 6. 深度与阴影

同 nightward-v1 六层（内凹按钮→辉光）；作品场景内剪影用更深一档的紫黑，制造"画面纵深"。

## 7. Do's & Don'ts

### Do
- 每幅作品配等宽摄影参数行——器材数据是等宽字体的天然落点
- 呼吸星点动画 ease-in-out（透明度+小位移+辉光）
- 团期用行式清单 + 三态徽章，不做卡网格
- hero 一句诗意大标题 + 玻璃资历卡
- 绿只在导航 logo、星点、YAML 关键字、开放徽章各出现一次

### Don't
- 不要绿做大面积或与粉/珊瑚同组件
- 不要让作品场景使用 UI 色（场景是内容画布）
- 不要区题字重超过 500——夜是平静的
- 不要纯黑画布或中性灰边框

## 8. 响应式行为

992 作品两列、玻璃卡单列；768 导航折叠、团期徽章换行、页脚两栏；480 作品单列、按钮全宽；375 hero ≥38px。

## 9. Agent 提示词指南

**起手式**：紫黑双底 → hero 辉光 + 星点 + 玻璃资历卡 → 作品网格（每幅场景渐变 + 等宽参数）→ 深区 YAML 观测卡 → 行式团期 → 白 CTA 终章。

**示例提示词**：
- "星野卡：rgba(54,45,89,.35) 底紫边 12px；场景 = #0d0918 深空底 + 斜向银河渐变带（rgba(190,180,255,.22)）+ clip-path 山影 #0a0614；信息 = 等宽参数行（14mm f/1.8 · 15s · ISO3200）+ 19px/500 标题。"
- "星轨场景：repeating-conic-gradient(from 0deg at 50% 118%, rgba(255,255,255,.16) 0deg .35deg, transparent .35deg 2.6deg) 同心弧 + 底部 16% #0a0614 地平。"
- "行式团期：130px 日期（Space Grotesk 22px/700）+ 团名/集合点 + 描边药丸徽章（余 4 席=绿、已成团=紫、候补=灰）。"

**适配题材**：星空/生态向导作品集、暗夜保护、自然摄影师主页、户外领队预约——"夜晚 + 专业知识 + 可预约"的个人品牌页。
