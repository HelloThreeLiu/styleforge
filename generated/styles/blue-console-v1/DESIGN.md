# Design System: Blue Console（蓝调控制台 · SaaS 设置风）

> 派生自页面 `20260820-neura-ai-workspace-settings`（★4，study of `coinbase`）。
> 核心命题：Coinbase 的金融级蓝白语言移植到 **SaaS 工作台/设置类界面**——药丸 CTA、行高 1.00 的大标题、深浅交替分区，以及一整套可复用的设置页组件语法（侧栏分区、蓝开关、用量计量、密钥管理、深色账单区）。

---

## 1. 视觉主题与氛围

金融级的克制。白与近黑 `#0a0b0d` 是两块舞台，唯一的彩色是功能蓝 `#0052ff`——它只出现在"能点、能开、在激活、被计量"的地方。整体气质：可信、干净、效率至上，像一家持牌机构的产品，而非玩具。

本风格的增量在于**控制台语法**：

- 设置页采用"粘性侧栏分区 + 右侧面板"骨架，侧栏项是药丸（冷灰底 + 蓝字激活）；
- 一切微型交互件继承 CTA 的 56px 药丸几何（开关、进度条、角色标签），全站无方角交互件；
- 页面尾部用**深色账单/运营分区**收束（白 ↔ 黑交替的核心节奏），深区内再放 `#282b31` 深卡。

**关键特征**：
- 蓝 `#0052ff` 只做功能：激活、边框、开关、计量条、链接——从不装饰
- 56px 药丸 CTA，CTA 永比方角圆
- Display 标题行高 **1.00**（80/64/52px 逐级）
- 白内容区 ↔ `#0a0b0d` 深特性区的色相对比造深度，阴影极简
- 冷灰 `#eef0f3` 承担全部次级表面（带蓝调）
- 拉丁字标小写（品牌、眉题），亲和签名

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 画布（浅区） | `#ffffff` | 主内容、表单、表格 |
| 画布（深区） | `#0a0b0d` | 账单/运营特性区、页脚 |
| 深卡 | `#282b31` | 深区内的卡片、主 CTA 按钮底 |
| 功能蓝 | `#0052ff` | 激活项、蓝描边按钮、开关开启态、计量填充、选中态边框 |
| hover 蓝 | `#578bfa` | 深色底上的链接/CTA hover（暗底可读性） |
| 链接蓝 | `#0667d0` | 浅底次级链接 |
| 冷灰 | `#eef0f3` | 次级按钮、药丸标签、表头、开关关闭态 |
| 次级文本 | `#5b616e` | 说明、元信息 |
| 边框 | `rgba(91,97,110,0.2)` | 组件描边；深区内用 `rgba(255,255,255,0.1)` |
| 蓝染底 | `rgba(0,82,255,0.04–0.1)` | 选中卡片、所有者徽章的淡蓝 |

蓝底白字只用于"当前方案"类徽章与蓝描边按钮的 hover 反转；大面积纯蓝块禁止。

## 3. 字体规则

双族制（替代原四字族的等价分工）：

| 角色 | 字体 | 规格 |
|---|---|---|
| 展示标题 | 展示族（几何无衬线 400） | 52–64px / **行高 1.00** / -0.015em |
| 眉题 | 展示族 700 | 14px / 大写 / 0.06em / 品牌蓝 |
| 区块/面板题 | 展示族 400 | 36px / 1.11 |
| 卡片/功能题 | 展示族 600 | 18px / 1.33 |
| 正文 | 阅读族（人文无衬线 400） | 18px / 1.56 |
| 按钮 | 展示族 600 | 16px / 1.2 / +0.16px 字距 |
| 徽章/说明 | 展示族 600–700 | 13–14px |
| 代码/密钥 | 等宽族 | 14px |

600 是功能强调的默认字重；展示标题一律 400（大而不吼）。中文回退 PingFang SC / Microsoft YaHei。

## 4. 组件样式

**按钮（全药丸，56px 圆角起步）**
- 主 CTA：`#282b31` 深卡底白字，hover 变 `#578bfa`
- 蓝描边：透明底 + `1px solid #0052ff` 蓝字，hover 反转为蓝底白字
- 冷灰：`#eef0f3` 底近黑字（次级/管理类）
- 深区内的主行动：白底药丸 `btn-light`

**开关**：48×28 轨道、56px 圆角；开启态纯蓝底白钮，关闭态冷灰底；钮为白色圆。

**计量条**：8px 高、56px 圆角的轨道与填充；填充纯蓝；标签行 14/600 + 阅读族数值右对齐。

**设置侧栏**：粘性；项 16/600 药丸，hover 冷灰、激活冷灰底 + 蓝字；面板标题 36px/400。

**表单**：输入框白底 12px 圆角 + `rgba(91,97,110,.2)` 边，focus 变蓝；标签 14/700。

**表格/列表卡**：16px 圆角 + 组件边；表头行冷灰底 14/700；头像为冷灰圆 + 蓝字姓氏；角色药丸（所有者 = 10% 蓝底蓝字）。

**模型/方案选择卡**：白底 16px 圆角；选中态 = 蓝边 + 4% 蓝染底 + 蓝圆点；价格行蓝字 700。

**密钥管理**：等宽掩码 + 蓝描边"重新生成"（两段确认：首击变提示文案、3 秒超时复位）。

**深色账单区**：`#0a0b0d` 全宽；`#282b31` 24px 圆角深卡；蓝底"当前方案"药丸 + 36–52px 白色 Display 价格 + `#578bfa` 用量柱（当月纯蓝高亮）+ 发票行（链接用 hover 蓝）。

**反馈**：瞬时按钮态（"✓ 已保存/已发送"1.4s 复位），不用 toast 弹层。

## 5. 布局原则

- 容器 max-width 1120px；8px 基距
- 设置骨架：232px 粘性侧栏 + 1fr 面板（≤1024 转单列，侧栏变横向滚动）
- 分区间距 20–28px 卡距、72px 区块距
- 白 ↔ 黑交替：主体设置区为白，账单/运营区为 `#0a0b0d`，页脚延续深色
- 深度来自色相对比；阴影只保留极轻的开关钮投影

## 6. 深度与阴影

| 层级 | 处理 | 用途 |
|---|---|---|
| L0 | 无 | 白区组件（边框代替阴影） |
| L1 | `1px solid rgba(91,97,110,0.2)` | 卡片、输入框 |
| L2 | `rgba(10,11,13,0.2) 0 1px 3px` | 开关圆钮 |
| 深区 | 色相对比（白卡上黑区） | 账单深卡 |

阴影纪律：**能用边框就不用阴影**；深浅交替承担大结构深度。

## 7. Do's & Don'ts

### Do
- 每个交互件都药丸化（56px 起），微组件继承同一几何
- 蓝只出现在功能处：激活、开关、计量、选中、链接
- 展示标题行高 1.00，正文 1.56，各自不破
- 设置页用侧栏分区 + 面板骨架，切换真实可用
- 页面尾部放深色账单/运营区制造节奏
- 危险操作（重生成/删除）用两段确认

### Don't
- 不要大面积纯蓝色块（蓝描边与蓝药丸足矣）
- 不要方角 CTA 与方角开关
- 不要在深色区用 `#0052ff` 做小字（换 `#578bfa`）
- 不要展示标题加粗超过 400
- 不要在白区引入暖色（冷灰蓝调是底色性格）
- 不要装饰性图标/插画——结构即美

## 8. 响应式行为

| 断点 | 关键变化 |
|---|---|
| >1024（基准） | 侧栏 + 面板双栏；模型卡三列；账单双卡 |
| ≤1024 | 设置转单列、侧栏横滚；模型/账单卡单列 |
| ≤768 | 导航折叠抽屉；表格隐藏次要列；页脚两栏 |
| ≤480 | Display 标题 36px；CTA 全宽 ≥44px；表格转两行式；页脚单列 |

底线：375px 下展示标题 ≥ 36px；触控目标 ≥ 44px；侧栏横滚不产生页面级横向滚动。

## 9. Agent 提示词指南

**起手式**：铺白 → 画好 56px 药丸 CTA（深卡底）→ 定唯一功能蓝 → 搭"侧栏 + 面板"骨架 → 尾部压一块 `#0a0b0d` 深区。

**示例组件提示词**：
- "设置侧栏：粘性，项 16px/600 药丸，激活项 #eef0f3 底 #0052ff 字，点击切换右侧面板。"
- "用量计量条：8px 高 56px 圆角轨道 #eef0f3，填充 #0052ff，上方标签行 14/600 名称 + 右侧数值。"
- "模型选择卡：白底 16px 圆角 rgba(91,97,110,0.2) 边，选中态蓝边 + rgba(0,82,255,0.04) 染底 + 蓝圆点，价格行 #0052ff 700。"
- "深色账单卡：#282b31 底 24px 圆角，蓝底方案药丸 + 36px 白 Display 价格 + #578bfa 柱状图（当月 #0052ff 高亮）。"

**迭代心法**：
1. 数一数纯蓝出现的次数——每一次都要能回答"它在指示什么功能"
2. 任何方角交互件都是漏网之鱼，改回药丸
3. 白区太素就调分区节奏（深色区收尾），不要加彩色
4. 设置面板必须真实可切换——演示态在这套语法里等于未完成

**适配题材**：SaaS 控制台/设置/成员管理天然契合；金融、账务、合规、企业 AI 平台同样成立——凡"信任是卖点、效率是体验"的后台界面都适用。
