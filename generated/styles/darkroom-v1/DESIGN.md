# Design System: 暗房控制台 Darkroom（派生自 linear.app）

> 血统：`linear.app` → `20260821-darkroom-local-llm-settings`（★4）→ 本风格。
> 核心命题：把 Linear 的"近黑精密 UI"做成**本地优先工具的设置控制台**配方——⌘K 命令面板、分区设置流、危险区两步确认，以及"隐私即文案"的叙事姿态。

## 1. 视觉主题与氛围

工程师的深夜工作台。近黑三级表面（`#08090a` 画布 / `#0f1011` 面板 / `#191a1b` 浮面）以亮度堆叠构建海拔；半透明白描边（5%–8%）如月光线框；靛蓝 `#5e6ad2/#7170ff` 是全系统唯一彩色，只给 CTA 与激活态。界面安静得像一块熄屏的显示器——直到你按下 ⌘K。

氛围关键词：本地、离线、隐私、命令面板。文案直白带一点立场（"你的对话只属于你的硬盘"、"没有账号体系"）。

**关键特征：**
- 近黑三级亮度堆叠（非阴影深度）；半透明白描边 `.05/.08`
- Inter 可变字体 510 签名字重（400 读 / 510 强调 / 590 宣告，无 700）+ `"cv01","ss03"`
- **⌘K 命令面板**：`#191a1b` + 12px 圆角 + 五层近零级联阴影 + 实时过滤 + ↑↓↵ 键盘导航
- 设置页三件套：粘性分区侧栏（激活靛蓝条）+ 分区堆叠 + 右下角保存浮条（✓ 淡出）
- 控件套件：toggle 靛蓝轨道、分段选择器、accent 滑块、单选卡（选中靛蓝描边+圆点）
- 危险区：红 30% 描边 + 3% 红底 + 两步确认（3 秒复位）
- 成功绿 `#10b981` 仅状态点与保存反馈

## 2. 色彩与角色

| 角色 | 值 | 用途 |
|---|---|---|
| 画布/面板/浮面 | `#08090a` / `#0f1011` / `#191a1b`（hover `#28282c`） | 亮度即海拔 |
| 文本四层 | `#f7f8f8` / `#d0d6e0` / `#8a8f98` / `#62666d` | 白度分层，非色相 |
| 品牌靛蓝 | `#5e6ad2` CTA 底 / `#7170ff` 激活 / `#828fff` hover | 唯一彩色，只给交互 |
| 描边 | `rgba(255,255,255,.05)` subtle / `.08` 标准 | 月光线框 |
| 按钮微透明 | `rgba(255,255,255,.02→.05)` | 按钮永非实色块 |
| 成功绿 | `#10b981` | 状态点、保存 ✓ |
| 危险红 | 描边 30% + 底 3% | 危险区专用 |

## 3. 字体规则

Inter 可变（`wght 100..900`）直载；`font-feature-settings: "cv01","ss03"` 全局；等宽用系统链（ui-monospace/SF Mono/Menlo）。

| 角色 | 字号 | 字重 | 备注 |
|---|---|---|---|
| 页题 | 48px | 510 | -1.056px；设置页不需要 hero |
| 分区题 | 20px | 590 | -0.24px |
| 标签/正文 | 15px | 510/400 | 标签 510、说明 400 三级灰 |
| kbd 键位 | 12px | 400 | mono + `.05` 白底徽标 |
| 状态数字 | mono 13px | 400 | 显存/token 等资源读数 |

展示负字距按文档缩放（48/-1.056、32/-0.704、20/-0.24），中文 375px 收窄至 -0.6px。

## 4. 组件样式

- **⌘K 命令面板（签名）**：85% 黑遮罩 + `#191a1b` 面板（12px 圆角 + `.08` 白边 + 五层级联近零阴影）；输入行 + 结果列表（13px/510 银 → hover `.02` 白底白字）+ 底部 kbd 提示行；↑↓ 循环高亮、↵ 执行、Esc 关闭
- **设置行**：标签（15px/510 白 + 13px 三级灰说明）左、控件右，行间 5% 白底线；768 以下上下堆叠
- **toggle**：36×20 药丸，开 = 靛蓝轨道白点右移；480 放大 44×24
- **分段选择器**：`.02` 白底 6px 圆角内嵌按钮，激活 `.05` 底 + 1px 黑环
- **单选卡**：`.02` 白底 + `.08` 白边 8px 圆角，选中靛蓝描边 + 圆点；右侧 mono 元数据
- **资源状态卡**：`.02` 底卡 + 6px 靛蓝进度条 + mono 占用读数 + 足迹说明
- **危险区**：红 30% 描边 8px 圆角 + 3% 红底；按钮两步确认（"再点一次确认"→ 3 秒复位 →"已清除 ✓"禁用）
- **保存浮条**：右下角 fixed，靛蓝主按钮 + emerald「✓ 已保存」1.6s 淡出

## 5. 布局原则

- 210px 粘性设置侧栏 + 内容分区堆叠；992 以下侧栏转顶部横滚 tab
- 分区顺序建议：通用 → 核心功能 → 性能/资源 → 隐私 → 快捷键 → 危险区
- 页头：面包屑 + 48px 题名 + 一句立场文案 + 状态 pill（绿点 + mono 读数）

## 6. 深度与阴影

亮度堆叠（`#08090a→#0f1011→#191a1b→#28282c`）承载一切海拔；唯一多层阴影给命令面板（近零透明度五层栈）；内凹 `rgba(0,0,0,.2) 0 0 12px inset` 可用于沉入面板。禁偏移投影。

## 7. Do's & Don'ts

### Do
- 每个本地工具页都配 ⌘K 面板（导航 + 操作双入口）
- 危险操作必两步确认且 3 秒自动复位
- 隐私文案写立场（"没有账号体系""默认关闭"），不只写开关
- 资源占用（显存/磁盘/内存）做成进度卡 + mono 读数
- kbd 键位用 mono 徽标；保存反馈 ✓ 淡出
- 亮度堆叠做深度，半透明白做描边

### Don't
- 不要 700 字重、不要纯白文本、不要实色按钮底
- 不要在暗底用偏移阴影（不可见）
- 不要把靛蓝用于装饰（仅 CTA/激活/选中）
- 不要跳过快捷键表——命令面板的入口必须在页面可见
- 不要让危险区与常规设置混排

## 8. 响应式行为

992 侧栏转横滚 tab；768 导航链接隐藏、设置行堆叠；480 toggle 44px、保存条全宽右对齐、按钮 ≥44px；375 页题 30px。命令面板在触屏端保留点击触发（按钮式输入框入口）。

## 9. Agent 提示词指南

**起手式**：铺 `#08090a` → 分区堆叠 + 210px 侧栏 → 每行"标签+说明 / 控件" → 危险区收尾 → 钉一条保存浮条 → 装 ⌘K。

**示例提示词**：
- "命令面板：85% 黑遮罩，#191a1b 面板 12px 圆角 + 1px rgba(255,255,255,.08) 边 + 五层近零阴影；输入 15px/400 白，结果行 13px/510 #d0d6e0 hover 变 #f7f8f8 + .02 白底；底部 kbd 提示（↑↓ 导航 / ↵ 选择 / esc 关闭）。"
- "设置行：左 15px/510 白标签 + 13px #8a8f98 说明，右控件；行间 1px rgba(255,255,255,.05) 底线。"
- "危险区：1px rgba(238,61,54,.3) 边 + rgba(238,61,54,.03) 底，8px 圆角；按钮描边同红，点击后变'再点一次确认'，3 秒复位。"

**适配题材**：本地模型运行器、自托管工具、开发者桌面应用、隐私优先产品——一切"设置页承载价值观"的本地优先工具。
